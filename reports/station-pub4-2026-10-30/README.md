# 第4便: 575駅以外の駅の実在確認（2026-10-30）

第3便（PR #304・575駅）の続き。`lib/all-stations.ts` の589駅のうち、`lib/station-verified-stores.ts` に入っていなかった14駅（関西11・神奈川3）を照合した。

## 結論

- 14駅とも、照合前のチェーン一覧は **0件**（明示リストも一律付与も無い小さな駅）。駅ページに出ていたのは「近くの施設」とホットペッパーの店だけだった。
- 照合の結果、**800m以内のチェーン店50店（11駅）・800m〜1kmの店36店**を公式で確認し、14駅を `station-verified-stores.ts` に登録した。これで589駅すべてが照合済みになる。
- 駅ページに出ていた近くの施設20件は、19件を運営元の公式で営業中と確認した。残りの「愛知こどもの国」（愛知県西尾市）は、**同名の別の駅（名鉄蒲郡線こどもの国駅）を取り違えて、横浜市青葉区の「こどもの国」駅ページに出ていた**ので外した。
- 同じ確認の中で、575駅側にも**駅のホーム上（改札内）の店が2店**載っているのが見つかった（吉野家 JR京橋駅ホーム店＝大阪京橋の駅前、ドトール 東武北千住駅下りホーム店＝北千住の駅前と、牛田・京成関屋の「少し歩く」枠）。`gate-status.json` に改札内として登録し、4行を外した。同じチェーンの別の店が各駅に残るので、駅のチェーン数は変わらない。

## 確かめたこと

1. **店の実在（2026-10-30）**: 載せる86店すべてについて、チェーン公式の店舗ページを1店ずつ取り直した。ページが JS 描画で店名が取れないコメダ（4店）とモスバーガー（6店）は、公式の一覧API（`eu.komeda.co.jp/v1/hp/shop?all=true`・1,054店、`www.mos.jp/data/shop/shop.json`・1,327店）で店名と住所を確認した。閉店・長期休業の告知がある店は無かった（ミスタードーナツ OBP・エル枚方の「休店」は曜日ごとの営業カレンダー、ロイヤルホスト森ノ宮の休業は11/12の1日だけ）。
2. **陽性対照**: 同じ全国一覧から、575駅で実在を確認済みの店が引けること（第3便の検算）に加え、上の2つのAPIが今日も全国の件数を返すことを確かめた。
3. **座標の狂い**: 載せる店の公式住所を国土地理院の住所検索で位置に直し、公式座標の距離と比べた。250m以上ずれたのは4店で、どれも住所の検索が丁目まで当たらず、町の代表点に落ちたのが原因だった（京都の通り名住所2店、天保山マーケットプレースのサブウェイは公式住所の区名が「中央区」と誤記・正しくは港区、海の公園のスターバックスは番地まで）。公式座標は実際の所在地と合っていたので、公式座標をそのまま使った。
4. **駅の座標**: 14駅の座標を HeartRails Express（駅データAPI）と突き合わせた。**梅小路京都西が約295m、計算科学センターが約203mずれていた**ので、`scripts/station-verify/stations.json` と `lib/station-coords.json` を直した。梅小路京都西は直した位置で照合し直し、800m〜1kmの店が入れ替わった（京都駅側のイオンモールKYOTOの8店が外れ、西大路・五条七本松側の6店が入る）。
5. **改札の内外**: 吉野家 JR京橋駅ホーム店は、公式住所が「JR大阪環状線京橋駅外廻りホーム」なので改札内として外した（大阪城公園駅から984m）。
