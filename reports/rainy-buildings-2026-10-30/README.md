# 雨の日の建物台帳（2026-10-30）

`scripts/station-verify/building-access.json` を新設した（設計書 `docs/station-cond-rebuild-2026-10.md` §5-4・§9 の Phase 3 の前提データ）。**まだ画面と判定には使っていない**（雨の日の判定は今のまま保留）。

## 対象

- 設計書の「約170棟」は、雨の日の候補になる62駅（主要駅・救済リストの駅で、建物名から3店以上になりうる駅）にある実在チェーン店の住所から拾った**建物名の表記ゆれ込みの数（168通り）**だった。同じ建物をまとめると **100棟・224店**。
- 一覧は `buildings-input.json`（建物ごとの店名・住所・近くの駅）。100棟のうち8棟は住宅・オフィスビル（ライオンズマンション5棟・新目黒東急ビル・港区芝のサンシャインビル・梅島ニアステーションビル）で、商業施設の公式サイトが無い。

## 作り方

1. 建物ごとに、Claude API（Opus 5.5・web検索とページ取得・Batch API）で運営元の公式サイトを調べさせ、原文と出典URLを JSON で返させた（`~/biz/kyounoko/tools/official-fact-audit/building-audit.mjs`）。出典は運営元（デベロッパー・商業施設・鉄道会社）の公式だけ。テナントのチェーン店ページ・まとめサイト・地図は出典にしない。費用は合計 約$26.6（Batch 100棟 $18.75＋ツール上限で調べきれなかった14棟の取り直し $7.53＋試験1棟）。
2. **返ってきた原文が出典ページに本当にあるかを、全件機械で突き合わせた**（出典URLを curl で取り直し、空白・記号をならして部分文字列を探す。metaタグの文言も対象）。323件中295件が一致した。一致しなかったものは手で見た:
   - JS描画のページ（ビックカメラ・ヨドバシ・東武百貨店・東急プラザ蒲田・ららぽーと豊洲・ルミネ池袋）は内蔵ブラウザで本文を読んだ。
   - ソラマチはHTMLページが403で、公式フロアガイドPDFの文字を読み取った。
   - **出典URLが存在しないもの**（東武百貨店のキッズ施設ページ・エキュート上野のベビーカー貸出ページは404）や、公式サイトに接続できないものは「公式で確認できず」にした。モデルが取得を断られたとき、検索結果の抜粋から原文を作ることがある。原文の突き合わせを省くと、存在しないページを出典にした記載が台帳に入る。
3. 原文に設備名が入っていない記載（「5Fにご用意しております。」など、ページの見出しの下の文）は、`note` に「原文に設備名は入っていない（出典ページの該当する欄の記載）」と書いた（21件）。

## 使うとき（Phase 3）

- 「駅直結」「雨に濡れずに」と書けるのは `directAccess.verdict === "確認済み"` かつ `value === "yes"` の建物だけ。直結先の駅（`stations`）は公式の書き方なので、駅slugとの対応づけを先にする。
- 設備は「確認済み」のものだけ表示し、出典と確認日を添える。「公式で確認できず」は書かない（「ない」とも書かない）。
- 営業状態・設備は変わるので、公開前日に取り直す。
