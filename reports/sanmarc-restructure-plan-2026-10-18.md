## 2. 公式の確認（2026-10-18）

- **本部メニュー「デザート」**: キッズセット 490円・3点セット（チョコクロ・ソフトクリーム・アップル100%ジュース）。対象年齢・大人の可否は記載なし。記事の記載（9/4確認）と一致。
- **店舗検索**: 店舗一覧の API は店ごとに住所・電話・営業時間・デリバリーだけを返し、`services`（設備）はどの店も空。キッズ・ベビー・駐車場などの絞り込みは無い。
- **店舗ページ**: 「席数」（例: 禁煙71席）と「備考」、店舗メニューへのリンク。店舗メニューのカテゴリは店で違う（パスタがある店、モーニングが無い店、デザートが無い＆茶業態）。
- **店舗メニュー > デザート**: 東京の通常店3店（店舗ID 721・730・689）でキッズセットが載っていた。＆茶 両国東口店（1009）はデザートのカテゴリが無い。→ **全店を回せば「キッズセットがある店／無い店」を都道府県別に数えられる**（五右衛門型の店ごとデータ）。
- 店舗IDの一覧は API が GET の条件を受け付けず（常に同じ20件）、内蔵ブラウザで都道府県別の一覧を開いて集める必要がある。
