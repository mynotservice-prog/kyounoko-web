# 駅ページの店舗情報の公式照合（全589駅・2026-11-02）

全589駅の店舗台帳を公式の店舗一覧と取り直し、手書きの対応表を廃止して台帳に一本化した。本文・FAQ・構造化データに残っていた根拠のない断定も外した。

## 数字

| 項目 | 結果 |
|---|---|
| 公式の取り直し | 54チェーンを11/2に全国取得。大阪王将だけ公式が503で取れず10/08版のまま |
| 台帳の差 | 19店の差で63駅が変更（`store-changes.csv`。5店枠の入れ替わりを含む） |

上位50駅の読み取りは `readings.csv`（駅・チェーン・判定・最寄り店・公式URL）。

## 判定の基準

- 実在: 駅中心から直線800m以内。800m超〜1kmは「少し歩く」枠だけ。1km超は載せない。
- 銀座インズ店は新橋駅から1,027〜1,036mで載せない。
- 上位50駅で無いと判定した162件は、公式座標と住所の両方で測って800m以内に入らないことを確認した。全駅への展開は同じ手順の機械照合で、1件ずつの距離の二重確認は上位50駅だけ。
- 陽性対照: 全チェーンで件数を10/28と比べて大きな増減なし。すかいらーくは point API を直接引いて実在店が返ることを確認。
- 休業: 再開まで7日以上あるものは載せない（台帳の決まり）。再開を取りこぼさないよう `closed-now.csv` で追う。

## 本文・FAQ・構造化データの修正

- 駅トップ: 手入力のランチ価格の表示・「サクッと800円以内」・予算の絞り込み、雑誌・SNSの説明、混雑やエリアの断定、古い「この情報について」を外した。
- 個人店面のFAQの「チェーン店0店」を修正。
- 路線40本: 鉄道会社の設備・料金の断定を外し、「N店舗」を延べ件数に、「使いやすいTOP3」を「掲載の多いTOP3」に変更。
- `/station` 一覧: 駅数と説明を実数に修正。
- `/data`: チェーン店の設備を公式の根拠だけに変更。ベビーカーの列・絞り込み・順位を外し、家族度スコアを2指標に変更。件数を23区に揃えた。

## 施設の断定（公式で照合）

公式と違っていた: 原宿の「ファミレスなし」、有楽町の「ベビーカー貸出3施設」、レイクタウンの価格・店名・品数・優待店。
確認できず外した: 日吉・四ツ谷・レイクタウンの「駅直結」、自由が丘のおむつ替え5階、kaze の「ベビーシートあり」7店分、アウトレット2店の内容、mori のベビーカー預け場所。
確認できた「駅直結」は残した: キュービックプラザ新横浜、相模大野ステーションスクエア、アトレ松戸、アトレ浦和、グランエミオ所沢。

## 社長判断に回したもの（直していない）

1. **雨の日51面**: 件数が説明文の語で決まっている。チェーン68件は天丼てんやと洋麺屋五右衛門の「ビル内」、個人店108件のうち64件は「地下鉄」の字の一致。直すと配信面が減る可能性があるので、建物台帳との結線と合わせて判断が要る。
2. **題名・H1**: 全面の末尾「離乳食持込・ベビーチェア」、個人店面の「話題店」、「子連れOK」の一律表記。11/25ごろの駅ページ題名変更の測定と重なるので触っていない。
3. **`STATION_CHAIN_DATA_UPDATED`**: 上げると全駅の sitemap の lastmod が動くので据え置き。本文からは参照を外した。
4. **レイクタウン**: 店の掲載と kaze のキッズメニュー表示は8/10確認のまま。公式が統合されたので44店の取り直しが要る。
5. **チェーン説明文の残り**: 「ご飯おかわり自由」「小盛りあり」などの断定は未照合。
6. **個人店の語**: 俺のワイン酒場などチェーン色のある店も個人店枠に入る。

## 別件

- `/data/restaurants` は開発環境で約8.4MB（本番の現状は6.3MB）。
- `docs/writing-rules.md` のサイゼリヤの `list?address=…` は HTTP 400。全国取得は `fetch/saizeriya.py` で動く。
- `STATION_CHAIN_EXCLUDE` と ubiquity の自動付与は全駅が台帳登録済みなので到達しない。駅を足すと再び動く。
