## ⚪ 遠方（関東圏外）の扱い

代わりに Track B＝公式で確認できる設備（おむつ替え・授乳室・ベビーカー動線）・料金・予約データを充実させ、
「運営者は未訪問。設備情報は公式で確認」と明示することで、誠実なまま情報密度で勝負する。
