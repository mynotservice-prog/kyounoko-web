## 実装フロー

1. **ながみー側**：各プログラムの「広告リンク」(URL)をASP管理画面から取得
   - A8: 「広告リンク」ボタン → リンクコード生成 → URLを抽出
   - もしも: 「広告リンクへ」ボタン → URLを抽出
2. **コピペで本ドキュメントの該当エントリに追記** (例:「② ワンダーボックス → URL: https://...」)
3. **私が `lib/affiliate-products.ts` に一気に追加**
4. **`AFFILIATE_TARGET_SLUGS` に該当記事を追加**
5. **デプロイ**
