## 2. 次回 Claude design で重点的に磨きたい箇所

優先度順。各項目に**今の課題**と**理想の状態**を書いてあります。

### 2-1. TOP のヒーロー（最優先）

**現状**：
- 横 1 列、左に手書きコピー＋右に親子写真の半透明オーバーレイ
- 検索フォームは下に重ねた白パネル（PC ではやや浮いて見える）

**改善希望**：
- スマホ：写真がもっと「親子の笑顔」が主役に見える構図にしたい
- PC：左右 2 カラム（左：コピー＋フォーム / 右：大きな写真）にしたい
- 「今日、どこ行く？」のキャッチが今より大きく目立つこと
- 「0〜6歳の子育てメディア」バッジの位置をもっと自然に
- フォームのドロップダウン UI が iOS / Android で見栄えに差があるので、カスタム dropdown のデザイン案がほしい

### 2-2. スポット詳細ページ

**現状**：
- ヒーロー → 基本情報グリッド（4 枠）→ 設備 → アクセス地図 → 関連 → 保存ボタン
- アクセス地図は OpenStreetMap iframe
- 「きょうのこチェック」（星評価）は未実装

**改善希望**：
- ヒーローのデザイン強化：画像 + タイトル + パンくず + カテゴリチップを綺麗に重ねる
- 「きょうのこチェック」（運営者目線の 5 段階評価カード）の UI 案
- 「年齢別の楽しみ方」アコーディオン or タブのデザイン
- 写真ギャラリー（複数枚スワイプ）の UI

### 2-3. イベント一覧・詳細

**現状**：
- `/events`：開催中／今週／今月の 3 ブロックに分けた縦リスト
- `/event/[slug]`：ヒーロー＋基本情報カード＋編集部メモ＋公式リンクボタン

**改善希望**：
- カレンダー表示の選択肢（月別グリッド）
- 「子連れOK度」バッジ（◎○△）
- イベントカードに**残り日数**バッジ（「あと3日」「今週末」など）
- 期間長いイベントと単発イベントの見せ方の差別化

### 2-4. エリアページ（/area 系）

**現状**：
- `/area`：7 都県カード＋人気エリアチップ
- `/area/tokyo`：23 区 + 多摩のリスト
- `/area/[slug]`：ヒーロー＋人気スポット横スクロール＋関連記事

**改善希望**：
- エリアページのヒーローを「その街の象徴的なビジュアル」に
- 「このエリアでよく検索される条件」（雨の日 × 0歳 など）のショートカット
- 駅一覧へのリンクをもっと目立たせる（既存の `/station/[slug]` 540件への導線）

### 2-5. 記事詳細ページ

**現状**：
- 本文 HTML はそのまま残し、外側だけ V2Frame で包む（最小侵襲）
- container-article 内部の見た目は旧デザインのまま

**改善希望**：
- 記事の H1・lede・カテゴリチップ・公開日のヘッダーブロックを v2 トーンに統一
- 本文中の H2 / H3 のスタイル
- FAQ アコーディオン
- 関連記事カードの統一感
- AdSense 配置の自然な見せ方

### 2-6. 検索 / フィルター UX

**現状**：
- `/search?q=雨` でキーワード検索
- ヒーローフォーム条件は `/today` に送って絞り込み
- 検索結果ページにフィルター UI なし

**改善希望**：
- フィルターのボトムシート UI（年齢／エリア／天気／予算）
- 検索結果カードに条件マッチ理由を可視化（「あなたの条件: 雨の日 × 1〜3歳」）
- 該当0件のときの EmptyState（条件を1つ外す提案）

### 2-7. カテゴリページ

**現状**：
- 10 カテゴリ（today-doko 等）の一覧、各カテゴリで記事を縦リスト表示

**改善希望**：
- カテゴリヒーロー（カテゴリ固有のイラスト or 写真 + キャッチ）
- 人気記事 Top5 を冒頭に強調
- サブカテゴリ（タグ）への絞り込みチップ

### 2-8. 保存一覧 (`/favorites`)

**現状**：3タブ（スポット／外食／特集）、各タブで保存済みをリスト

**改善希望**：
- 空状態の改善（イラスト＋「探す」CTAがもっと魅力的に）
- 保存日でソート切替

### 2-9. 全体の統一感

- カードのデザインバリエーション（横スクロール用・リスト用・ミニ）の整理
- セクション見出しのバリエーション（アイコン付き／オレンジバー／番号付き）
- マイクロインタラクション（カードのホバー、保存♥ のアニメーション等）

## 6. その他、伝えておきたいこと

- イベント機能は **編集部が手動でキュレーション**する方式（Walker Plus 等の転載は NG）。今は 7 件サンプル。
- 「最近見たスポット」「保存一覧」は localStorage ベース。サーバー保存は将来検討。
- AdSense は審査済み、本番のみ表示。dev では枠だけ確保（空）。
- PWA インストール対応済み。下部ナビが画面下に固定。
- 全ページに JSON-LD（Article / Event / CollectionPage / LocalBusiness / FAQPage）を出している。Google リッチリザルト最適化済み。
- フォントは Noto Sans JP は外し、丸ゴシック（M PLUS Rounded 1c）に統一済み。
