## 申請手順（A8.netの例）

1. **A8.netにログイン** (https://www.a8.net/)
2. **プログラム検索** で個別プログラム名を検索
3. **「提携申請する」** をクリック
4. **メディア情報の確認**（自動入力）→「申請内容を確認する」
5. **「申請する」** クリックで完了
6. **承認まで1日〜7日**（プログラムによる）
7. **承認後、リンク作成 → サイトに貼り付け**

## 環境変数（ENV）の管理

A8.netのアフィリエイトリンクは個別URLで管理されるため、もしも経由楽天のような自動ラップは不要。**直接記事内に挿入する形** が基本。

ただし、よく使うバナーは React component化しておくと管理が楽：

- `components/affiliate/A8Banner.tsx`（バナー画像＋リンク）
- `components/affiliate/A8TextLink.tsx`（テキストリンク）
