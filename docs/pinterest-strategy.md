# Pinterest 流入戦略（子育てママ層攻略）

## なぜPinterestか

- **子育てママの主要な情報源**：Pinterestユーザーの男女比は女性70%、25-44歳が最も多い → きょうのこのターゲット完全一致
- **検索エンジン的に使われる**：「離乳食」「自由研究」「100均DIY」など、Google検索の代わりに使う層が増加
- **長期的なトラフィック**：Pin は数ヶ月〜数年単位でクリックされ続ける（Google検索より長寿命）
- **競合少なめ**：日本語Pinterestの子育てジャンルは英語圏より競合密度が低い

## Phase 1: アカウント開設＋ビジネス化（30分）

1. **個人アカウント作成** ([pinterest.com](https://pinterest.com))
2. **ビジネスアカウントに切り替え**（無料）
   - 設定 → アカウント管理 → ビジネスアカウントに切り替え
   - サイトURL: `https://kyounoko.jp` 入力
3. **サイト所有権の確認**
   - Pinterest からタグ or HTMLファイルを発行
   - サイトに設置 → 確認完了
   - 完了後「Pinterest Rich Pins」が有効に

## Phase 2: Rich Pins 自動連携（実装済み）

サイト側は対応済み：
- 各記事に `pinterest:image` `pinterest:description` `pinterest:title` メタタグ自動出力
- Pinterest が記事 hero 画像と説明を自動取得
- ピン作成時に高解像度な画像と本文情報が反映される

確認方法：
- [Pinterest Rich Pins Validator](https://developers.pinterest.com/tools/url-debugger/) に記事URL貼り付け

## Phase 3: ボード設計（最初の5ボード）

カテゴリに合わせて5ボードでスタート：

| ボード名 | カテゴリ |
|---|---|
| **今日どこ行く｜0-6歳子連れスポット** | today-doko |
| **今日なに作る｜子供ごはん時短レシピ** | today-taberu |
| **今日なにする｜0-6歳の家遊びアイデア** | today-nani |
| **今日どう回す｜ワーママの時短家事Tips** | today-mawasu |
| **季節と行事｜0-6歳の年中行事ガイド** | gyouji |

各ボード説明文に：
- ターゲット（0-6歳ママ）
- 内容（実体験・体験談）
- サイトURL（[kyounoko.jp](https://kyounoko.jp)）

## Phase 4: ピン作成のコツ

### サイズ
- **縦長 1000×1500px（2:3比率）** がベストプラクティス
- 既存hero画像（1600×900横長）はクロップ＋再構成が必要

### デザイン要素
- **大きな文字**でタイトル明示（モバイルで読める）
- **記事の数字** を強調（10選・3歳・5分）
- **目を引く色** （きょうのこのブランドカラー）
- **写真とテキストのコントラスト** を確保

### 投稿頻度
- **1日2〜5ピン** が推奨（多すぎは逆効果）
- **新規Pin と既存Pinのリピン** を組み合わせ
- 朝9-11時、夜21-23時の投稿が最も反応良い

## Phase 5: 自動化（Buffer or Tailwind）

### 無料プラン
- 既存ピンをCanvaで作成 → Pinterest手動投稿
- 1日30分の作業で週20Pin

### 有料プラン（推奨）
- **Tailwind**（月$15、Pinterest公式パートナー）
- 自動スケジュール投稿
- 最適投稿時間の自動判定
- 月100Pin以上の自動化

## Phase 6: 初期投稿コンテンツ（最初の100Pin）

優先的にピン作成すべき記事 TOP10：

6. **離乳食食材宅配比較** - 高関心

- **GA4 で「pinterest.com」からの流入** を確認
