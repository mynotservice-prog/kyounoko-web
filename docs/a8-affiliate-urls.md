## A8リンク管理のコツ

1. **トラッキングURLは固定** — 一度発行されたURLは原則変わらない
2. **MarkdownでもHTMLでも使用可** — `[テキスト](URL)` で配置
3. **rel="sponsored nofollow noopener"** は `lib/articles.ts` の `ensureRelAndTarget` で自動付与
4. **コンバージョン管理** — A8管理画面の「レポート」で日次確認
5. **新規承認時** — このドキュメントに追記してから配置
