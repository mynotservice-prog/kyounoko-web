## D. 帰宅後の対応シナリオ

### ケース1: 承認された場合 ✅

1. AdSense → 広告 → 自動広告 を有効化（既にAdSlotコンポーネント実装済みなのでクリック数回で完了）
2. ads.txt が `google.com, pub-4445473825791494, DIRECT, f08c47fec0942fa0` を返している事を確認（既存実装で問題なし）
3. 初日は様子見、3日目に広告配置のA/Bを開始（記事内中央 vs 末尾 vs サイドバーなど）

### ケース2: 拒否された場合 ❌

拒否理由のメールが届くので、その内容に応じて対応：

- **「価値の低い広告枠（コンテンツが少ない）」** → AdSenseは新規サイトでよくある拒否理由。**追加コンテンツ + 1〜2週間後に再申請**。旅行中の自動サイクルでさらに記事が増えているはずなので、再申請のタイミングが良くなる可能性が高い。
- **「ポリシー違反」（薬機法、医療系コンテンツの断定的表現など）** → editorial-policy ページの方針通りに見直し。該当記事を特定して書き換え。
- **「サイトがダウンしている / アクセス不可」** → Vercel デプロイ確認、サーバーエラー（5xx）の有無確認。

### ケース3: まだ「準備中」のまま ⏳

審査は1〜4週間が目安。それ以上経過しても変化がなければ：

1. AdSense ヘルプセンターから問い合わせ
2. Search Console の検索パフォーマンスを見せて、自然流入があることを示せると有利

## 旅行中のリスクチェック

- **新規記事の追加**: 旅行中も2時間ごとに新規記事が公開される。AdSense はクロール対象記事数を見ているので、量が増えるのは基本プラス。ただし、品質が落ちると逆効果になるリスクがあるので、scheduled-task のプロンプトで「質>量」を強調済み。
- **構造の変更**: 大規模なリダイレクト・URL変更は審査中に避けるべき。今日まで実装した変更（GA計測の admin 除外、PRBadge強制表示、metaDescription拡充）はすべて軽微で、AdSense にとっては「品質向上」のシグナルになる。
