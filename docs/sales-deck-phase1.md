# 営業資料 Phase1：無料掲載のご案内（レジャー施設・地域のお店向け）

> Claude Design ハンドオフ用ドラフト。各スライドの「見出し／本文コピー／載せる数字・図版」を指定。
> 目的＝**お金を取らずに掲載してもらい、関係と掲載実績をつくる**こと。請求ではなく実績を渡すフェーズ。
> データ出典：Google Search Console 実数（2026-06-26取得 / `scripts/gsc-report.mjs`）。
> **一次標的＝パイロット30施設（牧場・おもちゃ美術館・ミュージアム・屋内施設／`docs/outreach-pilot-30.csv`）。** 多くが取材・撮影開放を明記＝無料掲載が通りやすい。飲食チェーンは実データで強いがPhase2。

## 前提・トーン
- 相手：子連れ向けレジャー施設（牧場・おもちゃ美術館等の中小施設）／地域の飲食店。決裁が速い規模を優先
- 文中は「御施設・お店」と両対応で表現する
- ゴール：その場で「じゃあ無料なら載せてもらおうか」を引き出す
- トーン：売り込みでなく「無料で御店の集客をお手伝いします」。専門用語を出さない（SEO/CTR等は言い換える）
- 想定尺：6〜7スライド（A4縦 or 16:9）。短く。

## スライド4：読者は「来店見込みの高い親」です
- **見出し**：見ているのは、“これから行くお店”を探している親
- 3点を箇条で：
  - **96%がスマホからアクセス** → 外出先・移動中に「今から行ける場所」を探している
  - 検索は「ベビーカー」「授乳室」「○歳から」「子ども椅子」など**来店直前の具体的な条件**で調べている
  - だから、**見た人がそのまま御施設・お店へ足を運びやすい**
- 図版：実際の検索ワード例をタグ風に並べる（「○○牧場 何歳から」「サイゼリヤ ベビーカー」「ガスト 離乳食」など、施設・飲食を混ぜる）

## 数字の扱い・注意（社内メモ／資料には出さない）
- 月間「約2,800」＝直近28日のデバイス集計実数（2,825）。query集計は1,360だがプライバシー閾値で過小なので、総数はデバイス集計を使う。
- 「約19倍」＝query集計 前月比（71→1,360）で period 比較が一貫しているのでこの倍率を採用。
- グラフの週次は query集計の実数（過小だが推移の形は正しい）。**総数（2,800）とグラフの週合計が一致しない**点に注意——資料では「成長の形」をグラフに、「月間総数」を数字パネルにと役割分担させる（並べて引き算されないようレイアウトで離す）。
- 数字は誇張せず、すべてGSC実数の範囲。更新時は `node scripts/gsc-report.mjs --days=28` を再取得。
