# きょうのこ サイト画像生成リスト（ChatGPT / 画像生成 AI 用）

> **目的**: サイト見栄え強化のために必要な画像を生成依頼する用のプロンプト集。
>
> **使い方**:
> 1. ChatGPT (DALL-E / GPT-Image) に下記プロンプトをそのまま投げる
> 2. 生成された画像をダウンロード
> 3. 指定のファイル名で `public/v2/` 配下に保存
> 4. リポジトリにコミット

**共通の作風指示（毎回プロンプト先頭に追加してください）**:

```

明るい自然光、温かい雰囲気、パステル調。
日本人の親子・子どもを基本とする。
派手な装飾なし、清潔感、信頼感重視。
横長 16:9 （ヒーロー）または 1:1 （カード）。
```

## ファイル命名規則（厳守）

- 拡張子は **`.webp`** （Photoshop / Squoosh.app で変換可能）
- 命名は **kebab-case の英数字のみ**（日本語ファイル名は NG）
- 保存先は上記の「`public/v2/...`」のパスをそのまま使う
- 同名の既存ファイルがあれば上書き OK

## 推奨フロー

1. ChatGPT (Plus サブスク) で **DALL-E 3** を使う（または GPT-4o の Image gen）
2. プロンプトを 1 枚ずつ入力 → 生成 → ダウンロード
3. ファイル名をリネーム
4. webp 変換（必要なら https://squoosh.app）
5. 指定パスに配置
6. 全部揃ったら一括コミット

## 注意事項

- **実在の人物・キャラクター・ブランドロゴは含めない**（著作権・肖像権）
- 「ディズニー」「サンリオ」「ドラえもん」等の登場 NG
- 子どもの顔は **後ろ姿 or 横顔** が無難（マネキン感を避けつつ匿名性確保）
- 画像が苦手なシーン（料理アップなど）は無理せず Pexels / Unsplash から拾ってきても OK
