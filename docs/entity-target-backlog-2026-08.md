# 固有名詞ターゲット バックログ（着手待ち）

- 作成: 2026-08-18
- 方針の根拠: 社長裁可「基本、固有名詞じゃないと掲載順位で上位は狙えないので固有名詞で取りに行く」
- 計測: GSC `sc-domain:kyounoko.jp` / 2026-07-18〜08-15（28日）/ サイト全体 1,030,807表示・50,876クリック
- 再現: `node --import ./scripts/_ts-resolve.mjs tmp/backlog-screen.mjs`（実体ギャップ抽出は `tmp/find-entity-gaps.mjs`）

---

## 0. この表の読み方 — 表示数で選ばない

意図の型でCTRが桁で変わるため、**表示数の大きさではなく「調達型の表示 × 到達可能なCTR」で選ぶ**。

- **調達型**（キッズメニュー／授乳室／ベビーチェア／子連れ／遊び場／じゃぶじゃぶ池 など）＝勝てる
- **単答型**（何時まで／いつから／料金／何歳から）＝AIOが完答するので順位を上げてもクリックにならない

実測でこれがはっきり出ている:

| 例 | 表示 | CTR | 中身 |
|---|---|---|---|
| コメダ | 47,393 | **0.22%** | 単答型が44,128（93%）。順位7.7位でもクリック105 |
| やよい軒 | 4,486 | **10.41%** | 調達型が3,377。順位4.7位 |

**コメダは表示がやよい軒の10倍あるのにクリックは1/4。** 表示数で優先度を決めると必ず間違える。

## 1. 優先度A — すぐ着手できて効果が読めるもの

### A-1. CoCo壱番屋（順位はあるのにCTRだけ低い）

| 指標 | 値 |
|---|---|
| 全体 | 7,748表示 / 171クリック / **CTR 2.21%** / 5.4位 |
| うち調達型 | 4,883表示 / **CTR 2.0%** |

**同じ5位台の他チェーンと2〜3倍の開きがある**（やよい軒5.4% / バーガーキング4.5% / 資さんうどん6.6%）。

  何が上位に出ているか／自社スニペットが質問に直答しているかを確認 → タイトル・冒頭を直答型に書き換え
- 注意: タイトル変更時は `getArticleAdType` の検証が必須（過去に広告タイプが反転した事故あり）

## 3. 優先度C — 先に「そもそも向くのか」を調べる

### C-1. 一蘭（5,275表示なのにCTR 0.61%）

調達型が1,092表示あるのにCTR0.9%。**カウンター席主体で子連れに構造的に向かない**可能性がある。
「子連れで行ける」と書けない店を無理に狙うと、記事の主張が嘘になる。

- やること: 実店舗の子連れ受け入れ（ベビーカー／子供用椅子／小学生の扱い）を公式で確認 →
  向かないなら**捨てる**（`一蘭 小学生` 856表示・0クリックはその兆候）

### C-2. 夢見が丘キッズパーク（1,442表示・CTR 0.28%）

スポット `/spot/-pppf` は登録済みだが8.7位でクリック4件。**中身が薄いか、意図とズレている**。

- やること: 実SERPを見て、何を求められているのかを確認してからスポットを厚くする

### C-3. 昭和記念公園（11.2位＝2ページ目）

## 4. 着手前チェックリスト（今日の作業で得た教訓）

新しい固有名詞に着手する前に、必ずこの順で確認する。

1. **意図の型を見る** — 単答型（何時まで／いくら）に偏っていたら、順位を上げても取れない。捨てる
2. **実SERPを見る** — WebSearchのリンク集はSERPではない。動画カルーセル／PAAの有無でCTR期待値が桁で変わる
3. **今も実施しているか公式で確認** — シャトレーゼ白州工場は**工場見学が2022年に中止**なのに、
   二次情報には見学案内が今も大量に残っていた
4. **年齢下限を確認**（施設系）— 当サイトは0〜6歳が中心。JAL工場見学は小学生未満入場不可、
   明治坂戸は4歳未満不可、崎陽軒は3歳未満不可と**施設ごとにバラバラ**
5. **自社カニバリを確認** — 既存記事と食い合わないか
6. **タイトルを触るなら** `getArticleAdType` の検証を必ず通す
