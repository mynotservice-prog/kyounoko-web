## 提携申請する際のコツ

A8の審査基準は「**サイトのジャンル整合性**」と「**月間PV**」。「きょうのこ」は以下のアピール文を使うと通りやすい：

> 0〜6歳の子育て世帯向けメディア「きょうのこ」を運営しております。
> 月間XX万PV、記事数1,000本超、Webサービスとして本格運営しています。
> 育児ジャンル全般を扱っており、知育玩具・教材・宅配食・ベビー用品など多角的に紹介可能です。
> 該当ジャンルでの記事執筆実績も多数ありますので、ぜひ提携をお願いいたします。

### 申請時のチェック

- [ ] 申請理由欄に**該当記事URLを2〜3本貼る**（記事の質をアピール）
- [ ] サイト情報は最新の月間PVを記入
- [ ] 「即時提携」マークがあるものから優先（審査なし）
- [ ] 「審査ありプログラム」は1度に10件まで（多すぎ申請はマイナス印象）

### NG例

- [ ] 競合と紛らわしい大量比較記事のみ
- [ ] 個人のアフィリンクで埋まった単発記事
- [ ] 営業色が強いサイト

## 提携後 すぐにやること

1. **EPC（Earnings Per Click）が高い素材を選ぶ**
   - A8 管理画面の「EPC順」で並び替え
   - 上位2〜3つを記事内に分散配置
2. **テキストリンク優先**（バナーよりCV率が高い）
3. **発リンクのテキストは「ベネフィット＋ブランド名」**
   - ◯ `発送前に内容確認できる【And TOYBOX】`
   - × `公式サイトはこちら`
4. **記事末尾の「最終CTA」が最も効く**
   - 全部読んでくれた読者は購入意欲が高い
   - 結論として推奨する1社のリンクを最後にもう一度
