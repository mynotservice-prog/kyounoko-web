## 投稿時の注意

- **タイトル**: 元記事タイトルの一部を変えて重複ペナルティ回避（例: 「【完全保存版】」を冒頭に追加）
- **ハッシュタグ**: 各記事末尾に推奨タグ #育児 #子育て #ワンオペ育児 等を入れる
- **公開設定**: 全文無料公開推奨（バックリンク強化が主目的）
- **画像**: note 上で別途アップロード（記事内の画像URLはきょうのこへの参照リンク）
