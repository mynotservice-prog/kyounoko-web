## 2. 紫外線・日焼け対策

肌の弱い赤ちゃん・子どもの紫外線対策は通年テーマだが、夏が最大ピーク。

### 必読記事

- [子供用日焼け止め2026比較ランキング](https://kyounoko.jp/article/kodomo-hiyakedome-osusume-2026)

### ポイント

- SPF30〜50で日常用
- ウォータープルーフは海・プールのみ
- 2時間ごと塗り直し
- 物理ガード（帽子・ラッシュガード）併用

### 安全管理の基本

- 0〜2歳：水深10cm以下、常に手の届く距離
- 3歳以降：浮き輪併用OK
- 紫外線・熱中症対策同時に
- 水分補給を頻繁に

## 4. 虫除け・蚊対策

### 必読記事
