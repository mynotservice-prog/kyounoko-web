## 手動枠の期待値は当初想定より小さい（重要）

上の表がそのまま答えになっている。**remegift は kyounoko の2.1倍の広告密度（imp/PV 5.90 対 2.91）なのに、ページRPMは同等かむしろ低い**（¥351 対 ¥377）。
つまり **枠を増やしても1ページあたりの収益は比例して増えない。**

過去メモにあった「kyounoko の imp/PV は 1.1、remegift の 6.2 水準まで底上げできる」という前提は**古い**。自動広告と広告インテントが埋めた結果、すでに 2.91 まで来ている。残る伸びしろは 2倍弱で、しかもその2倍を実現している remegift の RPM が上回っていない。

→ **手動枠55個の一括投入は、期待値が小さいわりに体験を確実に削る。** 入れるとしても記事中1枠から。

## 先送りしてよい理由（ただし支払いは急ぐ）

広告枠そのものは急がなくてよい（上記のとおり期待値が小さい）。

一方 **支払いは急ぐ**。管理画面に「住所確認が必要なため、お支払いが保留されています」が出ており、**PIN が未入力**（本人確認・税務情報は完了済み）。PIN は郵送で届く6桁で、社長が郵便を待って入力する段階。
最低支払額 ¥8,000 に対し、**すでに月 ¥10,345（アカウント合計・過去30日）を稼いでいる**ので、閾値は事実上もう超えている。残高が ¥189 に見えるのは月末に確定するため。**PIN 入力が遅れるほど滞留するだけ。**

## 判断日

**2026-09-01週**。既に同じ週に9月判定のタスクが2件（鳥貴族 kids-menu 面／一覧探索クラスタ）あるので、まとめて処理する。

### 8/14 に先にやること

AdSense で **広告インテントの自動最適化テスト**が走っている（2026-07-20〜2026-08-14・50%配信・7.49万表示）。中間結果はパターン ¥3,405 対 オリジナル ¥3,304 の **+3%** で、管理画面自身が「現時点で判断することはおすすめしません」と出している。

**テスト期間中に広告構成を変えると結果が汚れる**ので、手動枠の投入は 8/14 以降。8/14 に「オリジナルを選択」か「パターンを適用」を決める。

### そのとき見る3つ

| 見るもの | 判断 |
|---|---|
| PIN 入力→銀行詳細が完了しているか | 未完なら、まずそれ。広告枠の議論はその後 |
| 広告インテントのテスト結果（8/14確定） | +3%程度なら誤差。ここが決まってから次を触る |
| PVの伸びが踊り場に入ったか | 伸びている最中は、体験を変えて成長を鈍らせるリスクの方が大きい。横ばいになったら入れどき |

直近のGSC週次では 7/13週 1,358clk/日 → 7/20週 1,295clk/日 とわずかに下降しており、**すでに踊り場の兆しがある**。9月時点で横ばいが続いていれば、3つ目の条件は満たす。

## 入れると決めた場合の進め方

一気に55枠を開けない。**記事中1枠から**始め、下記のUX指標を前後比較する。

### ベースライン（GA4実測 2026-08-01・直近28日／前28日）

| 指標 | 直近28日 | 前28日 |
|---|---|---|
| PV | 60,473 | 12,405 |
| セッション | 43,298 | 8,918 |
| ユーザー | 39,902 | 8,231 |
| **PV/セッション** | **1.40** | 1.39 |
| **エンゲージメント率** | **0.596** | 0.598 |

PV/セッション 1.40、エンゲージメント率 0.596 が、広告を入れる前の基準値。
**収益だけを見て判断しないこと。**この2指標が明確に落ちるなら、収益が増えていても引き戻す。エンゲージメントの低下は最終的に検索順位に返ってくる。

取得コマンド:

```bash
node scripts/ga4-report.mjs --property=533628127
```
