## マスター文面（フォーム・メール共通）

**件名：**
```
「きょうのこ」に{施設名}を掲載中です／公式写真ご提供のお願い
```
※フォームに件名欄が無い場合は、本文1行目に上記を入れる。

**本文：**
```
{施設名} ご担当者さま

突然のご連絡失礼いたします。全国の子育て家庭向けおでかけメディア
「きょうのこ」（https://kyounoko.jp ）の運営担当です。

このたび、子育て家庭におすすめできる施設として、{施設名}様の
ご紹介ページを当サイトに無料で公開しております。
▼掲載ページ
{掲載URL}

ただ、現在は一般的な写真で掲載しているため、貴施設の公式のお写真
（プレス用で構いません・3〜5枚）をご提供いただけませんでしょうか。
いただいた素材で無料で差し替え、より魅力が伝わるページにいたします。

・利用は当掲載ページとSNS紹介に限定し、クレジット（©{施設名}様）を明記します
・公開前に確認用URLをお送りし、修正は無料です
・お写真はメール添付・ギガファイル便など、ご都合のよい方法で結構です

きょうのこは子育て層に特化して成長中のメディアです。早めにご協力
いただいた施設様は、特集や上位表示で優先的にご紹介してまいります。

ご検討のほど、よろしくお願いいたします。
──────────
きょうのこ ／ service@remegift.jp
```

> 任意の一手間：冒頭に「Instagram（@xxxx）も拝見しました。」等の一文を足すと返信率が上がる。
> 取材歓迎を明記している施設（りんどう湖等）には「貴施設の取材歓迎の方針を拝見し…」と触れると刺さる。
