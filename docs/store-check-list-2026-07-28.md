# 実店舗で確認してほしいこと（2026-07-28 作成）

公式サイトに記載が無く、**実店舗でしか分からない項目**だけを集めたリスト。
公式で確認できる項目（ベビーチェアの有無・低アレルゲンメニュー・対象年齢など）はここに入れていない。あれは `curl` で取れるのでこちらで処理する。

## なぜこれが要るのか

「離乳食を持ち込めるか」は**検索需要が最も大きい軸**なのに、**主要チェーンはどこも公式サイトに書いていない**（2026-07-28 に各社公式を確認）。
競合サイトは「公式がOKと言っている」と書いているが、**その根拠は公式サイトに存在しない**。うちも同じ書き方をしていたので 2026-07-28 に「店舗判断」へ修正した（PR #99）。

つまりこの軸は、**実際に店舗で確認した人だけが本当のことを書ける**。ここが唯一の差別化点になる。

## 店舗で聞くこと（3つだけ）

入店時か注文時に、これだけ聞けば足ります。

1. 「**離乳食を持参しているんですが、大丈夫ですか？**」
2. 「**レンジで温めてもらうことはできますか？**」
3. 「**ミルク用のお湯をいただけますか？**」

## 記録してほしいこと

雑で構いません。

```
チェーン名 / 店舗名（◯◯店 or 「郊外のロードサイド店」程度でも可）/ 時期（年月）
1. 持ち込み  → OK / 断られた / 条件付き（内容）
2. 温め      → OK / 断られた / 条件付き
3. お湯      → OK / 断られた / 条件付き
その他気づいたこと（あれば）
```

**「断られた」も同じくらい価値があります。**「店舗判断で、断られることもある」と書けるのは実際に断られた人だけで、それ自体が他社に無い情報になります。

## 使い道

いただいた内容は `lib/chain-reports.ts` に構造化して入れ、該当記事に

> 編集長が◯◯店で確認（2026年◯月）：離乳食の持ち込みOK、レンジでの温めも対応してもらえた。

の形で載せます。**公式に記載が無いという事実 ＋ 実際に確認した結果**の2段構えにすると、
「公式がOKと言っている」とだけ書いている競合より正確で、かつ読者にとって有用になります。
