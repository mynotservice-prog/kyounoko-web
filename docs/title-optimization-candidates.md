# タイトル最適化候補（CTR向上で月間PV増を狙う）

## 戦略

Search Console 上位記事は **インプレッション（=露出）はあるがCTRが低い** ものを優先で書き換える。
- **インプ高×CTR低**：書き換え効果が最大
- **インプ高×CTR高**：触らない（壊さない）
- **インプ低×CTR高**：そもそも露出を増やす（SEO・内部リンク強化）

## 効果的なタイトル要素

### 数字を入れる
- 「5選」「10の方法」「3ステップ」
- 数字付きはCTR平均1.3〜1.5倍

### 年号を入れる（モノ系記事）
- 「2026年版」「2026年最新」
- 鮮度をアピール、+10〜20% CTR

### 具体性
- 「子連れで使いやすい」より「ベビーカーOK・キッズメニュー付き」
- 細部情報あり vs なしで +15〜30% CTR

### 検索意図に合わせる
- 「いつから・何歳から」→ 不安解消ワード追加
- 「おすすめ」→ ランキング型
- 「比較」→ 比較表ありを明示

### 句読点・記号
- 【】はモバイル検索結果で目立つ
- ｜（縦棒）で2フレーズ化
- !? は控えめに（スパムっぽさ）

## 実装方法

各記事の `title:` フィールドを上記改善案に書き換える：

```yaml
---
slug: yayoiken-kodzure-koryaku
title: 【2026年】やよい軒は子連れOK｜ベビーチェア・取り分けメニュー・キッズ対応完全ガイド
metaDescription: ...
---
```

書き換え後は IndexNow を送信して再クロール促進。

## A/Bテスト方針

タイトル変更は **同時に1記事のみ** が推奨。
1. 1記事のタイトルを変更してデプロイ
2. SCで1〜2週間の変化を観察（CTR・順位）
3. 改善したら次の記事へ
4. 悪化したら元に戻す

10記事連続変更は順位変動の原因切り分けが困難になる。
