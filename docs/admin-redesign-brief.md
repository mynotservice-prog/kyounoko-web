# きょうのこ Admin リデザイン ブリーフ（Claude Design 依頼用）

> このまま Claude Design に貼り付けて使えます。スクショ（現状のダッシュボード＋ナビ）を添付してください。

---

## 1. 背景

「きょうのこ」は子連れおでかけ情報サイト（Next.js 15 / React 19 / Tailwind）。
その **内部管理画面（/admin、noindex・運営者1人だけが使用）** をリデザインしたい。
公開サイトは和紙風の温かいテーマだが、**Admin は別物**として中立的な業務ツールにする。

## 2. 解決したい問題（最重要）

現状の Admin は **見た目以前に情報設計が破綻**している：

1. ヘッダーに **11リンクをフラット横並び**。グルーピングも現在地表示もなく「どこに何があるか／今どこにいるか」が分からない
2. 分析系・コンテンツ系・運用系が混在し役割の境界が見えない
3. 全インラインstyleで画面ごとに見た目がバラつく

→ **ナビの階層化・現在地表示・情報のグルーピング** を最優先で解決したい。色を綺麗にするだけでは不十分。

## 3. デザイン方向性（中立トーン）

- **業務ツールらしい中立デザイン**。SaaSダッシュボード（Linear / Vercel / Plausible 系）の落ち着いた雰囲気
- グレースケール基調＋**アクセント1色**（公開サイトの clay/レンガ系 `#8E3F22` を差し色として最小限に）
- **情報密度は高め**・余白は機能的に。数字は等幅フォントで揃える
- ダークモードは不要。ライトのみ
- 装飾的なイラスト/SVGは不要。**実装する前提の実用レイアウト**で

## 4. 作ってほしい画面（3枚に限定）

全11画面は作らない。型を決める3枚だけ。残りは実装側でトークン適用して展開する。

### 画面A: ナビゲーション・シェル（最重要）
- **左サイドバー**固定。3グループ＋見出し、現在地ハイライト
- グループ構成：
  - **分析・計測**：ダッシュボード / 経営KPI / Insights（記事品質） / Events（GA4イベント発火数） / A/B / SEO
  - **コンテンツ**：記事 / プラン / スポット
  - **運用・編集**：スポット編集 / イベント編集 / Image Gen
- 上部に薄いトップバー（サイト名「管理画面」＋ "内部管理用 · noindex" 表示）

### 画面B: ダッシュボード（/admin）
既存の3ブロックを再設計：
- **KPIカード**横並び（記事数 / プラン数 / スポット数 / エリア特化率）
- **データ源の健全性**：複数データ源が「LIVE / 要確認 / 未設定」のどれかをバッジ表示するカード群
- **改善候補**：Hero画像なし記事数などの数値リスト
- **記事カテゴリ分布**：カテゴリ名＋件数のテーブル

### 画面C: 一覧＋編集の型（記事 or スポットを例に）
- **一覧**：検索/フィルタ＋データテーブル（タイトル / カテゴリ / 状態 / 更新日 / 編集ボタン）。行数が多い前提
- **編集**：フォーム1枚（タイトル・本文・Hero画像・メタ）の基本レイアウト
- ここで「一覧→編集」の型を確定し、記事/プラン/スポット 全部に流用する

## 5. 制約（実装に落とすため必須）

- **実装可能なHTML/CSS構造**で出力（飾りでなくレイアウトが分かるもの）。Tailwind 前提だと尚良い
- UI文言は**すべて日本語**
- レスポンシブは不要（PC運営前提）。ただしサイドバーは折りたためると望ましい
- 既存の絵文字アイコン（📊📝🔧📈🎨）は撤去 or 中立な線アイコンに置き換え可
