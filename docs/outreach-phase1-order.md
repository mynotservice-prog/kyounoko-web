# Phase1 営業：送付順リスト（無料掲載・関係構築）

> 標的＝パイロット30施設（`docs/outreach-pilot-30.csv`）。**無料掲載でYesを取り、掲載実績と関係を貯める**のが目的。
> 並べ替え基準：①取材・撮影開放を明記＝最も通りやすい ②企業/小規模＝決裁が速い ③露出を歓迎する姿勢。
> 連絡文面は `docs/outreach-messages.md` を流用。資料は `docs/sales-deck-phase1.md`（→Canva化）。

## 進め方
- **1日5件ずつ、第1波から順に。** 返信が来たら掲載→実績スクショ化→次波の文面に「掲載例あり」を足す。
- 文面は短く：①誰か ②急成長の実数（月2,800・19倍） ③無料掲載＋公式写真の提案 ④掲載URL添付。
- フォーム/取材窓口がある先はそこへ。電話のみの先は後回し（時間効率）。

## 後回し / 保留
- **電話のみ＆組織判断が重い**：小岩井農場、うだ・アニマルパーク、大洗わくわく科学館、ぴぃかぁぶぅ（カプコン本社判断）→ 第1〜3波の反応を見てから。
- **掲載データに誤りの可能性＝先に修正**：感性の森（所在地）、ワンダーキャッスル（横手市の可能性）、ふくろうの杜（施設特定できず）→ 営業前に `lib/spots.ts` 側を要確認（[[kyounoko-spot-data-audit]]）。
- 残り全国688件（`docs/outreach-full-688.csv`）は、第1〜3波で文面・反応率が固まってから横展開。
