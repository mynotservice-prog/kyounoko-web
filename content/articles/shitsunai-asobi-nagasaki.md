**結論：無料と公式に明記されているのは、大浦児童センター（1階の子育て支援センター「ひなたぼっこ」も無料）。展示を見せながら無料で過ごせるのは長崎市科学館（未就学児は入館無料）。大型遊具でしっかり体を動かすなら、長崎ブリックホール内のピクニックです。**

大浦児童センターと長崎市科学館は、どちらも**対象の子どもは無料**と公式に案内されています。

## 1. 大浦児童センター（1階「ひなたぼっこ」）｜無料

大浦町にある長崎市立の児童センターです。**長崎市公式サイトの児童館一覧に「利用料：無料」と明記**されています。同じ建物の1階には、0〜2歳向けの梅香崎地区子育て支援センター「ひなたぼっこ」があり、運営団体の公式サイトにも**「利用料金　無料」**と明記されています。

| 項目 | 内容 |
|---|---|
| 所在地 | 長崎市大浦町7-2 |
| 児童センター開館 | 平日正午〜午後6時。夏・冬・春休み期間中と土曜は午前9時〜午後6時 |
| 児童センター休館 | 日曜日・祝日・年末年始 |
| 児童センター料金 | **無料** |
| ひなたぼっこ対象 | 就学前（おおむね0〜2歳）の子と保護者 |
| ひなたぼっこ開設 | 午前10時〜午後4時（月〜土。日・祝・お盆8/15・年末年始休） |
| ひなたぼっこ料金 | **無料** |

観光地の大浦・グラバー園エリアに近く、市電「大浦天主堂」電停から徒歩圏です。大きい子は2階以上の児童センター、乳幼児は1階のひなたぼっこ、と年齢で使い分けられます。

詳細は[長崎市公式サイト（児童館・児童センター）](https://www.city.nagasaki.lg.jp/site/e-kao/6412.html)と[ひなたぼっこ運営団体の公式サイト](https://npo-hot.jp/guide/)で確認できます。

## 2. ピクニック（長崎ブリックホール1階）｜大型遊具と人工芝

長崎ブリックホール1階にある淵地区子育て支援センターです。**室内に人工芝と大型遊具、サイバーホイールが常設**と長崎市公式サイトで案内されています。

| 項目 | 内容 |
|---|---|
| 所在地 | 長崎市茂里町2-38 長崎ブリックホール1階 |
| 対象 | 0歳〜年長さんの子と保護者（3歳以上のきょうだいも利用可） |
| 開設 | 午前10時〜午後4時 |
| 休所 | 日曜日・祝日・年末年始 |
| 食事 | 10時〜15時半はいつでも利用可 |

利用料は長崎市公式ページに記載がないため、[長崎市公式サイト](https://www.city.nagasaki.lg.jp/site/e-kao/75547.html)または電話（095-843-3555）で確認してください。ブリックホールは路面電車「松山町」電停・JR浦上駅から歩ける立地です。

## 3. 長崎市科学館｜未就学児（0〜6歳）は無料

油木町にある市立の科学館です。**公式サイトの料金表に「未就学児（0～6歳）は無料」と明記**されています。プラネタリウムと展示室があり、0〜6歳ならどちらも無料で利用できます。

| 項目 | 内容 |
|---|---|
| 所在地 | 長崎市油木町7番2号 |
| 開館 | 9:30〜17:00 |
| 休館 | 月によって異なる（公式サイトの休館日カレンダーで要確認） |
| 未就学児（0〜6歳） | **無料** |
| 子供（小中高） | 展示室310円・プラネタリウム360円・セット券600円（税込） |
| 大人（15歳以上） | 展示室610円・プラネタリウム720円・セット券1,200円（税込） |

雨の日にしっかり時間を潰したいときの候補です。詳しくは[長崎市科学館公式サイト（利用案内）](https://www.nagasaki-kagakukan.jp/guide/)で確認してください。

## 4. もりのクレヨン（上長崎地区子育て支援センター）

片淵の上長崎地区ふれあいセンター1階にある子育て支援センターです。**対象は3歳以下の子と保護者（妊娠中から利用可）**と長崎市公式サイトで案内されています。世界のおもちゃに囲まれて親子で過ごせる場所です。

| 項目 | 内容 |
|---|---|
| 所在地 | 長崎市片淵1丁目13-13 上長崎地区ふれあいセンター1階 |
| 対象 | 3歳以下の子と保護者（妊娠中から利用可） |
| 開設 | 日曜日〜金曜日（土曜日・祝日・年末年始は休館） |
| 開設時間 | 10:00〜16:00 |
| 運営 | 一般社団法人トムテのおもちゃ箱 |

**開所日が「日〜金」と、他の支援センターの多くが休みにする日曜日に開いているのが特徴**です。土曜が休みなので週末に行くなら日曜を選ぶ必要があります。

利用料は長崎市公式ページに記載がないため、[長崎市公式サイト](https://www.city.nagasaki.lg.jp/site/e-kao/76277.html)または電話（095-824-9211）で確認してください。

## 年齢別の選び方

| 年齢 | 第一候補 | 理由 |
|---|---|---|
| **0〜1歳** | ひなたぼっこ（大浦児童センター1階） | 0〜2歳向け・無料 |
| **2〜3歳** | ピクニック（長崎ブリックホール）／もりのクレヨン | ピクニックは大型遊具・人工芝。もりのクレヨンは3歳以下対象 |
| **4〜6歳** | 長崎市科学館 | 未就学児（0〜6歳）は入館無料 |

## 予算で選ぶ

- **0円で済ませたい** → 大浦児童センター・ひなたぼっこ（無料と公式明記）、長崎市科学館（未就学児は無料）
- **料金要確認だが立ち寄りやすい** → ピクニック（大型遊具・人工芝）、もりのクレヨン（3歳以下向け）

## 雨の日のコツ

- **大浦エリアは児童センターとひなたぼっこがはしごできる**：同じ建物で年齢に応じて使い分けられます
- **長崎市科学館は休館日が月替わり**：曜日固定ではないので、行く前に公式サイトの休館日カレンダーを確認
- **日曜に開いているのはもりのクレヨン**：ひなたぼっこ・ピクニックは日曜休みですが、もりのクレヨンは日〜金開設（土曜休み）です
- **ブリックホールは公演日に混みやすい**：ピクニックは同じ建物にホールがあるため、イベント日は駐車場が混むことがあります

## よくある質問

### Q. 長崎市で無料の室内遊び場は？

A. **大浦児童センターと1階の「ひなたぼっこ」が無料**と公式に案内されています。**長崎市科学館も未就学児（0〜6歳）は無料**です。ピクニック・もりのクレヨンは料金の記載が公式ページになく、確認が必要です。

### Q. 0歳を連れて行けるところは？

A. **ひなたぼっこ**は0〜2歳向けで無料です。**もりのクレヨン**も3歳以下（妊娠中から）が対象で、日曜も開いています。

### Q. 長崎市にキドキド（ボーネルンド）はある？

A. **室内遊び場「キドキド」の公式店舗一覧に長崎県の店舗はありません。**みらい長崎ココウォークに以前あった「ボーネルンドキドキドランド」は、2023年12月のリニューアルで「おもちゃのあおき」に替わっています。

### Q. 長崎市にファンタジーキッズリゾートはある？

A. **ありません。**公式サイトの店舗一覧では、九州は福岡東（イオン福岡東ショッピングセンター）の1店舗のみです。
