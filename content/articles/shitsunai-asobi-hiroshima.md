## 1. 5-Daysこども文化科学館｜入館無料・原爆ドーム前電停から約300m

広島市こども文化科学館の愛称です。**公式サイトの利用案内に「入館料　無料」と明記**されています。プラネタリウムも幼児・小中学生は無料で、有料になるのは高校生以上です。

| 項目 | 内容 |
|---|---|
| 所在地 | 広島市中区基町5番83号 |
| 開館時間 | 9:00〜17:00 |
| 休館日 | 月曜日（祝日をのぞく）、祝日の翌平日（土日祝は開館）、12月29日〜1月3日、臨時休館あり |
| 入館料 | **無料** |
| プラネタリウム | 幼児・小中学生無料、大人510円、高校生・シニア（65歳以上）250円（いずれも個人） |
| 駐車場 | なし（近隣の有料駐車場を利用） |

1階の「天空の夢の国」は、科学の基本的なしくみを遊びながら体験できる展示のフロアです。大型のボールコースター「ボールの旅」や、中に入って“しかけ”を試す「たんけんとりで」もあります。2階の「ガリバーランド」では、新幹線から路面電車までの鉄道模型を、自分でボリュームを操作して走らせることができます。

プラネタリウムは無料の人もチケットが必要で、午前9時から当日の全投影分を1階で発券します。投影時刻は平日（火〜金）が11:00・13:00・14:00・15:00、土日祝と春夏冬休みの平日は10:00から16:00まで1日6回です。

**建物の耐震改修と展示リニューアルのため、2027年3月31日をもって臨時休館**し、休館は2027年4月1日から令和11年度中のリニューアルオープンまでと公式サイトのお知らせに記載されています。この冬は開館している予定です。

広電「原爆ドーム前」電停から約300メートル。詳細は[公式サイトの利用案内](https://www.pyonta.city.hiroshima.jp/guide/base/)で確認できます。

## 2. ヌマジ交通ミュージアム（広島市交通科学館）｜幼児〜中学生は観覧無料・無料駐車場78台

アストラムライン長楽寺駅が最寄りの、乗り物と交通の博物館です。**1階と屋外広場は無料、2〜4階の展示室は幼児〜中学生が無料**と公式サイトに明記されています。

| 項目 | 内容 |
|---|---|
| 所在地 | 広島市安佐南区長楽寺2-12-2 |
| 開館時間 | 9:00〜17:00（展示室への入場は16:30まで） |
| 休館日 | 月曜日（祝日の場合は開館）、祝日の翌平日、年末年始（12月29日〜1月3日）ほか |
| 観覧料（2〜4階の展示室） | 大人510円、高校生・シニア（65歳以上）250円、**幼児〜中学生無料** |
| 1階・屋外広場 | 無料 |
| 駐車場 | **あり（無料・78台）**。土日祝の催し物開催日は満車になることも多いと公式FAQに記載 |

3・4階には直径20メートルの巨大な交通ジオラマ「ビークルシティ」があり、ところどころのスイッチやレバーを操作すると街のなにかが動きます。2階には古今東西の乗り物模型（約2,800点所蔵）や、電車の運転・自転車・飛行のシミュレーターがあります。1階のライブラリーでは乗り物や交通がテーマの本・ビデオ約1万点を自由に閲覧できます（貸し出しはなし）。

公式FAQには、**ベビーカーの貸出あり（台数に限りあり）、おむつ替えスペースは各階トイレ内、授乳室は1階（受付に声かけ）**と記載されています。食べ物は1階のガイダンスコーナー・屋外ベンチなどで可、2階以上の展示室内では食事はできません。屋外の「おもしろ自転車」（100円・30分）は天候で中止になることがあります。

詳細は[公式サイトのご利用案内](https://www.vehicle.city.hiroshima.jp/guide/)と[よくある質問](https://www.vehicle.city.hiroshima.jp/guide/question_and_answer/)で確認できます。

## 3. 広島市の児童館｜市内124館・無料（未就学児は保護者同伴）

広島市が設置・運営する児童館で、**市の公式ページに「児童館の利用は無料です」と明記**されています。小・中学生のほか、**乳幼児とその保護者も利用対象**です。

| 項目 | 内容 |
|---|---|
| 数 | 市内140小学校区のうち124学区に124館（令和8年5月1日時点） |
| 対象 | 小・中学生、乳幼児とその保護者（乳幼児は保護者の同伴が必須） |
| 料金 | **無料** |
| 開館時間 | 平日13:00〜18:30（長期休業中など学校休業日は12:00〜）、土曜10:00〜17:00 |
| 休館日 | 日曜日、国民の祝日、年末年始（12月29日〜翌年1月3日） |
| 駐車場 | なし（車で来館しないよう市が案内） |

遊戯室にはバスケットゴール・肋木・雲梯などがあります（整備時期によって構造・設備が異なる場合あり）。**小・中学生以外の利用者が使える時間帯は館ごとに違う**ため、行く前に利用する児童館に確認してください。未就学児は保護者同伴なので事前の利用登録は不要で、来館時に利用者名簿へ氏名などを記入します。

年末年始のほか、**冬季の小学校一斉閉庁日に休館する場合がある**と市のページに記載されています。各館の所在地・電話番号は[広島市の児童館一覧](https://www.city.hiroshima.lg.jp/living/kosodate/1021263/1017021.html)、利用のルールは[児童館について](https://www.city.hiroshima.lg.jp/living/kosodate/1021263/1017020.html)で確認できます。

## 4. つどいの広場「げんキッズ」（健康科学館内）｜無料・申込不要・日曜も開設

広島市健康づくりセンター健康科学館の中にある、市の常設子育てオープンスペースです。**「事前の申し込みや利用料は必要ありません」と広島市の公式ページに明記**されています。

| 項目 | 内容 |
|---|---|
| 所在地 | 広島市中区千田町三丁目8-6 健康科学館内 |
| 対象 | 0歳〜未就学児と保護者（小学生は遠慮するよう案内あり） |
| 料金 | **無料** |
| 利用時間 | 10:00〜15:00 |
| 休み | 月曜日（祝日の場合は開館）、祝日の翌日（土・日にあたる場合は開館）、年末年始、臨時休館あり |
| 設備 | 授乳スペースあり |

市内8区の常設オープンスペースのうち、**日曜日に開いているのはここだけ**です（ほかの7か所は月〜金曜の開設）。おもちゃや遊具があり、子どもと一緒にそれぞれのペースで遊べる場所です。発熱・発疹など体調の悪い人は利用できず、入室前に手指の消毒・検温があります。**おやつ・食事はできない**ため、水やお茶を持参します。混雑時は入場制限の場合があります。

同じ建物の健康科学館（展示ホール）は中学生以下が無料（大人370円、高校生・65歳以上180円）で、休館日は12月28日〜1月4日です。**健康科学館は2027年3月31日に閉館**しますが、げんキッズは閉館後も同じ建物内で引き続き実施すると広島市の公式ページに記載されています。

詳細は[健康科学館のげんキッズのページ](http://www.kenkou.city.hiroshima.jp/activities/kidz/index.html)と[広島市の公式ページ](https://www.city.hiroshima.lg.jp/living/kosodate/1021253/1025911/1003502.html)で確認できます。

## 5. 子育てオープンスペースつばさ｜紙屋町・1日100円・土曜も開設

紙屋町ガレリア3階にある、広島市の公募型常設オープンスペースです（運営はこども子育て応援ひろしま労働者協同組合）。

| 項目 | 内容 |
|---|---|
| 所在地 | 広島市中区紙屋町1-6-1 紙屋町ガレリア3階 |
| 対象 | 0歳〜就学前の乳幼児（と保護者） |
| 利用時間 | 10:00〜16:00 |
| 料金 | **1日100円（1家族）**、利用登録の年度会費200円（1家族） |
| 休み | 日曜・祝日、年末年始 他 |

親子でゆっくり過ごしたり、親同士でおしゃべりしたりできる場所で、毎月のお誕生日会や、専門家による子育て情報の講習会などの行事もあります。**事前予約制の一時預かり**も行っています（市の一覧では300円〜/30分）。お子さんとその保護者でない人だけの入室はできません。

**土曜日も開いている**のが、月〜金曜開設の区の常設オープンスペースとの違いです。詳細は[つばさの公式ページ](https://os-tsubasa.kosodateroukyou.or.jp/os/)で確認できます。

## 6. ピュアハートキッズランド 広島アルパーク店｜0・1歳無料の屋内パーク

西区草津新町の商業施設アルパーク（東棟）にある、完全会員制の室内遊び場です。広島市内で遊具のある屋内パークならここが軸になります。

| 項目 | 内容 |
|---|---|
| 所在地 | 広島市西区草津新町2-26-1 アルパーク東棟4F |
| 対象 | 小学生以下の子どもと保護者（中学生〜19才は保護者同伴でも入場不可） |
| 営業時間 | 10:00〜19:00（最終入場18:30）※営業時間が異なる場合があると記載 |
| 定休日 | 店舗（アルパーク）に準ずる |
| 会員証 | 年会費330円（1家族1枚・発行時に本人確認書類が必要） |

**入場料（税込・1人あたり）**は、ピュアキッズフリー（1日遊び放題）が**平日1,200円・休日1,500円**（大人2人目以降は1,100円）、ベーシックプラン（時間制）が**30分ごとに平日400円・休日500円**です。**0才・1才の子どもは無料**（母子手帳や保険証など年齢確認できるものを提示）と公式サイトに明記されています。子どもだけ・大人だけの入場はできません。11月〜1月のうち休日料金になる日は、[公式のお知らせ](https://www.nikke-purekids.jp/news/45711/)のカレンダーで確認できます。

館内には、ボールプールや船の滑り台がある「キッズラグーン」、ジップラインの「ターザンロープ」、抗菌の白い砂の「サンドパーク」、プラレールの「ジオラマパーク」などがあります。**24か月までの赤ちゃんと保護者専用の「ベビーパーク」**、個室の授乳スペースと調乳スペース（入室は女性限定）、おむつ替え室もあります。ピクニックカフェは飲食物の持ち込みが可能です。

JR山陽本線「新井口駅」・広電宮島線「商工センター入口駅」からそれぞれ徒歩約3分。車の場合は入庫から4時間無料、ピュアキッズ利用でさらに4時間無料（合計8時間。北棟は合計6時間まで）です。年末年始の営業は、[公式の店舗ページ](https://www.nikke-purekids.jp/shop/hiroshima/)で確認してください。

## 寒い日・雨の日のコツ

- **日曜は児童館とつばさが休み**：日曜に無料で遊ぶなら、こども文化科学館・ヌマジ交通ミュージアム・げんキッズ（いずれも月曜休み）が候補です
- **年末年始は12月29日〜1月3日の休館が多い**：こども文化科学館・ヌマジ交通ミュージアム・児童館は12月29日〜1月3日が休館。健康科学館は12月28日〜1月4日が休館です
- **駐車場はヌマジとアルパークが公式に記載あり**：ヌマジは無料駐車場78台、アルパークは入庫4時間無料（ピュアキッズ利用で合計8時間）。こども文化科学館と児童館は駐車場がありません
- **げんキッズは飲食不可**：おやつ・食事はできないので、水やお茶だけ持っていきます。食事を挟むなら、持ち込み可のカフェがあるピュアハートキッズランドか、1階で食べられるヌマジが組み合わせやすい
- **こども文化科学館は2027年3月末まで**：2027年4月1日から令和11年度中のリニューアルオープンまで臨時休館します

## よくある質問

### Q. 広島市で無料の室内遊び場は？

A. **5-Daysこども文化科学館（入館無料）、市立の児童館（無料）、つどいの広場「げんキッズ」（無料）**が、公式に無料と明記されています。ヌマジ交通ミュージアムも1階・屋外広場は無料で、2〜4階の展示室は幼児〜中学生が無料（大人は510円）です。

### Q. 0歳を連れて行けるところは？

A. **げんキッズ（0歳〜未就学児・授乳スペースあり）、子育てオープンスペースつばさ（0歳〜就学前）**が0歳から対象です。**ピュアハートキッズランドは0・1歳が無料**で、24か月までの赤ちゃん専用のベビーパークと授乳室があります。ヌマジ交通ミュージアムも授乳室（1階）とベビーカーの貸出があります。

### Q. 日曜日に開いているところは？

A. **こども文化科学館・ヌマジ交通ミュージアム・げんキッズ・ピュアハートキッズランド**です。児童館とつばさは日曜休みです。

### Q. 年末年始に開いているところは？

A. こども文化科学館・ヌマジ交通ミュージアム・児童館は**12月29日〜1月3日が休館**、げんキッズとつばさも年末年始は休みです（日付は公式に記載がありません）。ピュアハートキッズランドの年末年始の営業は、公式サイトで確認してください。

### Q. こども文化科学館はいつまで行ける？

A. 公式サイトのお知らせでは、**2027年3月31日をもって臨時休館**し、2027年4月1日から令和11年度中のリニューアルオープンまで休館すると記載されています。この冬（2026〜2027年）は通常の休館日以外は開館の予定です。
