## 結論

| 形態 | 開始時期 |
| --- | --- |
| くたくたに煮て潰す | **5〜6ヶ月（離乳食初期）** |
| 細かく刻む | 7〜8ヶ月 |
| 1〜2cmに切る | 9〜11ヶ月 |
| すする・通常 | 1歳半〜 |

## なぜ離乳食初期からOK？

- 米に次いで離乳食に取り入れやすい
- アレルゲン（小麦）の確認のため早めに少量試す
- 消化しやすく、エネルギー源として優秀
- ただし**塩分処理は必須**

## 月齢別の進め方

### 5〜6ヶ月（離乳食初期）

- くたくたに煮て塩抜き
- すりつぶしてペースト状
- 小さじ1から
- 必ず**茹で汁を捨てる**

### 7〜8ヶ月（離乳食中期）

- 5mm角に細かく刻む
- 軟らかく煮る
- だしで風味付け

### 9〜11ヶ月（離乳食後期）

- 1〜2cmに切る
- 手づかみ食べデビューにも
- かけうどん風（薄味）

### 1〜1歳半（完了期）

- 3〜4cmに
- 釜揚げ・かけうどん
- 大人より薄い味

### 1歳半〜

- すする練習
- 通常の食べ方に近づける
- お店デビュー可

## 量の目安

| 年齢 | 1食の目安（茹で後） |
| --- | --- |
| 5〜6ヶ月 | 小さじ1〜2 |
| 7〜8ヶ月 | 30〜40g |
| 9〜11ヶ月 | 50〜80g |
| 1歳〜 | 80〜100g |
| 2〜3歳 | 100〜120g |
| 4〜5歳 | 150〜180g |

## 塩分処理（最重要）

### なぜ必要？

- 乾麺・茹で麺ともに塩を含む
- 子どもの1日塩分目安は1〜3g
- うどん1人前の麺自体で1g前後

### やり方

1. たっぷりのお湯で茹でる
2. 茹でたら水でしっかり流す
3. 別の出汁で温め直す
4. つけだしも薄める

### 出汁のコツ

- 昆布・かつおの出汁を薄めて
- 醤油は数滴〜小さじ1/4
- 大人の半分以下の濃さで

## 小麦アレルギー対策

### 初めての与え方

- 平日午前中
- ごく少量（小さじ1）から
- 単独で
- 既知の食材と組み合わせない

### 症状

- 口の周りの赤み
- 蕁麻疹
- 嘔吐・下痢
- 呼吸困難

→ 出たら即受診。

### 米粉うどんという選択肢

- 小麦アレルギーがある子に
- 風味は近いが食感がやや異なる
- 米粉100%で安心

## 注意点・避けたい場面

- 必ず塩抜き
- 長い麺は気管に入りやすい→短く切る
- 熱々で食べさせない（火傷）
- すすり方を教えるまでは噛んで食べる
- カップうどんは塩分高すぎ
- インスタントは4歳まで控える

## お店デビューのコツ

- セルフうどんチェーン（はなまる・丸亀）が便利
- かけうどん（小）から
- 取り分けOKな店
- 子ども用器を借りる
- ハサミで麺を短く

## 我が家のリアル

息子5ヶ月半でうどん粥デビュー。たっぷり茹でて水で流して、すりつぶしてペースト。問題なく完食。それから離乳食の定番に。

1歳半で丸亀デビュー。かけうどん（小）を取り分け、ハサミで短く切って。ちょこんと座って一生懸命食べる姿が可愛かったです。2歳になる頃にはすするコツも覚えました。

我が家は冷凍うどんを常備。お腹空いた時の即席ランチに便利。「うどんあるよ」がママのお守り言葉になっています。

## まとめ

- 5〜6ヶ月から離乳食でOK
- 必ず塩抜き
- 月齢に応じて長さ・固さを調整
- 小麦アレルギーに注意
- お店は1歳半以降が安心
- セルフうどん店が取り分けに便利
