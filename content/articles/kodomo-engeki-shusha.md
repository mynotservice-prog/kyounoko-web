## 結論（時期・必要なもの）

子供の演劇出演は**「園や学校の発表会」「地域の子供劇団」「テレビ・舞台のオーディション」**の3パターン。本人のやる気と継続力が前提で、**親は送迎・台本暗記サポート・メンタルケア**が主な役割。**記念撮影と動画は必ず残す**、それが家族の宝物になります。

- 向いている人：子が演じることに興味、地域劇団に参加させたい
- 向いていない人：本人にやる気がない（強制NG）

## いつやる？目安

### 演劇に出会うタイミング

- **3〜4歳**：園のお遊戯会で初体験
- **5〜6歳**：本格的な役どころに挑戦
- **小学生**：学芸会・地域劇団
- **オーディション**：年齢制限ありの劇団が多い

### 関わり方の段階

| 段階 | 内容 |
| --- | --- |
| 初級 | 園の発表会 |
| 中級 | 地域の子供劇団（月1〜2回稽古） |
| 上級 | 劇団員養成所、舞台オーディション |
| プロ | テレビ・映画のオーディション |

## 準備するもの

### オーディション参加の場合

| アイテム | 詳細 |
| --- | --- |
| 履歴書（写真付き） | 上半身＋全身写真 |
| 本人のプロフィール | 趣味・特技・好きなもの |
| 動画自己PR | 30秒〜1分の自己紹介 |
| 親の連絡先 | 緊急対応用 |

### 稽古に必要なもの

- **台本**（コピー保管）
- **動きやすい服装**（ジャージ・Tシャツ）
- **筆記用具**（ト書き書き込み用）
- **水筒・タオル**
- **着替え・汗拭き**

## 当日の流れ

| 時間 | 内容 |
| --- | --- |
| 朝 | 早めの朝食、衣装着替え |
| 出発 | 余裕を持って |
| 楽屋入り | 化粧・最終確認 |
| 開演前 | 緊張ケア |
| 本番 | 客席で見守り |
| 終演 | 達成感を共有 |
| 帰宅 | ねぎらい、好きな食事 |

## 服装のポイント

### 稽古時

- **動きやすいジャージ・Tシャツ**
- **靴下＋スリッパ持参**（多くの稽古場が土足禁止）
- **長い髪はゴム必須**

### 本番衣装

- **指定衣装**が大半
- **インナー（肌着・タイツ）**は自前
- **靴・履物**は指定確認

## 写真撮影のコツ

### 撮影可能か事前確認

- **稽古中は撮影禁止**が多い
- **本番中は劇場ルール厳守**
- **公式写真サービス**を使う団体も

### 撮れる範囲で残す

1. **稽古帰りの自然な表情**
2. **衣装合わせ**
3. **楽屋入り**
4. **本番後の達成感**
5. **共演者との集合写真**

### 動画撮影

- 公式DVD・動画を購入する形が多い
- 個人撮影禁止の場所もあり、要確認

## 親のサポート

### できること

- **送迎**（稽古場は遠いことが多い）
- **台本暗記の相手**（読み合わせ）
- **栄養・睡眠管理**
- **メンタルケア**：緊張・スランプ時の声かけ

### やりすぎNG

- 「もっと上手に」のプレッシャー
- 他の子と比較
- 親が前のめりになる
- スタッフ・他の親への過干渉

### 本人のやる気を尊重

- 「やめたい」と言ったら受け止める
- 続けるか判断する時間を与える
- 親の願望を押し付けない

## オーディションの探し方

### 主な経路

- **児童劇団・養成所サイト**：劇団四季ファミリーミュージカル、てんねん子供劇団など
- **キッズタレント事務所**
- **地域の市民劇団**：気軽に始めやすい
- **学校・園の紹介**

### 注意点

- **高額な入会金・受験料は要警戒**
- **稽古場の見学**は必ず
- **契約書の中身を確認**
- **本人の意思を最優先**

## メンタルケア

### 当日朝

- 「いつも通りで大丈夫」
- 「失敗しても誰も責めない」
- 「楽しんで」

### 終演後

- 「すてきだったよ」
- 反省より達成を称える
- 次回の話は本人に任せる

## 我が家のリアル

長女は**幼稚園のお遊戯会で「おたまじゃくし役」**が演劇デビュー。本人が「もっとやりたい」と言ったので地域の子供劇団に1年通いました。

正直、稽古場の送迎は親の負担が大きく、平日夕方が潰れる覚悟が必要。でも本人が舞台で輝く姿は何物にも代えがたい。

**「やめたい」と言った時はあっさり受け入れた**のがその後の人生で良かったと思います。強制せず、本人のペースで関わることが大切でした。

## まとめ

- 子供の演劇出演は**園・地域・プロ**の3段階
- 親は**送迎・暗記サポート・メンタルケア**
- **強制せず本人のペース**
- 撮影は**ルール厳守**で範囲内で
- **「やめたい」も尊重**
- 思い出を**写真・動画で残す**
