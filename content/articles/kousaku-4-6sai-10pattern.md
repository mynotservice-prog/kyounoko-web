## 結論（先に知りたい人へ）

4〜6歳の工作は、**「ハサミ・ノリ・セロテープ」の3点で完成するもの**に絞るのが正解です。この年齢はアイデアはあるのに手先が追いつかない時期。**親が材料を切っておいて、子どもが組む**分業ができる設計だと、集中30分を超えます。

10パターンすべて家にある材料で成立。**完成品が飾れる・遊べる・あげられる**を条件に選びました。次の100均訪問で買い足せる小物も明記してあります。

- **向いている人**：4〜6歳、自分で作りたい欲が強い、完成品を飾りたい
- **向いていない人**：キレイな見本どおりに作らせたい（この年齢はアレンジが強みです）

## 工作を成功させる3つの条件

### 1. 材料は親が事前に切っておく

牛乳パック・画用紙・段ボール。**直線カットは親がやって**、子どもはノリ付けと組み立てから入る。これだけで4歳でも20分集中します。

### 2. 完成の着地点を最初に決める

「けん玉を作るよ」「カブトだよ」と**ゴール画像を見せる**。自由すぎると手が止まります。迷ったらPinterestで写真1枚だけ検索して見せる。

### 3. 飾る・遊ぶ場所を先に決める

完成したら「玄関に飾ろう」「弟にプレゼントしよう」と出口を先に言う。**作ったあと放置されるとモチベが下がる**ので、飾り場所を約束してから始めます。

## 01 · 紙コップけん玉

**対象**：4〜6歳 / 所要 **15〜20分** / 難易度 ★★ / 手離し度 ★★★

**材料**：紙コップ2個、タコ糸60cm、新聞紙 or アルミホイル（玉用）、セロテープ

**作り方**
1. 紙コップの底同士をテープで貼り合わせる
2. 新聞紙を丸めてアルミホイルで包み、玉にする
3. タコ糸の片端を玉に、もう片端をコップの底にテープ留め
4. シール・マジックで装飾

**完成後**：本当に遊べます。兄弟で対決にすると30分は遊びます。
**飾り場所**：子ども部屋の棚に吊るす。

## 02 · 牛乳パックマラカス

**対象**：4〜6歳 / 所要 **15分** / 難易度 ★★ / 手離し度 ★★★★

**材料**：牛乳パック1本、米 or 小豆 大さじ2、ビニールテープ、シール・マジック

**作り方**
1. 牛乳パックを洗って乾かす（前日準備）
2. 中に米を入れる
3. 口をホチキス＋ビニールテープで厳重に閉じる
4. 絵の具 or マジックで絵を描く

**ポイント**：中身を**米→小豆→ビーズ**で比較すると音の違いが学べて理科っぽい。
**飾り場所**：実際に使う→おもちゃ箱。

## 03 · トイレットペーパーロケット

**対象**：4〜6歳 / 所要 **20分** / 難易度 ★★ / 手離し度 ★★★

**材料**：トイレットペーパーの芯1本、折り紙3枚、テープ

**作り方**
1. 芯を折り紙で巻いて貼る
2. 先端を円錐状に折り紙で作って取り付け
3. 翼を3枚、底に貼り付ける
4. マジックで窓・名前を書く

**発展**：風船を芯に差し込むと**本当に飛びます**。庭・ベランダ推奨（室内は天井NG）。
**飾り場所**：窓辺に並べる。

## 04 · 段ボール迷路

**対象**：5〜6歳 / 所要 **40〜60分** / 難易度 ★★★★ / 手離し度 ★★

**材料**：大きめ段ボール箱のフタ（平面）、細い段ボール or 厚紙を細長く切ったもの（壁用）、ビー玉1個、ボンド

**作り方**
1. 段ボールのフタを平らに置く
2. 細長い段ボールを迷路の壁としてボンドで貼る
3. スタートとゴールを書く
4. ビー玉を転がして遊ぶ

**親の仕事**：段ボールを細く切るところまで。設計は子どもに任せます。
**飾り場所**：リビングで何度も遊べる。兄弟・友達受けも◎。

## 05 · 画用紙お面

**対象**：4〜6歳 / 所要 **20〜30分** / 難易度 ★★ / 手離し度 ★★★

**材料**：画用紙 or 厚紙1枚、輪ゴム or ヒモ、ハサミ、クレヨン

**作り方**
1. 顔の大きさに合わせて画用紙をカット
2. 目の位置に穴を開ける
3. 動物・ヒーローの顔を描く
4. 耳にヒモを付けて完成

**鉄板モチーフ**：恐竜・ライオン・アンパンマン・プリンセス。
**遊び**：お面をつけて**家中で動物園ごっこ**。30分は遊べます。

## 06 · 折り紙カブト／動物

**対象**：4〜6歳 / 所要 **10〜20分** / 難易度 ★★〜★★★ / 手離し度 ★★

**鉄板5種**
1. カブト（男の子に人気）
2. 手裏剣（表裏色違いが映える）
3. つる（6歳から可）
4. 犬・猫の顔（4歳でも可）
5. 箱（実用品）

**ポイント**：YouTubeの**「おりがみくらぶ」**が分かりやすく、親が見ながら横で教えられます。4歳はカブト・犬、5歳は手裏剣、6歳はつるが目安。
**飾り場所**：壁に貼る or カゴに入れる。

## 07 · ペーパークイリング（簡易版）

**対象**：5〜6歳 / 所要 **30〜40分** / 難易度 ★★★ / 手離し度 ★★★

**材料**：折り紙 or 色画用紙を1cm幅に細長く切ったもの20本、ボンド、台紙

**作り方**
1. 細長い紙を**つまようじに巻きつけて**渦巻きにする
2. 端をボンドで留める
3. 台紙に渦巻きを並べて花・動物を作る
4. 全部貼ったら乾かす

**完成品**：額に入れて飾ると**かなり見栄えする**。祖父母プレゼントに最適。

## 08 · 自然物コラージュ（葉・実）

**対象**：4〜6歳 / 所要 **30分（＋散歩）** / 難易度 ★★ / 手離し度 ★★★★

**材料**：散歩で拾った葉・どんぐり・松ぼっくり・石、画用紙、木工ボンド

**作り方**
1. 散歩で材料を10個以上拾う（20分）
2. 画用紙に並べて絵を作る（顔・動物・風景）
3. 位置が決まったらボンドで固定
4. マジックで目・口を書き足す

**季節感**：春は桜の花びら、秋はどんぐり＋紅葉、冬は松ぼっくり。**季節ごとに作って飾り替え**ると家が豊かになります。

## 09 · 石鹸細工（せっけん粘土）

**対象**：5〜6歳 / 所要 **30分（＋乾燥1日）** / 難易度 ★★★ / 手離し度 ★★

**材料**：市販の石鹸粘土（100均・キャンドゥにあり） or 粉石けん＋水、食紅少々

**作り方**
1. 粘土状にこねる
2. 動物・フルーツ型に成形
3. 1日乾かす
4. 実際に手を洗うのに使える

**注意**：目に入ると危険。制作中は**目をこすらない**ルールを徹底。
**飾り場所**：洗面所に置いて**実際に使う**と盛り上がる。

## 10 · ペットボトル風鈴

**対象**：4〜6歳 / 所要 **30分** / 難易度 ★★★ / 手離し度 ★★★

**材料**：500mlペットボトル1本、タコ糸、鈴（100均）、折り紙、シール

**作り方**
1. ペットボトルの底を親が切る（危険なので親が担当）
2. 折り紙・シールで装飾
3. 切り口の下にタコ糸で鈴を吊るす
4. 本体の上に穴を開けて吊り下げ紐を付ける

**完成後**：ベランダ・窓辺に吊るすと風で鳴ります。**夏の工作**として秀逸。
**季節限定感**：4〜9月が活躍期。

### 目的別おすすめ

- **当日で完結したい** → 01・02・03・05・06
- **しっかり取り組む休日** → 04・07・10

## 完成品の見せ場を作る

4〜6歳は**「誰かに見せて褒められる」がエネルギー源**。作品は以下で見せます。

1. **玄関の棚**に1週間飾る → 来客にも見せる
2. **祖父母に写真を送る** → 電話で感想をもらう
3. **保育園の先生に見せる** → 翌日の登園モチベ

作ったまま放置は厳禁。**作る→飾る→褒める**の3点セットで次もやりたくなります。

## よくある質問

### Q. 不器用でうまくできず泣きます

4〜6歳は**手先の発達差が6ヶ月〜1年ある**年齢。難易度★★★以上は一旦保留し、★★までに絞りましょう。「失敗しない工作」を3つクリアしてから次に進むと挫折しません。

### Q. 材料を揃えるのが面倒

**牛乳パック・トイレットペーパー芯・ペットボトル**を各3本キープしておくだけで、10工作のうち6つ回せます。使ったら補充のルーチンを作れば常時ストックできます。

### Q. 完成品が溜まって片付かない

**撮影して捨てる**が結論。写真アルバムを作れば本人も満足します。**飾り期間は1週間**とルール化し、次の新作が来たら前の作品を卒業（撮影→処分）。

### Q. 兄弟（2〜3歳）が邪魔します

下の子には**別の材料（シール・ぬりえ）**を与えて同じテーブルで。または**役割分担**（下：シール貼り担当、上：組み立て担当）で巻き込む。同じ机で違う作業が平和の秘訣です。

### Q. 集中せずすぐ席を離れます

工作は**完成までの時間を最初に伝える**と集中しやすい。「20分で終わるよ」「5ステップあるよ」と数字で見通しを出す。途中で席を離れたら5分休憩→戻ってくるルーチンでOK。
