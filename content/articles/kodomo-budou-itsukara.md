## 結論

| 形態 | 開始時期 |
| --- | --- |
| 皮むき・小さく刻む | **7〜8ヶ月** |
| 皮むき・4等分 | 9〜11ヶ月 |
| 半分にカット | 4歳〜（噛める子） |
| 丸ごと | **5歳以降** |

## なぜ丸ごとは5歳までNG？

- **誤嚥・窒息リスク**：球形＋ツルッとした表面＋適度な硬さで気管に完璧にハマる
- 過去にぶどう・プチトマトでの窒息死亡事故が複数報告
- 消費者庁・日本小児科学会も「ぶどうは丸ごと与えない」と注意喚起
- **4歳以下は特に注意**、5歳までは切る
- **縦に半分または4等分**が安全

## 月齢別の進め方

### 〜6ヶ月

- 与えない

### 7〜8ヶ月

- 皮をむいて細かく刻む（5mm角）
- 種は必ず取る
- すりつぶしてヨーグルトに混ぜても

### 9〜11ヶ月

- 皮をむいて縦に4等分
- 種を取る
- 手づかみ食べデビューにも

### 1〜3歳

- 皮むき・4等分が基本
- 噛む練習に良い

### 4歳〜

- 縦半分まではOKな場合も（よく噛める子）
- それでも丸ごとはNG

### 5歳以降

- 丸ごとOK
- 座って食べる、笑わないなどルールを

## 品種別判断

| 品種 | 特徴 | 注意点 |
| --- | --- | --- |
| 巨峰 | 大粒・皮厚め | 皮むき必須・種あり |
| シャインマスカット | 皮ごと・種なし | 大粒で誤嚥注意 |
| デラウェア | 小粒・種なし | 1粒が小さいので誤嚥危険 |
| ピオーネ | 大粒・種なし | 誤嚥注意 |
| ナガノパープル | 皮ごと・種なし | 誤嚥注意 |
| 干しぶどう | レーズン | 1歳〜・粘り気で歯に注意 |

## デラウェアの落とし穴

- 小粒だから「飲み込みやすそう」と思いがち
- 実は**最も気管にハマりやすいサイズ**
- 房ごと渡すのは絶対NG
- 1粒ずつ取って、半分に切る
- 5歳まで丸ごと飲み込ませない

## 安全な切り方

### 大粒（巨峰・シャインマスカット等）

1. 房から1粒取る
2. 皮をむく（必要に応じて）
3. 縦に半分
4. さらに縦に半分（4等分）

### 小粒（デラウェア）

1. 房から1粒取る
2. 縦半分に切る
3. 大量に与えない

## 皮・種の扱い

### 皮

- 巨峰：必ずむく（1歳まで）/2歳以降は噛みきれれば可
- シャインマスカット：皮ごと食べられるが大粒は4等分
- デラウェア：皮は薄く小粒なのでそのまま可（カット後）

### 種

- 必ず取り除く
- 種なし品種が安心

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 7〜8ヶ月 | 1〜2粒分（刻み） |
| 9〜11ヶ月 | 2〜3粒分（4等分） |
| 1歳 | 3〜5粒（4等分） |
| 2〜3歳 | 5〜7粒（4等分） |
| 4歳 | 5〜10粒 |
| 5歳以降 | 10粒前後 |

## 栄養

- ビタミンB1・B6・C
- カリウム
- ポリフェノール（皮に多い）
- 糖分高めなので食べ過ぎ注意

## アレルギー対策

### ぶどうアレルギー

- 比較的稀
- 口の周りの赤み
- 仮性アレルゲン反応も

### 初めての与え方

- 平日午前中
- 少量
- 単独で

### 症状

- 口の周りの赤み
- 蕁麻疹
- 嘔吐

→ 出たら受診。

## 注意点・避けたい場面

- 房ごと渡さない（1粒ずつ管理）
- 笑いながら・歩きながら食べさせない
- ベビーカー・チャイルドシートで食べさせない
- 兄姉が丸ごと食べていても下の子は切る
- お弁当のフルーツでも丸ごとNG
- 楊枝刺しは逆に危険

## 保育園・お弁当での注意

- 多くの園で「ぶどうは皮むき・カット」がルール
- 家でも同じルールで統一
- お弁当に入れる場合は4等分
- 房から取って渡すのは大人の役目

## 我が家のリアル

息子9ヶ月でシャインマスカット4等分デビュー。「あまい！」と喜んで食べていました。1歳でデラウェアも、ただし必ず半分にカット。

3歳の夏、ぶどう狩りに行きました。「丸ごと食べたい！」と言われましたが「5歳になったらね」と説得。代わりに私が半分に切ってあげると納得して食べていました。

5歳の誕生日、初めての丸ごとシャインマスカット。「噛んで食べる」「笑わない」を約束させてから。感動の表情でした。それでもふざけている時は今でもカットしています。

ぶどうとプチトマトの誤嚥事故ニュースを見るたびに、切る習慣の大切さを再確認しています。

## まとめ

- 丸ごとは5歳以降
- 4等分（縦切り）が基本
- 小粒のデラウェアも油断禁物
- 7〜8ヶ月から刻んで離乳食可
- 種・皮の扱いも品種別に
- お弁当・保育園でも要注意
