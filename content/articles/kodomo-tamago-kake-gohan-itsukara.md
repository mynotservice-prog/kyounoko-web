## 結論｜開始時期

| 形態 | 開始時期 |
| --- | --- |
| 生卵そのまま（本物のTKG） | **3〜5歳以降が安心** |
| 半熟卵かけご飯 | 3歳以降 |
| 温泉卵かけご飯 | 2〜3歳以降 |
| 完全加熱卵かけご飯（卵とじ風） | 1歳〜 |
| 蒸し卵ご飯 | 7〜8ヶ月〜 |

## なぜ生卵は3歳までNG？

- **サルモネラ菌のリスク**：殻や卵白に付着している可能性
- 抵抗力が未熟な乳幼児は感染すると重症化しやすい
- 高熱・激しい下痢・嘔吐・脱水を起こす
- 3歳未満は腸内環境が整っておらず特に注意
- 日本の卵は衛生管理が世界トップレベルだが、リスクはゼロではない
- 厚生労働省も「乳幼児には生卵を控える」と指針

## 月齢別の進め方

### 〜6ヶ月

- 卵そのものをまだ与えない
- 母乳・ミルク・離乳食初期に集中

### 7〜8ヶ月（卵黄スタート期）

- 完全加熱の卵黄からスタート
- 固ゆで卵黄を裏ごししてお粥に少量
- 「卵かけご飯」風として小さじ1から

### 9〜11ヶ月

- 全卵（卵白）も加熱して開始
- スクランブルエッグをご飯に混ぜる
- 卵とじご飯（しっかり火を通す）

### 1〜1歳半

- 完全加熱の卵とじご飯OK
- 「うちのTKG」として加熱版を提供
- 半熟・生卵はまだNG

### 2〜3歳

- 温泉卵ご飯を慎重に試せる（新鮮卵のみ）
- 半熟はまだ避けたい
- アレルギーなければ全卵自由

### 3〜5歳

- 半熟卵かけご飯を少しずつ
- 生卵は新鮮なもの限定で慎重に
- 体調不良時は避ける

### 5歳以降

- 大人と同じ生卵TKGも可（新鮮卵限定）
- ただし夏場や体調不良時は加熱推奨

## 与え方のコツ

### 加熱版TKGレシピ

- 温かいご飯に溶き卵を回しかけ、よく混ぜる
- 余熱だけでは不十分なのでレンジ20〜30秒
- 黄身も白身も完全に火が通る状態に
- しょうゆ少量＋かつおぶしで風味UP

### 半加熱（2〜3歳〜）

- 温泉卵（70℃で30分加熱されたもの）を使う
- 市販品は管理されているので比較的安心
- 自家製は温度管理が難しいので市販を

### 生卵デビュー（3歳〜慎重に）

- パック表記の賞味期限内、できれば購入後3日以内
- ヒビ割れがないもの
- 冷蔵庫で保管していたもの
- 殻を割る前に流水で洗う
- 割ったらすぐ食べる

## サルモネラ対策

### 新鮮卵の選び方

- 賞味期限が長く残っているもの
- パックにヒビがないもの
- 冷蔵保管されているもの（常温販売は避ける）
- 信頼できるメーカー
- できれば「生食用」表記のもの（日本独自基準）

### 取り扱いの注意

- 殻に触れた手で他の食材を触らない
- 殻を割ったらすぐ調理
- 割った卵を常温放置しない
- まな板・包丁を分ける
- 余ったら必ず冷蔵、当日中に

### サルモネラ症状

- 食べてから6〜48時間後に発症
- 発熱・腹痛・激しい下痢・嘔吐
- 子どもは脱水を起こしやすい
- 高熱や血便があれば即受診

## アレルギー対策

### 卵アレルギー

- 三大食物アレルギーの一つ
- 卵白に多く含まれるオボムコイドが原因
- 加熱でアレルゲン性が低下する
- 生卵は加熱卵より反応が出やすい
- 卵黄→全卵加熱→半熟→生の順に試す

### 初めての時

- 加熱卵が問題なくても、半熟・生は別物として慎重に
- 平日午前、病院が開いている時間に
- 少量から（小さじ1）
- 異変があれば即受診

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 7〜8ヶ月（加熱卵黄） | 卵黄1/3個 |
| 9〜11ヶ月（加熱全卵） | 全卵1/3個 |
| 1〜2歳（加熱TKG） | 全卵1/2個 |
| 3〜5歳 | 全卵1個 |
| 6歳〜 | 全卵1〜2個 |

## 注意点・避けたい場面

- 夏場（6〜9月）の生卵は特に注意
- 体調不良時は加熱版で
- 保育園・幼稚園では生卵NGがほとんど
- 旅行先・外食では避ける
- 賞味期限切れは加熱しても廃棄

## 我が家のリアル

息子8ヶ月で固ゆで卵黄をご飯に混ぜたのが「初TKG（風）」。1歳から完全加熱の卵とじご飯を毎朝のように。「黄色いご飯〜」と喜んで食べました。

3歳の時、夫が普通に生卵かけご飯を食べていて「ボクも！」と要求。「もう少し大きくなったらね」と説明し、温泉卵で代用。4歳になって新鮮卵限定で初TKGデビュー。今ではすっかり朝の定番です。

ただし夏場と体調が怪しい時は今でも加熱版に切り替えています。

## まとめ

- 生卵TKGは3〜5歳以降が安心
- 加熱版なら1歳から楽しめる
- サルモネラ対策が最重要
- 新鮮な国産卵を選ぶ
- 殻を割ったらすぐ食べる
- 夏場・体調不良時は加熱を
