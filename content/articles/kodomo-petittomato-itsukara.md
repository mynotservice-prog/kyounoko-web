## 結論

| 形態 | 開始時期 |
| --- | --- |
| 皮むき・小さく刻む | **9〜11ヶ月** |
| 4等分（縦に切る） | 1歳〜 |
| 半分に切る | 4歳〜（よく噛める子） |
| 丸ごと | **5歳以降** |

## なぜ丸ごとは5歳までNG？

- **誤嚥・窒息リスク**：球形＋ツルッとした表面で気管に入りやすい
- 消費者庁・日本小児科学会も「ミニトマトは丸ごと与えない」と注意喚起
- 過去に窒息事故の死亡例あり
- **4歳以下は特に注意**、5歳までは切ることが推奨
- 縦に切る（半分ではなく4等分）のが安全

## 月齢別の進め方

### 〜8ヶ月

- 与えない
- 普通のトマトをすりおろし・湯むきで離乳食に

### 9〜11ヶ月

- 皮をむいて細かく刻む
- 種は取り除く
- 5mm角

### 1歳〜1歳半

- 皮をむいて4等分（縦）
- 種は気になれば取る
- 弁当には入れない

### 1歳半〜3歳

- 4等分が基本
- 皮はむかなくても可（噛みきれれば）

### 4歳〜

- 縦半分まではOKな場合も
- ただし丸ごとはまだNG
- お弁当では半分以下に

### 5歳以降

- 丸ごとOK
- でも座って食べる、笑わないなど注意

## 安全な切り方

### 推奨：縦に4等分

1. ヘタを取る
2. 縦に半分に切る
3. さらに縦に半分に切る
4. 4等分の細長い形に

### NG：横半分

- 表面が滑らかで気管に入りやすい
- 半分でも誤嚥事故報告あり

### NG：丸ごと（5歳まで）

- 球形は最も危険
- 「赤くてかわいい」が事故の元

## 皮・種・ヘタの扱い

### 皮

- 9〜11ヶ月：湯むき推奨
- 1歳〜：気になれば湯むき
- 2歳〜：そのままで可（噛みきれれば）

### 種

- 1歳までは取り除くと安心
- 1歳以降は気にしなくてOK
- アレルギー関連ではない

### ヘタ

- 必ず取る
- 雑菌が付きやすい
- 苦味の元

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 9〜11ヶ月 | 1個分（皮むき・刻む） |
| 1歳 | 2〜3個（4等分） |
| 2〜3歳 | 3〜5個（4等分） |
| 4歳 | 5〜7個 |
| 5歳以降 | 5〜10個 |

## お弁当での注意（最重要）

- お弁当のプチトマトは特に危険
- 保育園・幼稚園では4等分に
- 「彩りで丸ごと」は5歳までNG
- 切ったプチトマトはお弁当カップに
- 楊枝で刺すと逆に危険
- 保冷剤と一緒に（夏は傷みやすい）

### 保育園に確認

- 「プチトマト丸ごとOKか」必ず聞く
- 多くの園では年中までは切って提供
- 家でも同じルールに

## 栄養

- ビタミンC・E・カロテン
- リコピン（加熱で吸収UP）
- 食物繊維
- 通常のトマトより栄養価が高め

## アレルギー対策

### トマトアレルギー

- 比較的稀
- 口の周りが赤くなる（接触性）
- 仮性アレルゲン（ヒスタミン様）の影響もあり

### 症状

- 口の周りの赤み
- 蕁麻疹
- 嘔吐

→ 出たら受診。

## 注意点・避けたい場面

- 笑いながら・歩きながら食べさせない
- 寝転がって食べない
- 兄姉が丸ごと食べていても下の子は切る
- ベビーカー移動中は食べさせない
- 食事中は座ってもらう
- 楊枝刺しは逆に危険

## 我が家のリアル

息子1歳でプチトマト4等分デビュー。最初は皮を嫌がりましたが、今は大好物。

保育園のお弁当で「丸ごとプチトマト」を見て驚き。先生に確認したら「年少からは丸ごと提供」とのこと。我が家は5歳まで4等分継続のお願いをしました。

5歳の誕生日に「今日から丸ごとOK！」と宣言。「これか〜」と感動していました。それでも食事中はおふざけ厳禁ルール。窒息事故のニュースを見るたびに、切ることの重要性を実感します。

## まとめ

- 丸ごとは5歳以降
- 4等分（縦切り）が基本
- 横半分は危険なので避ける
- 9〜11ヶ月から皮むき刻みで
- お弁当・保育園にも要注意
- 笑いながら食べない
