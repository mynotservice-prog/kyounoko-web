## 結論（時期・必要なもの）

保育園選びは**「認可優先＋認可外併願」**が鉄則。**生後6か月の妊娠中から動き出し、見学5〜10園・申込10月**が一般的。**保育時間・通園距離・点数・園の雰囲気**の4軸で選び、**第1〜5希望まで提出**しましょう。地域差が大きいので**自治体ルールを必ず確認**。

- 向いている人：共働き家庭、来年度入園希望
- 向いていない人：幼稚園希望（[幼稚園 選び方](/article/youchien-erabikata)へ）

## いつやる？目安

### 年間スケジュール（4月入園の場合）

| 時期 | やること |
| --- | --- |
| 妊娠中〜出産後 | 自治体ルール把握 |
| 出産後すぐ | 認可・認可外リストアップ |
| 6〜9月 | 見学開始 |
| 10〜11月 | 認可申込（自治体による） |
| 12〜1月 | 内定通知 |
| 2月 | 認可外もキープ |
| 3月 | 入園説明会、グッズ準備 |
| 4月 | 慣らし保育→本格スタート |

### 0歳児・1歳児の競争率

- **0歳児（4月入園）**：比較的入りやすい
- **1歳児（4月入園）**：最激戦
- **年度途中**：欠員のみ、激戦

> ※地域差大：**都心部は1歳児入園待機児童多数**、**地方は希望園に入れる**ことも。自治体の保活難易度マップ要確認。

## 認可・認可外・小規模の違い

| タイプ | 特徴 | 入園基準 |
| --- | --- | --- |
| 認可保育所 | 国基準、保育料は所得割 | 点数審査 |
| 認可外（無認可） | 独自基準、料金は高め | 先着順 |
| 認証保育所（東京） | 都基準、認可と認可外の中間 | 先着順 |
| 小規模保育（A/B型） | 0-2歳児限定、19人以下 | 点数審査 |
| 企業主導型 | 企業が運営、地域枠あり | 各園判断 |
| 認定こども園 | 幼稚園＋保育園機能 | 認定区分 |

## 点数（指数）の仕組み

### 基本指数

- **就労状況**：正社員フルタイム＞短時間＞自営業
- **両親の点数を合算**
- **同点の場合は調整指数で順位付け**

### 調整指数の例

- ひとり親家庭：+◯点
- 兄弟同園希望：+◯点
- 認可外通園実績：+◯点
- 育休中復職予定：+◯点

> ※自治体ごとに大きく異なる。**区役所で点数試算**してもらうと正確。

## 当日の流れ（見学日）

| 時間 | 内容 |
| --- | --- |
| 出発前 | チェックリスト準備 |
| 到着 | 受付、自己紹介 |
| 説明 | 園長 or 主任の話 |
| 見学 | 教室・園庭・給食室 |
| 質疑 | 気になることを質問 |
| 帰宅 | 即座にメモ整理 |

## 見学チェックリスト

### 環境

- 教室の広さ・採光・空気
- 園庭の有無・広さ
- セキュリティ（門・防犯カメラ・入退室管理）
- トイレ・手洗い場
- 駐輪場・ベビーカー置き場

### 先生

- 笑顔で対応しているか
- 子供との距離感
- 配置人数（国基準を満たすか）
- 離職率

### 子供たち

- 表情、お友達と関わり
- 自由遊びの様子
- 給食を楽しんでいるか

### 食事

- 自園調理 or 外部委託
- アレルギー対応の柔軟さ
- 離乳食の進め方
- おやつの内容

### 持ち物

- **手作り指定の有無**（バッグ・ナフキンなど）
- **オムツの持ち帰り**有無
- **着替え枚数**

## 服装のポイント

### 親

- きれいめ普段着、歩きやすい靴
- 抱っこ紐 or ベビーカー対応

### 子（同伴）

- 動きやすい服、着替え持参

## 写真撮影のコツ

園内撮影は基本NG。**外観・看板**程度で。
帰宅後にチェックリストを清書し、比較表を作成。

## 申込のコツ

### 認可

- **第1〜10希望**まで書く（多いほど内定確率UP）
- **書類は1日でも早く**提出
- **コピーを取って保管**

### 認可外併願

- **入園金あり**の園が多い、保険として確保
- **認可内定後にキャンセル**するか、両方継続するか判断

## 慣らし保育

### スケジュール例

- **1週目**：1時間〜2時間
- **2週目**：午前のみ
- **3週目**：給食まで
- **4週目**：午後まで

### 親の心構え

- **泣くのは普通**
- **仕事復帰日に余裕を**
- **病気の覚悟**（最初の半年は風邪の連続）

## 我が家のリアル

長女の保育園は**見学10園・申込第5希望まで**で、第2希望の認可に内定。激戦区で**点数フルマックス＋兄弟加点なし**で滑り込み。

正直、見学10園は大変でしたが、**自園調理＋園庭広い＋先生の笑顔**が決め手の園に出会えました。**手作り指定なし・オムツ持ち帰りなし**の現代的な園を選んだのも正解。

次男は**兄弟枠で第1希望**にスムーズ入園。長女と同じ園は朝の送迎が楽でした。

慣らし保育の最初の1週間は**毎日泣き別れ**でしたが、3週目には笑顔で「いってきます」と言うように。

## まとめ

- 保育園は**認可優先＋認可外併願**
- **0歳児入園が比較的入りやすい**
- 点数の仕組みを**自治体で確認**
- 見学は**5〜10園**、比較表を作成
- **手作り指定・オムツ持ち帰り**もチェック
- 慣らし保育期間を**仕事復帰前に確保**
- 地域差が大きいので**自治体ルール厳守**

## 入園準備で「名前書き地獄」を回避する
