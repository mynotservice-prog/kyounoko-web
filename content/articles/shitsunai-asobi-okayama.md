## 1. ふれあい児童館（岡山ふれあいセンター内）｜無料・月曜も開館

中区桑野の岡山ふれあいセンターの中にある児童館です。運営する岡山市ふれあい公社のページに**「利用料は無料です」**と明記されています。市の児童館一覧でも、休館日は**第3土曜日と年末年始だけ**で、月曜日も開いています。

| 項目 | 内容 |
|---|---|
| 所在地 | 岡山市中区桑野715-2（岡山ふれあいセンター内） |
| 対象 | だれでも利用可（幼児は保護者同伴） |
| 料金 | **無料** |
| 開館（保育室・乳幼児専用） | 火・木・第1・第3金曜・土・日・祝日 10時〜18時／月・水・第2・第4・第5金曜 12時〜18時 |
| 開館（プレイルーム） | 日曜・祝日 10時〜18時／月〜土 12時〜18時 |
| 休み | 第3土曜日、年末年始（12月29日〜1月3日） |

保育室は乳幼児と保護者のための部屋で、ブロック・積み木・おままごとセット・絵本などがあると公式に書かれています。プレイルームには幼児用のおもちゃのほか、小学生以上向けの卓球やボードゲームがあります。受付で名前を記入して使います。

暴風・大雪・暴風雪の警報（岡山県南部）が出たとき、震度5弱以上の地震があったときなどは臨時休館になると案内されています。詳細は[岡山市ふれあい公社の児童館の利用案内](https://www.okayama-fureai.or.jp/okayama/0000001088.html)で確認できます。

## 2. 北ふれあい児童館（北ふれあいセンター内）｜無料・0歳からの保育ルーム

北区谷万成の北ふれあいセンターの中にある児童館です。公式ページに**「利用は無料です」**と明記されています。0歳から就学前の子が使う「保育ルーム」と、小学生以上の「マスカットホール」に分かれています。

| 項目 | 内容 |
|---|---|
| 所在地 | 岡山市北区谷万成二丁目6-33（北ふれあいセンター内） |
| 対象 | 保育ルームは0歳から就学前の幼児と保護者（小学生以上は入室不可） |
| 料金 | **無料** |
| 開館（保育ルーム） | 火・金曜 12時〜18時／水・木・土・日曜・祝日 10時〜18時 |
| 休み | 毎週月曜日、第3土曜日、年末年始（12月29日〜1月3日） |
| 設備 | 保育ルームにベビーベッドと簡易な授乳スペース、同じ階におむつ交換台のある多目的トイレ |

保育ルームにはおもちゃや絵本があり、親子でゆったり遊べると案内されています。**授乳スペースはパーティションで仕切った簡易なもの**なので、必要なら授乳ケープを持っていくよう書かれています。保育ルーム内では食事ができず、近くのソファなどを使います。

日曜・水曜・木曜の10時〜13時と、火曜・金曜の14時〜17時は地域子育て支援拠点事業の時間で、通常の児童館と同じように使えます。来館者が多いときは時間や人数を制限する場合があります。詳細は[保育ルームの利用案内](https://www.okayama-fureai.or.jp/kita/0000002720.html)と[北ふれあい児童館の利用について](https://www.okayama-fureai.or.jp/kita/0000001315.html)で確認できます。

## 3. 清輝児童センター｜無料・市の中心部

北区新道にある市立の児童センターです。岡山市の児童館一覧ページに、市内の児童館・児童センターの**利用料は「無料」**と記載されています。

| 項目 | 内容 |
|---|---|
| 所在地 | 岡山市北区新道2-20 |
| 対象 | だれでも利用可（小学校就学前の幼児は保護者同伴） |
| 料金 | **無料** |
| 開館 | 10月〜3月 10時〜17時／4月〜9月 10時〜18時 |
| 休み | 毎週月曜日（8月は毎週日曜日）、第1・第3日曜日、祝日、12月29日〜1月3日 |

市の紹介では、市役所・病院・図書館などの公共施設が点在する、交通の便の良い住宅地の中にあるとされています。火・水・木曜の10時30分〜14時30分は地域子育て支援拠点事業の時間です。就学前の親子向けには、毎週火曜10時30分〜11時30分の「コロコロひろば」（遊具を使った自由遊び）、毎週木曜の「チュンチュンクラブ」（音楽あそび・運動あそびなど）があります。

市内にはこのほかにも、旭東児童センター（中区）・財田児童センター（中区）など同じ利用条件の児童館・児童センターがあり、所在地と休館日は[岡山市の児童館・児童センター一覧](https://www.city.okayama.jp/shisei/0000032387.html)で確認できます。

## 4. 人と科学の未来館サイピア｜入館無料・未就学児はプラネタリウムも無料

北区伊島町の岡山県生涯学習センターの中にある、県の科学館です。公式の利用案内に**入館料「無料（ただしプラネタリウム観覧料を除く）」**と明記されています。プラネタリウムの観覧料も**未就学児は無料**です。

| 項目 | 内容 |
|---|---|
| 所在地 | 岡山市北区伊島町3-1-1（岡山県生涯学習センター） |
| 料金 | **入館無料**。プラネタリウムは大人（65歳未満）530円、高校生310円、小・中学生110円、**未就学児無料** |
| 開館 | 9時〜17時（原則） |
| 休み | 月曜日（祝日の場合は開館）、祝日の翌日（火〜金曜の場合）、12月28日〜1月4日 |
| 設備 | 授乳室、幼児トイレ、コインロッカー、エレベーター |

1階に「科学体験・学習広場」、2階にプラネタリウム（サイエンスドーム）と企画展示室があります。科学体験・学習広場は、休日や夏休みなどに科学教室やサイエンスショーの場になると案内されています。プラネタリウムの投影は、平日が14時30分・15時30分、土日祝が10時・11時・13時・14時30分・15時30分からです（団体予約などで投影がない時間もあり）。開始時刻を過ぎると入場できません。

駐車は生涯学習センターの駐車場（約180台）を使うよう案内されていて、土日祝日は混み合うとされています。バスはJR岡山駅西口バスターミナル23番のりばから岡電バス［76］系統で「京山入口」下車、徒歩8分です。詳細は[サイピアの利用案内](https://www.sci-pia.pref.okayama.jp/news/detail.aspx?servno=4938)で確認できます。

## 5. リトルプラネット 岡山天満屋｜デジタル遊具の有料パーク

表町の天満屋 岡山本店6階にある、デジタル技術を使った屋内の遊び場です。AR砂遊び「SAND PARTY!」や冒険型デジタルボールプール「ZABOOM JOURNEY」などがあります。

| 項目 | 内容 |
|---|---|
| 所在地 | 岡山市北区表町2丁目1-1 天満屋 岡山本店6F |
| 対象 | 年齢に関係なく入場可（アトラクションは3歳以上を推奨）。小学生までは18歳以上の保護者と一緒に入場 |
| 料金（平日） | 30分：こども（4〜12歳）700円・幼児（2・3歳）500円・おとな700円／60分：こども1,200円・幼児1,000円・おとな800円／1日フリーパス：こども1,800円・幼児1,600円・おとな900円 |
| 料金（休日） | 30分：こども920円・幼児700円・おとな900円／60分：こども1,550円・幼児1,300円・おとな1,000円／1日フリーパス：こども2,600円・幼児2,300円・おとな1,300円 |
| 0〜1歳 | **1歳以下は入場無料** |
| 年会費 | 入場には1家族ごとに会員登録が必要（年会費600円、翌年以降300円。1歳以下の子だけの場合は300円） |
| 営業 | 10時〜18時30分（18時最終受付） |
| 休み | 「天満屋 岡山本店の定休日に準ずる」と記載（年末年始の営業は公式に記載を確認できませんでした） |

**冬季休暇中（2026年12月21日〜2027年1月7日）は、平日でも土日・祝日と同じ扱い**と公式FAQに書かれています。冬休みに行くなら休日料金で考えておくと安心です。

延長は15分ごとにかかり、退場予定時刻を過ぎると自動で延長料金が発生します。パーク内で口にできるのは飲み物だけで、食べ物の持ち込みはできません。**パーク内にトイレはない**ので、入場前に済ませておくよう案内されています。おとな1人が同伴できる子どもは3人までです。料金・営業時間は[リトルプラネット 岡山天満屋の公式ページ](https://litpla.com/space/okayama-tenmaya/)で確認できます。

## 予算で選ぶ

- **0円で済ませたい** → ふれあい児童館、北ふれあい児童館、清輝児童センター（いずれも利用料無料と公式に記載）、サイピア（入館無料・未就学児はプラネタリウムも無料）
- **夕方まで遊ばせたい** → ふれあい児童館・北ふれあい児童館はいずれも18時まで
- **デジタル遊具で遊ばせる** → リトルプラネット 岡山天満屋（1歳以下は無料。幼児は平日30分500円から、別に年会費）

## 冬の雨・寒い日のコツ

- **年末年始は公的施設がほぼ休み**：ふれあい児童館・北ふれあい児童館・清輝児童センターは12月29日〜1月3日、サイピアは12月28日〜1月4日が休みです
- **曜日で休みが違う**：月曜は北ふれあい児童館・清輝児童センター・サイピアが休み（ふれあい児童館は開館）。第3土曜日はふれあいセンターの2館が休み。清輝児童センターは第1・第3日曜日と祝日も休み
- **冬は清輝児童センターが17時まで**：10月〜3月は10時〜17時の開館です
- **リトルプラネットは冬休み中の料金に注意**：2026年12月21日〜2027年1月7日は平日でも休日扱いです
- **警報が出たら休館の場合あり**：ふれあいセンターの2館は、岡山県南部に暴風・大雪などの警報が出ると臨時休館になると案内されています

## よくある質問

### Q. 岡山市で無料の室内遊び場は？

A. **ふれあい児童館（中区桑野）、北ふれあい児童館（北区谷万成）、清輝児童センター（北区新道）**が、いずれも利用料無料と公式に記載されています。岡山市の児童館一覧には市内の児童館・児童センター22館が載っていて、利用料はいずれも「無料」です。**人と科学の未来館サイピア**も入館無料で、プラネタリウムは未就学児無料です。

### Q. 0歳を連れて行けるところは？

A. **北ふれあい児童館**の保育ルームは0歳から就学前の子と保護者だけが入れる部屋で、ベビーベッドと簡易な授乳スペースがあります。**ふれあい児童館**にも乳幼児専用の保育室があります。**サイピア**には授乳室があります。**リトルプラネット 岡山天満屋**は1歳以下が入場無料です。

### Q. 年末年始（12月29日〜1月3日）に開いているところは？

A. ふれあい児童館・北ふれあい児童館・清輝児童センターは12月29日〜1月3日、サイピアは12月28日〜1月4日が休みです。リトルプラネット 岡山天満屋は「天満屋 岡山本店の定休日に準ずる」とされ、天満屋のサイトには「毎日休まず営業いたします」とありますが、年末年始の営業日・営業時間は公式に記載を確認できませんでした。行く前に電話（086-231-7626）で確かめてください。

### Q. 岡山市にボーネルンド（キドキド）やザキッズはある？

A. ボーネルンドの公式店舗一覧（2026年11月9日確認）に、**岡山県の店舗は掲載されていません**。ザキッズの公式店舗一覧（同日確認）で岡山県に載っているのは「岡山ゆめタウン高梁店」（高梁市）だけで、岡山市内の店舗は掲載されていません。

### Q. 月曜日に行けるところは？

A. **ふれあい児童館**は休館日が第3土曜日と年末年始だけで、月曜日も開いています（保育室は月曜12時〜18時）。リトルプラネット 岡山天満屋も天満屋の定休日以外は営業しています。北ふれあい児童館・清輝児童センター・サイピアは月曜休みです（サイピアは祝日の月曜は開館）。
