## 結論

| 種類 | 開始時期 |
| --- | --- |
| 離乳食用カレー（ベビーフード） | **7〜8ヶ月** |
| 手作り甘口カレー | 1歳〜 |
| 市販甘口ルー | **1歳半〜2歳** |
| 中辛 | 5〜6歳〜 |
| 辛口 | 小学生以降 |

## なぜ市販ルーは1歳半まで控える？

- **塩分・脂質**：大人向けで濃い
- **スパイス**：辛味成分（カプサイシン等）が刺激
- **化学調味料**：胃腸に負担
- 子ども用ルーでも1歳半以降推奨

## 月齢別の進め方

### 〜6ヶ月

- 与えない

### 7〜8ヶ月

- 離乳食用カレー味のベビーフード
- 風味づけ程度
- 手作りなら無塩・カレー粉ほんの少し

### 9〜11ヶ月

- ベビーフード活用
- 手作りは野菜カレー（無塩・少しカレー粉）

### 1〜1歳半

- 手作り甘口カレー
- 子ども用ルー（1歳半〜と表記のもの）
- 野菜は柔らかく

### 1歳半〜2歳

- 市販甘口ルー解禁
- 「○歳から」表記を確認
- ご飯と少しずつ

### 3〜4歳

- 通常の甘口（バーモントカレー等）
- お店の甘口も可

### 5〜6歳

- 中辛挑戦
- 子どもによって差大

## 市販ルー比較（甘口）

| ブランド | 対象 | 特徴 |
| --- | --- | --- |
| 1歳からのカレールウ（S&B） | 1歳〜 | 添加物控えめ |
| カレーの王子さま | 1歳〜 | 8大アレルゲン不使用 |
| バーモントカレー甘口 | 3歳〜目安 | 定番 |
| こくまろ甘口 | 3歳〜目安 | やや濃厚 |
| ジャワカレー甘口 | 3歳〜目安 | スパイス感あり |

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 7〜8ヶ月（BF） | 1袋（70g前後） |
| 1歳 | 子ども茶碗1/2杯＋ルー大さじ2 |
| 2〜3歳 | 子ども茶碗1杯＋ルー大さじ3 |
| 4〜5歳 | 大人の1/2 |
| 6歳〜 | 大人の2/3 |

## アレルギー対策

### カレーに含まれる可能性のあるアレルゲン

- 小麦（ルー）
- 乳（バター・牛乳）
- 大豆
- りんご（はちみつや甘み）
- ピーナッツ（一部）
- バナナ
- 鶏肉・牛肉・豚肉

### 注意点

- ルーは複合アレルゲン
- 「アレルゲン28品目不使用」のルーが安心
- 初めては既知の具材で

## 辛さの調整方法

### 辛くしすぎたとき

- ヨーグルト・牛乳を加える
- じゃがいもを増やす
- ご飯を多めに
- 卵黄を混ぜる

### 子ども用と大人用を分ける

- 途中までは一緒、最後に分ける
- 子ども鍋に取り分けてから大人用ルー追加
- 圧力鍋なら時短で2鍋OK

## トッピング判断

| トッピング | 目安 |
| --- | --- |
| 福神漬け | 4歳〜（塩分注意） |
| らっきょう | 5歳〜（噛みきれれば） |
| チーズ | 1歳〜 |
| 卵（半熟） | 3歳〜 |
| 揚げ物 | 2歳〜 |
| 納豆 | 1歳〜 |

## 注意点・避けたい場面

- 隠し味の香辛料（ガラムマサラ等）に注意
- ハチミツは1歳まで絶対NG
- カレー粉のみで作る場合も大人と同じ量はNG
- 食べ過ぎは胃腸に負担
- 食後に口の周りを拭く（色素沈着）

## CoCo壱（ココイチ）デビュー

- お子様カレー（甘口）は3歳〜推奨
- 辛さ控えめ・量少なめを選ぶ
- トッピングは慎重に
- ハンバーグ・コーン・温泉卵が定番

## 我が家のリアル

息子8ヶ月でベビーフードのカレー味デビュー。1歳半で「1歳からのカレールウ」で手作り、家族みんなで同じものを。

2歳半でバーモント甘口に切り替え。「美味しい」と完食。3歳でCoCo壱お子様カレー。コーントッピングで大喜び。中辛は5歳でようやく挑戦するも「辛い！」と水を飲んだので甘口に戻しました。

「うちの子辛いの平気」という話も聞きますが、個人差大。我が家は無理せず甘口継続中です。

## まとめ

- 離乳食用は7〜8ヶ月から
- 手作り甘口は1歳から
- 市販甘口ルーは1歳半〜2歳
- 中辛は5〜6歳以降
- アレルゲン28品目不使用ルーが安心
- ハチミツは1歳まで絶対NG
