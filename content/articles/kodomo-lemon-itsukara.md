## 結論

| 形態 | 開始時期 |
| --- | --- |
| 果汁少量（風味づけ） | **7〜8ヶ月〜** |
| レモン入りジュース | 1歳〜 |
| 輪切り（少量・薄く） | 2歳〜 |
| そのまま食べる | 3歳〜 |
| 皮の利用 | 2歳〜（よく洗って・無農薬） |

## なぜ少量から？

- **強い酸味**：唾液分泌増加・胃酸過多
- **歯のエナメル質**：直接含むと溶ける
- **口の周りの肌荒れ**：果汁で赤くなることも
- **果汁感覚**：意外と量は少しで十分

## 月齢別の進め方

### 〜6ヶ月

- 与えない

### 7〜8ヶ月

- 果汁を数滴、料理の風味づけ
- 魚にかける程度
- お湯で薄めて少量

### 9〜11ヶ月

- 加熱料理の隠し味
- ドレッシング少量

### 1〜2歳

- レモン入り飲料（薄めて）
- 蜂蜜レモン（1歳以降）
- フレンチドレッシング

### 2〜3歳

- 輪切りを薄く・お湯で割って
- レモネード
- 唐揚げにかける

### 3歳以降

- レモンサワー風（ノンアル）
- そのまま味見

### 5歳以降

- 通常の食べ方
- レモン汁料理いろいろ

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 7〜8ヶ月 | 果汁数滴 |
| 1歳 | 果汁小さじ1/4 |
| 2〜3歳 | 果汁小さじ1 |
| 4〜5歳 | 輪切り1〜2枚分の果汁 |

## 酸味の薄め方

### 飲み物として

- お湯：3倍以上で薄める
- ハチミツ（1歳以降）で甘み
- 炭酸水で爽やかに（4歳〜）
- 氷で薄める

### 料理として

- 加熱で酸味マイルド
- 油・バターと組み合わせ
- 醤油と混ぜてポン酢風

## メリット（ビタミンC）

- レモン1個でビタミンCが約100mg
- 子どもの1日推奨量（35〜40mg）を超える
- ただし**量は少しで十分**
- 鉄分吸収促進（牛肉と一緒に）

## 皮の扱い

### ワックス・防カビ剤に注意

- 国産レモンは比較的安心
- 輸入レモンはワックス・OPP・TBZが
- 「無農薬」「ノーワックス」表示を確認
- よく洗ってから使う

### 子どもに使う場合

- 国産無農薬を選ぶ
- 重曹で洗う
- お湯（80℃）でさっと洗う
- 皮は薄くスライス

## 歯への影響

- レモン汁を直接歯に長時間付着→エナメル質溶解
- ストローで飲むと歯に当たりにくい
- 食べた後はお水で口をすすぐ
- 食後すぐの歯磨きは避ける（30分後）

## 注意点・避けたい場面

- 空腹時は胃に刺激
- 喉が痛い時は避ける
- 口の周りの肌荒れに注意（拭いてあげる）
- ハチミツレモンは1歳以降
- 防腐剤入りポッカレモンは少量で
- 種は誤嚥注意（取り除く）

## 子ども向けレシピアイデア

- **レモンはちみつ（1歳〜）**：はちみつ大さじ1＋レモン汁数滴
- **レモネード（2歳〜）**：水＋果汁小さじ1＋砂糖少々
- **レモンチキン（1歳〜）**：唐揚げに数滴
- **白身魚のレモンソテー（9ヶ月〜）**：仕上げに数滴
- **レモンサラダ（2歳〜）**：ドレッシングに

## アレルギー対策

### 柑橘系アレルギー

- 稀だが存在
- 口の周りの赤み（接触性皮膚炎）
- 初めては少量・午前中

### 症状

- 口の周り・唇の腫れ
- 蕁麻疹
- 嘔吐

→ 症状あれば受診。

## 我が家のリアル

息子8ヶ月で白身魚のソテーに果汁数滴。問題なく完食。1歳半でハチミツレモンお湯割り、寝る前のお楽しみに。

3歳で唐揚げにレモンをかけてあげる係を担当。「ジュッ」と音が出るのが楽しいらしく、毎回喜んでかけてくれます。

5歳で初めて生レモンの輪切りを「味見する？」と勧めたら「酸っぱい！」と顔をしかめて大爆笑。動画撮影して家族で楽しみました。

レモネードは公園遊びの後の定番。氷を入れて爽やかに、夏のお供です。

## まとめ

- 風味づけは7〜8ヶ月から
- 飲み物（薄めて）は1歳〜
- そのまま食べるのは3歳〜
- 酸味は少量で十分
- 皮は無農薬を選ぶ
- 歯への影響に配慮
- 口の周りの肌荒れに注意
