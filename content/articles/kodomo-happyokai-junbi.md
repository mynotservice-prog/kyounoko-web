## 結論（時期・必要なもの）

発表会準備は**衣装・練習・撮影機材・心のサポート**の4点が肝心。**衣装は指示通りに**、**家での練習は本人が嫌がらない範囲で**、**撮影席は早めに確保**。当日は**「上手にできなくてもOK」**のメッセージを伝えるのが最大のサポートです。

- 向いている人：初めての発表会、家での練習をどうサポートするか迷っている
- 向いていない人：既にベテラン親

## いつやる？目安

### 発表会の開催時期

- **保育園・幼稚園**：12〜2月が多い（生活発表会・お遊戯会）
- **小学校**：学芸会は秋〜冬
- **音楽教室・バレエ**：年1回（夏 or 冬）

### 準備のスケジュール

| 時期 | やること |
| --- | --- |
| 1か月前 | 衣装案内確認、材料調達 |
| 3週間前 | 家での練習サポート開始 |
| 2週間前 | 衣装試着、サイズ調整 |
| 1週間前 | 撮影機材確認、当日の段取り共有 |
| 前日 | 衣装最終チェック、早寝 |
| 当日 | 早めに到着、撮影席確保 |

## 準備するもの

### 衣装

| パターン | 内容 |
| --- | --- |
| 全身指定 | 園が貸し出し or 購入 |
| 一部指定（白シャツ・黒ズボン） | 自宅で用意 |
| 完全自由 | 役柄に合わせて手作り or 購入 |

### 衣装小物の調達先

- **西松屋・ユニクロ**：白シャツ・黒スカートなど基本
- **しまむら・ドンキ**：派手な衣装ベース
- **100均**：小物（リボン・ヘアアクセ）
- **手芸店・通販**：ハンドメイド派

### 撮影機材

- **スマホ**：手軽だが望遠は弱い
- **ビデオカメラ**：会場が広い場合に便利
- **一眼レフ＋望遠**：高画質を求めるなら
- **三脚**：手ブレ防止
- **モバイルバッテリー**：必須

## 当日の流れ

| 時間 | 内容 |
| --- | --- |
| 朝 | 早めの朝食、衣装着替え |
| 出発 | 撮影機材忘れずに |
| 到着 | 撮影席確保、子は楽屋へ |
| 開演 | 静かに鑑賞、撮影 |
| 終演 | 子と合流、記念撮影 |
| 帰宅 | ねぎらいの言葉、好きな食事 |

## 服装のポイント

### 主役

- **衣装は園・教室指示通り**
- **インナー**：白い肌着・タイツ
- **靴**：指定なし or 白いシューズ
- **ヘア**：女児はリボン・ヘアバンド

### 親

- **きれいめ普段着**で十分
- **動きやすさ**重視（撮影で立つことも）
- **シャッター音マナー**を考慮した服装（音が出ない素材）

## 写真撮影のコツ

### 撮影席の確保

- **開場と同時に入場**して中央〜後方の通路側
- **三脚OKエリア**を事前確認
- **シャッター音禁止**の園も増加（マナーモード推奨）

### 撮り方

1. **入場シーン**：表情をアップで
2. **本番中**：ステージ全体＋我が子アップを切り替え
3. **動画は1曲丸ごと**保存
4. **終演後の記念撮影**：本人＋衣装＋お友達
5. **裏方の準備風景**もあれば残す

### 注意点

- **フラッシュ厳禁**（子供の目に悪い、雰囲気壊す）
- **シャッター音切替**（最近のスマホはOK機種多数）
- **動画と写真の切替**は事前に練習

## 家での練習サポート

### 練習のコツ

- **本人がやりたい時だけ**（強制NG）
- **親が観客役**：拍手で気分UP
- **動画を撮って一緒に見る**：客観視できる
- **「上手だね」より「楽しそうだね」**

### 練習でNGなこと

- 「もっと頑張って」のプレッシャー
- 兄弟と比較
- 「失敗したら笑われる」発言
- 毎日強制練習

## メンタルケア

### 当日朝

- **「楽しんでね」「いつも通りでいいよ」**
- **「ママパパが見てるからね」**で安心感
- **緊張は自然なこと**と伝える

### 終演後

- **「ありがとう、すてきだったよ」**
- **失敗しても叱らない**
- **本人がしたい話を聞く**

## 我が家のリアル

長女の幼稚園発表会は5歳のお遊戯。**衣装は白シャツ＋黒スカート指定**で西松屋で調達。家での練習は強制せず、**本人が「見て見て」と言った時だけ**観客役を担当しました。

正直、本番直前まで「**緊張で出たくない**」と言っていましたが、本番では満面の笑顔。**動画を撮りながら涙が止まらない**くらい感動しました。

撮影席は開場30分前から並んで通路側を確保。三脚＋一眼レフ＋スマホで2方向から撮影。後日DVDにして祖父母にプレゼント。

## まとめ

- 発表会準備は**衣装・練習・撮影・心のサポート**の4点
- 衣装は**指示通り**、小物は100均でも◎
- 家練習は**本人が嫌がらない範囲で**
- 撮影席は**開場と同時に確保**
- フラッシュ・シャッター音マナーに注意
- 当日は**「楽しんでね」**の声かけ
