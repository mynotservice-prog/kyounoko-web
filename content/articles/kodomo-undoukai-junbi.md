## 結論（時期・必要なもの）

運動会準備は**1週間前から逆算**で動くと余裕が生まれます。準備するのは**お弁当・敷物・撮影機材・暑さ寒さ対策・着替え**の5点。**お弁当は前日仕込み＋当日朝詰めるだけ**、**場所取りは公式ルールに従う**のが鉄則です。

- 向いている人：初めての運動会、共働きで効率重視
- 向いていない人：すでに何度も経験しベテラン

## いつやる？目安

### 運動会の開催時期

- **春**：5〜6月（小学校に多い）
- **秋**：9〜10月（保育園・幼稚園に多い）
- **コロナ後**：半日開催・分散開催も増加

### 準備のスケジュール

| 時期 | やること |
| --- | --- |
| 2週間前 | プログラム確認、場所取りルール把握 |
| 1週間前 | お弁当献立決定、買い物リスト作成 |
| 3日前 | 持ち物リスト最終チェック |
| 前日 | お弁当下ごしらえ、機材充電 |
| 当日朝 | お弁当詰め、出発 |

## 準備するもの

### 必須リスト

| カテゴリ | アイテム |
| --- | --- |
| 食事 | お弁当、飲み物（保冷）、おやつ、保冷剤、保冷バッグ |
| 場所取り | レジャーシート、椅子、テント（許可された場合）、クリップ |
| 撮影 | スマホ、カメラ、三脚、モバイルバッテリー、レンズ拭き |
| 暑さ対策 | 帽子、日焼け止め、扇風機、塩タブレット、うちわ |
| 寒さ対策 | ブランケット、カイロ、薄手のコート |
| その他 | ウェットティッシュ、ゴミ袋、絆創膏、薬、着替え |

### お弁当のポイント

- **おにぎり・サンドイッチ**（手で食べやすい）
- **唐揚げ・ウインナー**（冷めても美味しい）
- **彩り野菜**（ミニトマト・ブロッコリー）
- **デザートはフルーツ**（疲れた体に染みる）
- **保冷剤2個以上**で食中毒対策

## 服装のポイント

### 主役（子供）

- **指定の運動会服**（園・学校支給）
- **下に着るインナーは速乾性**
- **着替えセット**を必ず

### 親

- **動きやすい服装**（パンツ＋スニーカー）
- **帽子・サングラス**（紫外線対策）
- **撮影しやすい服**（リュック＋カメラ収納）
- **写真に映ってもいい服**（指定席に座る場合）

## 写真撮影のコツ

### 機材

- **スマホ＋望遠レンズアタッチメント**でも十分
- **一眼レフ**なら200mm以上の望遠
- **三脚**：競技中の固定撮影に
- **モバイルバッテリー**：1日電池切れリスク

### 撮り方

1. **入場行進**：列の中の子をズームで
2. **ダンス・お遊戯**：全身を撮影
3. **かけっこ**：連写＋ゴール位置で待機
4. **昼食**：家族のオフショット
5. **閉会式**：表彰や全体写真

### 動画も重要

- **演目1つは動画**で保存
- **手ブレ補正**を活用
- **横向き撮影**（縦は後で困る）

## 場所取りのコツ

### 公式ルール確認

- **早朝場所取りOK**か（前日からは大抵NG）
- **エリア指定**があるか
- **テント・タープ許可**

### 良い場所の見つけ方

- **入場門近く**：入場シーン撮影に最適
- **本部テント前**：放送が聞こえやすい
- **木陰**：日差しを避けたいなら
- **ゴール正面**：かけっこ撮影に

## 暑さ・寒さ対策

### 春・秋でも油断禁物

- **春の運動会**：日焼け止めSPF50＋帽子必須
- **秋の運動会**：朝晩冷える、薄手の上着
- **塩タブレット・OS-1**：熱中症予防
- **冷感タオル・ハンディファン**：暑い日

## 我が家のリアル

長女の保育園運動会は秋開催。前日にお弁当のおかずを全部仕込み（唐揚げ・ウインナー・ブロッコリー）、当日朝6時から詰めて出発。**場所取りはパパが7時に到着**して何とか日陰確保。

正直、**撮影に夢中で疲労困憊**でしたが、3歳の娘がかけっこで1位になった瞬間の動画は宝物。**スマホと一眼レフの2台体制**で記録残しました。

次男は人見知りピークでかけっこ途中で大泣き。それでも**ありのままを記録**したのが今では良い思い出です。

## まとめ

- 運動会は**1週間前から逆算**で準備

- 場所取りは**公式ルール厳守**
- 撮影は**スマホ＋望遠 or 一眼**
- **暑さ寒さ対策**を侮らない
- **動画も忘れずに**
