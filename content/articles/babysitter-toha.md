## 結論｜ベビーシッターの基本

- **ベビーシッターとは**：保護者に代わって自宅などで **子どもの世話をする保育サービス**
- **料金相場**：1時間あたり **1,500〜3,000円** が中心（マッチング系・派遣系で差あり）
- **依頼方法**：マッチングアプリ、ベビーシッター会社、自治体紹介、知人など
- **補助制度**：内閣府のベビーシッター割引券、東京都ベビーシッター利用支援事業など
- **選ぶ際の基準**：資格・経験・口コミ・面談・身分証確認

## ベビーシッターとは何か

ベビーシッターは **保護者の依頼で、自宅などで子どもを保育する個人または事業者** のことです。保育園のように施設で集団保育するのではなく、 **1対1（または兄弟一緒）の個別保育** が基本です。

### 保育士との違い

- **保育士**：国家資格。主に保育園で勤務
- **ベビーシッター**：資格は必須ではない（民間資格や保育士資格を持つ人も）

### 主な業務

- 子どもの見守り・遊び相手
- 食事補助・おむつ替え・寝かしつけ
- 簡単な家事補助（家庭による）
- 送迎・習い事の付き添い（オプション）

## 料金相場（2026年5月時点）

| サービス形態 | 1時間あたりの目安 |
| --- | --- |
| マッチング系（キッズライン、ポピンズシッターなど） | 1,500〜3,000円 |
| 派遣系（ポピンズ、ベアーズキッズ、ファミリーリブイン） | 2,500〜5,000円 |
| 自治体紹介（地域ごと） | 800〜2,000円 |
| 夜間・早朝・深夜割増 | 通常料金の20〜50%増 |

その他、入会金・年会費・交通費・キャンセル料がかかる場合があります。

## 依頼方法

### ステップ

1. **利用目的を整理**：仕事・通院・リフレッシュ・送迎など
2. **サービス形態を選ぶ**：マッチングアプリ、派遣会社、自治体紹介
3. **登録・会員登録**
4. **シッター検索＆面談**：可能なら **事前面談（顔合わせ）** をしてから本依頼
5. **予約・利用**
6. **支払い・レビュー**：終了後にレポート確認・評価

### 選ぶ際のチェックポイント

- 保育士・看護師・幼稚園教諭などの **資格保持者か**
- ベビーシッター経験年数
- 賠償責任保険への加入
- 身分証確認の有無
- 口コミ・レビュー
- 病児対応・夜間対応の可否

## 利用できる補助制度

- **内閣府ベビーシッター割引券**：勤務先が委託している場合、1回2,200円割引（年間複数枚）
- **東京都ベビーシッター利用支援事業**：都内在住で要件を満たす家庭に補助
- **自治体独自の補助**：政令市・特別区で導入が広がる
- **企業の福利厚生**：会員制シッターサービスの優待

> 補助制度は **自治体・勤務先・年度** によって内容が変わります。利用前に必ず確認を。

## 対象者・条件

- 利用に年齢制限はないことが多い（0歳から小学生まで対応する事業者も）
- 自治体補助は **対象年齢・所得・利用目的（就労・育休復帰など）** に条件あり
- 事業者ごとに病児保育の可否・対応エリアが異なる

## メリット・デメリット

| 項目 | 内容 |
| --- | --- |
| メリット | 自宅で個別保育／柔軟な時間対応／病児対応の事業者も／きょうだい同時可 |
| デメリット | 料金が高い／シッターによる差が大きい／密室保育のリスク／事前準備が必要 |

## 似たサービスとの違い

| サービス | 違い |
| --- | --- |
| 保育園 | 集団保育・公的施設 |
| 一時保育 | 保育園・認定こども園で一時的に預ける |
| 病児保育 | 病気中・回復期の子向け |
| ファミサポ | 地域住民同士の助け合い、低料金 |

## よくある質問

**Q1. 何歳から預けられる？**
事業者によりますが、生後57日以降など対応する所が多い。

**Q2. 安全面が心配……**
事前面談、賠償保険加入確認、複数回利用での慣らし、自宅にカメラ設置などで対策を。

**Q3. 病気のときも預けられる？**
病児対応のシッターサービスを選ぶ必要があります。事前登録制が多い。

**Q4. 料金を抑えるには？**
内閣府の割引券、自治体補助、ファミサポとの併用がおすすめ。

**Q5. 1回どのくらいの時間頼むのが一般的？**
2〜4時間が多め。リフレッシュ目的なら2時間、仕事なら4〜6時間など目的で調整。

## 我が家のリアル

我が家は妻の在宅会議が立て込む時期、週1〜2回ベビーシッターを利用しました。初回は事前面談で30分顔合わせ。子どもがシッターさんの顔を覚えてから本依頼にすると、別れ際の泣きが少なく親も安心できました。**「自分の時間を作るためのシッター利用は罪悪感が湧きがちだが、結果として子どもとの時間の質が上がる」** が我が家の実感です。費用は確かに高いですが、内閣府の割引券が職場経由で利用できたので家計負担はかなり軽減されました。

- ベビーシッターは **個別保育サービス**
- 料金相場は1時間1,500〜3,000円
- マッチング系・派遣系・自治体紹介と選択肢がある
- 補助制度を活用するとお得
- 安全面は事前面談・口コミ・保険確認で
