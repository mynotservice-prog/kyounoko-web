## 1. 伊丹市立児童会館こらくる｜無料・20時まで開館

御願塚にある市の児童館です。公式サイトに**「1階及び屋外施設は児童（18歳未満）や乳幼児、その保護者が無料で利用可能」**と書かれています。1階には子どもや乳幼児の親子が使えるプレイルーム、すくすくルーム、図書室、授乳室があり、屋外には多目的広場とグラウンドがあります。

| 項目 | 内容 |
|---|---|
| 所在地 | 伊丹市御願塚6丁目1-1 |
| 対象 | 18歳未満の児童・乳幼児と保護者（未就学の幼児は18歳以上の保護者同伴） |
| 料金 | **無料**（1階・屋外。2階の貸室はどなたでも有料・予約制） |
| 開館 | 9:00〜20:00（保護者同伴でない小学生は17時まで） |
| 休み | 火曜日（祝日の場合はその翌日）、年末年始（12月29日〜1月3日） |
| 設備 | プレイルーム、すくすくルーム（乳幼児向け）、図書室、授乳室 |

市の公式ページでも、1階は児童とその保護者が無料で使えると書かれています。飲食については「ご相談ください」との記載です。混雑状況によっては利用人数を制限する場合があると書かれています。

バスは市バスJR・阪急両伊丹駅5番のりばから、堀池口経由・塚口行きで「鈴原町1丁目」下車、南へ徒歩4分。駐車場は23台で伊丹市立わかばこども園と共用、開館（9:00〜20:00）直後・正午ごろ・夕方はこども園の送迎車両が出入りすると書かれています。詳細は[こらくるの公式サイト](https://www.corakuru.com/)と[伊丹市の公式ページ](https://www.city.itami.lg.jp/SOSIKI/KODOMO/KODOMOW/jidoukan/1547787869855.html)で確認できます。

## 2. きららホール（北部学習センター）ゆうぎしつ・にゅうじしつ｜無料・就学前の親子向け

北野にある、公民館・図書館・児童館の機能を持つ市の複合施設です。運営者の施設案内に、2階の**幼児と保護者が自由に遊べる「ゆうぎ室・にゅうじ室」**は学習室とともに**（無料）**と書かれています。

| 項目 | 内容 |
|---|---|
| 所在地 | 伊丹市北野4丁目30 |
| 対象 | 就学前の子どもと保護者（未就学児は保護者の付き添いが必要） |
| 料金 | **無料** |
| 利用時間 | ゆうぎしつ・にゅうじしつ 9:00〜17:00 |
| 休み | 水曜日（祝日の場合は開館し、翌日以降で休日でない最初の日が休館）、年末年始（12月29日〜1月3日） |

室内には木のおもちゃやおままごと、テラスには三輪車などがあります。使うときは利用簿に名前などを書きます。9:30〜12:00と13:00〜15:30は、ゆうぎしつに子育て相談員がいると書かれています。飲食は決められた場所で、ごみは持ち帰りです。同じ建物に図書館北分館があります。

バスは阪急伊丹駅・JR伊丹駅から市バス「荒牧公園行き」「JR中山寺行き」で「北センター前」下車、徒歩5分。駐車場は43台で1時間まで無料（市の公式ページ）、ゆうぎしつの利用時間は9:00〜17:00です。詳細は[きららホールの「親子・児童スペースの利用」](https://www.kirara-itami.com/service/parent-child/)と[伊丹市の公式ページ](https://www.city.itami.lg.jp/SISETU_KIKAN/KYOIKU_SISETU/22167.html)で確認できます。

## 3. こども文化科学館｜3歳未満無料・プラネタリウムと宇宙の体験展示

桑津にある、プラネタリウムと宇宙に関する体験展示を常設する市の科学館です。観覧料はプラネタリウム投影1回分で、展示見学も含みます。

| 項目 | 内容 |
|---|---|
| 所在地 | 伊丹市桑津3丁目1-36 |
| 料金 | 大人400円、中高生200円、小学生以下〜3歳100円、**3歳未満無料**（2027年4月1日から大人500円・中高生250円・小学生以下150円、3歳未満は無料） |
| 開館 | 9:00〜17:15 |
| 休み | 毎週火曜（祝日にあたるときは開館）、祝日の振替日、12月29日〜1月3日、番組の入替時 |
| 設備 | 授乳室、おむつ替台3か所、エレベーター（屋上展望台へはエレベーターで上がれない） |

小さい子向けには、**ちびっこ投影「サンタクロースのわすれもの」を2026年11月1日〜12月20日の日曜・祝日の10時から1日1回**投影しています。日ごとの開館日とプラネタリウムの開始時刻は、市の公式ページの開館日カレンダーと投影時刻表で確かめてください。

**駐車場はありません**（公式には近隣の伊丹スカイパーク北駐車場から徒歩3分と記載）。JR伊丹駅から徒歩17分、JR伊丹駅・阪急伊丹駅から市バスで「神津」バス停下車すぐです。詳細は[こども文化科学館の公式ページ](https://www.city.itami.lg.jp/SOSIKI/KODOMO/kodomobunka_kagakukan/index.html)と[観覧料改定のお知らせ](https://www.city.itami.lg.jp/SOSIKI/KODOMO/kodomobunka_kagakukan/50069.html)で確認できます。

## 4. 伊丹市昆虫館｜0〜2歳無料・一年中チョウが舞う温室

昆陽池公園の中にある、生きた昆虫と一年中ふれあえる市の施設です。チョウ温室では約14種1000匹のチョウが見られ、昆虫の世界を10倍に拡大したジオラマ、標本、図書コーナーもあります。

| 項目 | 内容 |
|---|---|
| 所在地 | 伊丹市昆陽池3-1 昆陽池公園内 |
| 料金 | 大人400円、中高生200円、3歳〜小学生100円、**0〜2歳児無料** |
| 開館 | 9:30〜16:30（入館受付は16時まで。チョウ温室は10時から） |
| 休み | 毎週火曜日（火曜が祝日の場合は翌日）、12月29日〜1月3日、臨時休館あり |

**館内で食事はできません**。飲み物は指定の場所で飲めます。チョウ温室ではチョウを集めたりつかまえたりしないよう書かれています。**企画展「ぶんぶんミツバチ」は2026年10月1日〜2027年1月18日**の開催です。

電車の場合はJR伊丹駅・阪急伊丹駅から市バスに乗り換え、「松ヶ丘」か「玉田団地」で下車します。車の場合は公園西側の昆陽池公園駐車場（1時間まで200円、以降30分ごとに100円）を使い、そこから公園の中を10分ほど歩きます。開館は9:30〜16:30です。詳細は[伊丹市昆虫館の利用案内](https://www.itakon.com/information/)で確認できます。

## 5. キッズランドUS 兵庫伊丹店｜0歳無料・イズミヤ昆陽3階

イズミヤショッピングセンター昆陽の3階にある、キッズランドUSの室内遊び場です。スーパージャングルジム、ボールプール、トランポリン、ブランコ、ふわふわドーム、公園コーナー、ベビーコーナー、ままごとコーナー、絵本コーナー、飲食コーナー、授乳室などがあります。

| 項目 | 内容 |
|---|---|
| 所在地 | 伊丹市池尻1丁目1番 イズミヤショッピングセンター昆陽3階 |
| 料金（平日） | お子様1時間パック 800円、お子様1日パック 1,000円、保護者様1日パック 700円 |
| 料金（休日） | お子様1時間パック 800円、お子様3時間パック 1,300円、保護者様1日パック 700円 |
| その他 | イブニングパック 平日（15時〜）800円・休日（17時〜）800円。**0歳は無料**。価格はすべて税込 |
| 営業 | 10:00〜20:00 |
| 休み | 公式に記載を確認できませんでした（年末年始の営業も同様） |

「休日」は**土日祝日、国民の休日および当社指定の休日料金期間中**と書かれています。保護者の同伴が必要です。時間制限のあるパックは、退出時間を超えると差額がかかります。

店舗ページには、駐車場あり（無料・710台）と記載されています（営業は10:00〜20:00）。料金・営業時間は[店舗の公式ページ](https://kidslandus.com/shop/hyogo-itami/)で確認できます。

## 年齢別の選び方

| 年齢 | 第一候補 | 理由 |
|---|---|---|
| **0〜1歳** | 児童会館こらくる／きららホール | 乳幼児向けのすくすくルームと授乳室（こらくる）、にゅうじしつ（きらら）がどちらも無料 |
| **2〜3歳** | 伊丹市昆虫館／こども文化科学館 | 0〜2歳無料の昆虫館、3歳未満無料の科学館。3歳からは100円 |
| **4〜6歳** | キッズランドUS／こらくる | ジャングルジムやトランポリン（キッズランドUS）、屋外の多目的広場とグラウンドもある（こらくる） |

## 予算で選ぶ

- **0円で済ませたい** → 児童会館こらくる、きららホールのゆうぎしつ（どちらも無料と公式に記載）。2歳までなら伊丹市昆虫館、3歳未満ならこども文化科学館も無料
- **ワンコインで半日** → こども文化科学館（3歳〜小学生100円・プラネタリウム1回と展示）、伊丹市昆虫館（3歳〜小学生100円）
- **しっかり遊具で遊ばせる** → キッズランドUS 兵庫伊丹店（平日 お子様1日パック1,000円・保護者様1日パック700円）
- **夕方以降も遊ばせたい** → こらくるは20時まで（保護者同伴でない小学生は17時まで）、キッズランドUSも20時まで

## 冬の雨・寒い日のコツ

- **年末年始（12/29〜1/3）は公的施設がすべて休み**：こらくる・きららホール・こども文化科学館・伊丹市昆虫館は、いずれも12月29日〜1月3日が休みです。キッズランドUSの年末年始の営業は公式で確認できませんでした
- **曜日で休みが違う**：火曜はこらくる・こども文化科学館・昆虫館が休み、水曜はきららホールが休み。火曜は公的施設のうちきららホールだけが開館日
- **車で行くなら駐車場を先に確認**：こども文化科学館は駐車場なし、昆虫館は昆陽池公園駐車場（有料）から公園の中を10分ほど歩きます
- **12月の日曜・祝日の朝は科学館のちびっこ投影**：「サンタクロースのわすれもの」は12月20日まで、日曜・祝日の10時から

## よくある質問

### Q. 伊丹市で無料の室内遊び場は？

A. **伊丹市立児童会館こらくる（1階と屋外）と、きららホールのゆうぎしつ・にゅうじしつ**が、公式に無料と記載されています。年齢つきの無料なら、**伊丹市昆虫館は0〜2歳、こども文化科学館は3歳未満**が無料です。

### Q. 0歳を連れて行けるところは？

A. **こらくる**には乳幼児などが過ごせるすくすくルームと授乳室があります。**きららホール**にはにゅうじしつがあります。有料施設でも、**キッズランドUS 兵庫伊丹店は0歳無料**で、ベビーコーナーと授乳室があります。

### Q. 年末年始（12月29日〜1月3日）に開いているところは？

A. 公的施設（こらくる、きららホール、こども文化科学館、伊丹市昆虫館）は、この期間はいずれも休みです。キッズランドUS 兵庫伊丹店の年末年始の営業は公式に記載を確認できませんでした。出かける前に店舗の公式ページで確認してください。

### Q. 伊丹市にボーネルンド（キドキド）はある？

A. ボーネルンドの公式店舗一覧（2026年11月9日確認）に、**伊丹市の店舗は掲載されていません**。近くでは「あそびのせかい 大阪国際空港店」がありますが、所在地は大阪府豊中市（大阪国際空港 北ターミナルビル4階）です。くわしくは[豊中市の子連れ室内遊び場](/article/shitsunai-asobi-toyonaka)で紹介しています。

### Q. 伊丹駅から行きやすいところは？

A. **こども文化科学館**はJR伊丹駅から徒歩17分、JR・阪急伊丹駅から市バスで「神津」下車すぐです。**こらくる**は両伊丹駅5番のりばから市バスで「鈴原町1丁目」下車、徒歩4分。**伊丹市昆虫館**は両伊丹駅から市バスで「松ヶ丘」か「玉田団地」下車です。
