## 結論｜開始時期

| 形態 | 開始時期 |
| --- | --- |
| 湯むき・種取り・刻み | **5〜6ヶ月** |
| 皮あり・刻み（5mm角） | 1歳〜 |
| 4等分カット | 1歳半〜 |
| 半分カット | 4〜5歳〜 |
| **丸ごと（そのまま）** | **5歳以降、噛みきれる子のみ** |

## なぜ丸ごとは超危険？

- **誤嚥窒息事故の最頻出食材**：保育園での死亡事例も複数発生
- 球状・つるつる・適度なサイズで気管をぴったり塞ぐ
- 消費者庁・日本小児科学会が繰り返し注意喚起
- 「節分の豆」「ぶどう」「ミニトマト」が三大窒息食材
- 4等分以上に切ることで断面がフラットになり詰まりにくい
- 5歳未満は**丸ごと絶対NG**

## 月齢別の進め方

### 〜4ヶ月

- 与えない

### 5〜6ヶ月

- 湯むきして種を取り、すりつぶしてペースト
- 加熱推奨（皮・酸味を和らげる）
- 小さじ1から

### 7〜8ヶ月

- 湯むき・種取り後、細かく刻む
- 生でも可（よく洗って）
- ヨーグルトや豆腐に混ぜて

### 9〜11ヶ月

- 湯むき・種取り後、5mm角
- ナポリタンやリゾットの具に

### 1歳〜

- 皮ありでも刻めば可（5〜7mm）
- 縦半分→さらに半分の4等分
- 必ず4等分以上に切る

### 1歳半〜3歳

- **必ず4等分カットを徹底**
- 半分カットでもまだ大きい
- 大人の目の届く範囲で

### 4〜5歳

- 半分カットOK
- ただし丸ごとはまだ避ける

### 5歳以降

- 噛みきれる子なら丸ごと可
- ただし「飲み込まずよく噛む」を徹底
- 食事中に走らせない・笑わせない

## 誤嚥対策（最重要）

### 必ず4等分

- 縦半分 → さらに横半分
- 断面がフラットになり気管を塞がない
- 半分カットでは球面が残るので不十分

### 食事姿勢

- 必ず座って食べる
- 歩きながら・走りながらは絶対NG
- 仰向け・寝転がりも危険
- 大人と目線を合わせて

### 食べる時の見守り

- 大人が必ずそばで見る
- テレビ・スマホを見ながらは咀嚼が疎かに
- 「もぐもぐしようね」と声かけ
- 口の中いっぱいに詰め込ませない

### 万一の時

- 背中をたたく（背部叩打法）
- 1歳未満は胸部突き上げ
- 1歳以上はハイムリック法
- 意識を失ったら119番

## 与え方のコツ

### 皮の扱い

- 湯むき：沸騰湯に10秒→冷水
- 包丁で十字に切れ目→剥きやすい
- 1歳までは湯むき推奨
- 1歳以降は皮ありでも消化可

### 酸味対策

- 加熱で酸味マイルドに
- チーズと組み合わせ
- 卵料理に混ぜる
- ナポリタン・オムレツの具

### 種の扱い

- 1歳までは取った方が消化良い
- 1歳以降は気にしなくて可
- 種が苦手な子も多い

## 量の目安

| 年齢 | 1日の目安 |
| --- | --- |
| 5〜6ヶ月 | 大さじ1まで（ペースト） |
| 7〜8ヶ月 | プチトマト2〜3個分（刻み） |
| 9〜11ヶ月 | 3〜4個分 |
| 1〜2歳 | 4〜5個（4等分） |
| 3〜5歳 | 5〜6個（4等分） |
| 6歳〜 | 7〜10個 |

## アレルギー対策

### トマトアレルギー

- 仮性アレルゲン反応が多い
- ヒスタミン・サリチル酸への反応
- 口の周りの赤み（接触性）

### 症状

- 口の周り・唇の赤み
- 蕁麻疹
- 嘔吐・下痢
- 重篤時はアナフィラキシー

→ 出たら受診。

### 初めての時

- 加熱から始める（仮性アレルゲン低減）
- 少量から
- 平日午前に

## 注意点・避けたい場面

- お弁当に丸ごと入れない（必ず4等分）
- 保育園・幼稚園では切って提供されているか確認
- BBQ・ピクニックでの楊枝刺しも危険
- パーティーの飾りで丸ごと出さない
- カットしたものは雑菌繁殖しやすいので当日中に

## 栄養価

### リコピン豊富

- 抗酸化作用
- 加熱・油と一緒で吸収率UP
- ナポリタンは理にかなった食べ方
- 子どもの免疫力サポート

### ビタミン・ミネラル

- ビタミンC・E
- カリウム
- 食物繊維（皮に多い）
- 大きいトマトより栄養密度高い

## 選び方

- ヘタが緑で元気なもの
- 皮にハリがあるもの
- 色が均一なもの
- 国産・無農薬が安心
- できれば購入後3日以内に

## 我が家のリアル

息子6ヶ月で湯むきペーストデビュー。最初は酸味で「うえ〜」という顔をしましたが、徐々に慣れて。

1歳半の保育園入園の時、先生から「プチトマトは必ず4等分で」と厳しく言われ、お弁当の作り方を改めました。ある日急いで半分カットで出してしまい、息子が「変なの〜」と言ってちゃんと噛んでくれたので冷や汗。

3歳の時、お友達の家のパーティーで丸ごとプチトマトが出ていてビックリ。すぐにカットさせてもらいました。**「カットされていなかったら絶対食べさせない」**が我が家のルール。

## まとめ

- 5〜6ヶ月から湯むきペーストで可
- **丸ごとは5歳まで絶対NG**
- 1歳〜は必ず4等分カット
- 縦半分→横半分の十字切り
- 食事中は必ず座って大人が見守る
- リコピン豊富で栄養価高い
