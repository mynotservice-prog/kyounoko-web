## 結論（時期・必要なもの）

「やめる」は**「逃げ」ではなく「次への一歩」**。**本人の気持ちを否定せず、原因を整理し、家族で話し合う**のが鉄則。**1か月の休会・体験**を挟んでから最終判断するのも賢明。先生への連絡は**正直に・感謝を込めて・規約通り**に行いましょう。

- 向いている人：子が「やめたい」と言い始めた、親も迷っている
- 向いていない人：始めたばかりで判断早すぎ（1〜3か月は様子見）

## いつやる？目安

### 「やめどき」を検討するタイミング

- **本人が長期間嫌がる（2〜4週間以上）**
- **体調・精神面に悪影響が出ている**
- **目標を達成した・次のステップに進みたい**
- **家計や送迎が家族の負担になっている**

### 急いで決めないほうが良い場面

- **発表会・試合の直前**：終わってから決める
- **新しい先生・コーチに変わった直後**：慣れる時間を
- **本人の体調不良時**：回復後に話し合う

## 準備するもの

### 話し合い前の整理

| アイテム | 内容 |
| --- | --- |
| 家族会議メモ | 続ける/やめる理由を列挙 |
| 振り返りノート | 本人の言葉を残す |
| 退会規約 | 月謝・連絡時期確認 |
| 次の選択肢 | 別の習い事・休止期間 |

## 声かけのコツ

### 本人への声かけ（NG/OK）

| シチュエーション | NG | OK |
| --- | --- | --- |
| 「やめたい」と言われた時 | 「せっかく続けたのに」 | 「そう思ったんだね、何があった？」 |
| 理由を聞く時 | 「ちゃんと話して」 | 「ゆっくりでいいよ、いつでも聞くから」 |
| 一度休む提案 | 「逃げないで」 | 「1か月休んで考えてもいいよ」 |
| 決断後 | 「もっと頑張れたかも」 | 「よく考えたね、次は何やってみたい？」 |

### 言葉の組み立て

1. **共感**：「やめたいって思ったんだね」
2. **質問**：「何が一番つらかった？」
3. **選択肢提示**：「休む、辞める、続ける、どれが一番気持ちが楽？」
4. **尊重**：「あなたが決めていいよ」
5. **次の一歩**：「決めたら、先生にちゃんと伝えようね」

## 判断軸の整理

### 続けるべきサイン

- **「やめたい」が一時的（数日〜2週間）**
- 発表会・試合の直前で緊張から
- 友達関係のトラブルが解決可能
- 上達を感じている

### やめるべきサイン

- **2〜4週間以上「行きたくない」が続く**
- **体調・睡眠・食欲に悪影響**
- 教室の雰囲気・指導が合わない
- 親も家族も負担を感じている
- 目標を達成した

## 先生への連絡

### タイミング

- **退会希望月の前月15日まで**が一般的（規約確認）
- **電話 or 教室で直接**が丁寧
- **メール・LINE**は最後の手段

### 伝え方の例

> 「いつもお世話になっております。◯◯の母です。突然のご連絡で申し訳ありませんが、◯月末で退会させていただきたくご連絡いたしました。◯◯（先生のお名前）にはたくさんのことを教えていただき、本人も親も感謝しております。最後まで通わせていただきますので、よろしくお願いいたします。」

### NG表現

- 「先生のせいで」
- 「教室が悪い」
- 「お金がかかるから」（家計の話は伏せて）

## 当日の流れ（退会日）

| 時間 | 内容 |
| --- | --- |
| 朝 | 本人と「今日が最後」を確認 |
| 出発 | 普段通り、特別感は出さない |
| レッスン | 普段通り受講 |
| 終了 | 先生・お友達にお礼 |
| 帰宅 | 振り返り、ねぎらいの言葉 |

## 服装のポイント

最後のレッスンも**普段通り**でOK。特別な格好をすると逆に本人が緊張するので、いつもの服装を。

## 写真撮影のコツ

最後の日を記念に残したい場合：

1. **教室の入り口で「ありがとう」ショット**
2. **先生との2ショット**（許可を取って）
3. **使い慣れた道具と一緒に**
4. **動画メッセージ**：「これまでの感想」を1分

## やめた後のフォロー

### その後のケア

- **次の習い事をすぐ探さない**（一旦休む期間が大事）
- **本人の話を聞く時間を増やす**
- **「やめてよかったね」**は1か月後に
- **後悔の言葉が出たら共感**

### 後悔した場合

- 「もう一度やりたい」と言ったら受け止める
- 復会できる教室なら相談
- 別の選択肢も提案

## 我が家のリアル

長女のピアノは**半年で「やめたい」**と言われ、1か月の休会を提案しましたが、本人の意思は固く退会。

正直、月謝1万円の楽器も買った後で「**勿体ない**」と思いましたが、**本人のメンタルが何より大切**と腹を括りました。先生に電話で「本人と話し合った結果」と正直に伝え、規約通り月末で退会。

その後、本人は**「ピアノは辞めて正解だった、スイミングは続けたい」**と自分で言うように。**選ぶ力を育てる経験**になったと今では思います。

辞めた後の1か月は何もせず、本人の様子を見守りました。

## まとめ

- 「やめる」は**逃げではなく次への一歩**
- **本人の気持ちを否定しない**
- **1か月の休会**を挟んでから判断
- 先生へは**規約通り・感謝を込めて**
- **やめた後のフォロー**も大切
- **選ぶ力を育てる経験**として活かす
