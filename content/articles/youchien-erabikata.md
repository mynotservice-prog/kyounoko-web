## 結論（時期・必要なもの）

幼稚園選びは**「教育方針・通園距離・預かり時間・費用・園の雰囲気」**の5軸で比較。**3歳の誕生月から動き出し、満3歳児クラスまたは年少から入園**が一般的。**見学3〜5園・説明会2〜3園・最終決断1園**のステップで進めましょう。

- 向いている人：来年度入園、複数園で迷っている
- 向いていない人：保育園希望（[保育園 選び方](/article/hoikuen-erabikata)へ）

## いつやる？目安

### 年間スケジュール（来年4月入園の場合）

| 時期 | やること |
| --- | --- |
| 4〜5月 | 情報収集、園リストアップ |
| 6〜7月 | 見学申込、説明会参加 |
| 8〜9月 | 体験入園、家族会議 |
| 10月 | 願書提出（私立は10月1日が多い） |
| 11〜12月 | 面接・選考 |
| 1〜2月 | 合格発表、入園準備 |
| 3月 | 説明会、グッズ購入 |
| 4月 | 入園式 |

> ※地域差あり：**都市部の人気園は願書受付に徹夜列**、**地方は通年募集**、と差が大きい。

## 準備するもの

### 情報収集ツール

| ツール | 内容 |
| --- | --- |
| 自治体の幼稚園一覧 | 自治体HPから |
| 園のHP・SNS | 雰囲気を掴む |
| 口コミサイト | 「みんなの幼稚園情報」「ウィメンズパーク」 |
| 在園児ママ友 | 生の声 |

### 比較表テンプレート

- 園名・住所・通園時間
- 公立/私立、定員、保育料
- 預かり時間（標準・延長）
- 教育方針・特色
- 給食/お弁当
- 制服/私服
- バス有無
- 行事頻度
- 親の出番（PTA）

## 選び方の5軸

### 1. 教育方針

| タイプ | 内容 |
| --- | --- |
| のびのび系 | 自由遊び中心、外遊び豊富 |
| 学習系 | 英語・読み書き・体操に注力 |
| モンテッソーリ | 自主性重視、教具中心 |
| 仏教・キリスト教系 | 宗教教育を含む |
| 自然体験系 | 森のようちえん、農業体験 |

### 2. 通園距離・方法

- **徒歩**：15分以内が理想
- **バス**：園バス利用なら範囲拡大可
- **自転車・車**：駐輪場・駐車場の有無確認

### 3. 預かり時間

- **標準**：9〜14時
- **延長保育**：朝7時半〜夕方18時の園も増加
- **長期休暇預かり**：夏休み・冬休み中の対応

### 4. 費用

- **公立**：月10,000円前後（無償化対象）
- **私立**：月25,000〜40,000円（無償化で月25,700円補助）
- **追加費**：制服・教材・送迎バス・行事
- **無償化**：満3歳の4月から月25,700円補助

### 5. 園の雰囲気

- 子供たちの表情
- 先生の対応
- 教室の整理整頓
- 親同士のコミュニティ

## 当日の流れ（見学日）

| 時間 | 内容 |
| --- | --- |
| 出発前 | チェックリスト準備、メモ帳 |
| 到着 | 受付、自己紹介 |
| 説明 | 園長 or 主任の話 |
| 見学 | 教室・園庭・給食室 |
| 質疑 | 気になることを質問 |
| 帰宅 | 即座にメモ整理 |

## 見学チェックリスト

### 環境

- 教室の広さ・採光
- 園庭の広さ・遊具
- トイレの清潔さ
- セキュリティ（門・防犯カメラ）
- 駐車場・駐輪場

### 先生

- 笑顔で対応しているか
- 子供との距離感
- 先生の人数と年齢層
- 離職率（質問してOK）

### 子供たち

- 表情は明るいか
- お友達と関われているか
- 自由遊びの様子

### 食事

- 給食 or お弁当
- アレルギー対応
- おかわりルール

### 行事

- 年間行事の頻度
- 親の出番回数
- PTAの活動範囲

## 服装のポイント

### 親

- **きれいめ普段着**（スーツ不要）
- **歩きやすい靴**
- **メモが取りやすい服**

### 子（同伴の場合）

- **動きやすい服**
- **着替え持参**

## 写真撮影のコツ

園内撮影は禁止が多い。**外観・園庭・看板**程度で。
帰宅後に**チェックリストを清書**して比較表にまとめましょう。

## 説明会の回り方

### 効率的な回り方

- **同じ日に2園回る**のは厳しい、1日1園推奨
- **平日午前**の説明会が落ち着いて聞ける
- **質問リスト**を事前準備
- **夫婦どちらかが行く**より両方で行く

### 質問例

- 入園後の慣らし保育期間
- 病気時の対応
- アレルギー対応
- 写真ビデオ撮影ルール
- 親のLINEグループ有無

## 願書提出のコツ

### 私立

- **10月1日朝に願書受付**が多い
- **人気園は前日からの列**も
- **2〜3園併願**も検討

### 公立

- 通園区域指定が多い
- 自治体経由で申込

## 我が家のリアル

長女の幼稚園は**見学5園・説明会3園・体験2園**を経て、自宅から徒歩10分の私立に決定。**「子供がのびのびできる園庭の広さ」**を最優先しました。

正直、人気園は10月1日の願書取得競争で**朝5時から並ぶ**羽目に。願書取得後、**面接で園長と相性を確認**して納得の決断。

月謝は3万円ですが、無償化で実質4,300円程度に。**「教育方針・通園距離・親同士のコミュニティ」**の3点が決め手でした。

次男は**長女と同じ園**で兄弟枠を活用。見学不要で楽でした。

## まとめ

- 幼稚園選びは**5軸**で比較
- **3歳の春から動き出し**、10月願書提出
- **見学3〜5園・説明会2〜3園**
- **公立は月1万、私立は月3万＋無償化**
- 願書受付の徹夜列対策
- 地域差あり、自治体ルールを必ず確認
