## 結論

| 形態 | 開始時期 |
| --- | --- |
| 粒（そのまま） | **5歳以降** |
| 砕いた・刻んだ | 3歳以降、よく噛める子のみ |
| ペースト・粉末 | 9〜11ヶ月から少量可 |

## なぜ5歳までNG？

- **誤嚥・窒息リスク**：気管に入りやすい大きさ・硬さ
- 消費者庁は「硬い豆やナッツ類は3歳まで、できれば5歳まで与えない」と注意喚起
- 噛む力・飲み込みのコントロールが未熟
- 笑った瞬間・泣いた瞬間に気管に入りやすい

## 月齢別の進め方

### 〜6ヶ月

- 与えない

### 7〜8ヶ月

- 基本は与えない
- アーモンドミルクなど飲料は薄めて少量から検討（医師相談推奨）

### 9〜11ヶ月

- アーモンドパウダー・きな粉のような粉末状なら少量可
- ヨーグルトや離乳食に少し混ぜる
- 1種類ずつ試す

### 1〜2歳

- ペースト・パウダー状でOK
- アーモンドバター・カシューペーストを少量
- 粒はまだNG

### 3〜4歳

- よく刻んだ状態で少量
- お菓子に砕いて入っている程度は可
- 粒のまま食べさせない

### 5歳以降

- 粒のままでも可
- ただし座って落ち着いて食べる習慣を

## ナッツの種類と特徴

| 種類 | 特徴 | 注意 |
| --- | --- | --- |
| アーモンド | カルシウム豊富 | アレルギーあり |
| くるみ | オメガ3豊富 | アレルギー多い |
| カシューナッツ | 甘み強い | アレルギーあり |
| マカダミア | 高カロリー | 油っぽい |
| ピスタチオ | 殻に注意 | アレルギーあり |
| ヘーゼルナッツ | 香ばしい | アレルギー多い |

## 量の目安

| 年齢 | 1日の目安 |
| --- | --- |
| 9〜11ヶ月 | 粉末を耳かき1杯 |
| 1歳 | 小さじ1/4 |
| 2歳 | 小さじ1/2 |
| 3〜4歳 | 刻んだもの小さじ1 |
| 5歳以降 | 粒で5〜7粒 |

## アレルギー対策

### ナッツアレルギーは重篤化しやすい

- 木の実類は特定原材料に準ずる品目（くるみは2025年から特定原材料に）
- アナフィラキシーリスクあり
- 種類ごとに反応が違うことも

### 初めての与え方

- 平日午前中
- ごく少量（耳かき1杯）から
- 1種類ずつ試す（アーモンドを試した日にカシューはNG）
- 単独で

### 症状

- 口の周りの赤み
- 蕁麻疹
- 嘔吐・下痢
- 呼吸困難

→ 出たらすぐ受診。呼吸器症状あれば救急車。

## 注意点・避けたい場面

- 粒のまま食べさせるのは5歳から
- お菓子・パンに混ざっている粒にも注意
- 寝ながら・歩きながら食べさせない
- 兄姉が食べていても下の子に渡さない
- ピーナッツ（マメ科）とナッツ（木の実）は別だが、両方リスク高

## 我が家のリアル

息子1歳でアーモンドパウダーをヨーグルトに混ぜてデビュー。粒は3歳まで完全NGにし、お菓子の原材料も「ナッツ含む」は避けていました。3歳半でクッキーに刻んで入っているもの解禁。粒のまま渡すのは年中になってからにする予定です。

ママ友の子はくるみアレルギーが判明。検査後、家族でくるみ製品を全部チェックして除去しました。「メーカー違いで原材料変わることも」と聞いてからは毎回ラベル確認しています。

## まとめ

- 粒は5歳まで誤嚥リスクでNG
- ペースト・粉末なら9〜11ヶ月から少量
- 初めては1種類ずつ・平日午前中
- アレルギーリスク高い食材
- 兄姉のおやつにも注意
