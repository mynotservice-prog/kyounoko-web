## 結論｜早見表

| 軸 | 楽天市場 | Amazon |
| --- | --- | --- |
| **価格** | セール時最安 | 通常価格安い |
| **ポイント** | 楽天ポイント（SPUで最大15倍） | Amazonポイント（少なめ） |
| **配送** | 店舗による（送料有料も） | プライム会員は即日無料 |
| **品揃え** | 国内ブランド豊富 | 海外含めて圧倒的 |
| **定期便** | 各店舗の定期購入 | 定期便おトク（5〜15%割引） |
| **セール** | 楽天スーパーSALE等 | プライムデー・ブラックフライデー |

**結論的に**：
- **楽天SPU高い人** → 楽天メイン
- **プライム会員** → Amazon メイン
- **両方併用が最強**（私の推奨）

## カテゴリ別の使い分け

### おむつ（高頻度購入）

→ **Amazon定期便が最強**

- 15%割引で月3,000円程度
- 自動配送で買い忘れなし
- 楽天は送料考慮するとAmazonより高め

### 離乳食・ベビーフード

→ **どちらでも**

- 楽天：レビュー多い・店舗豊富
- Amazon：プライム配送即日

### ベビー服・キッズ服

→ **楽天メイン**

- 国内ブランド豊富
- ポイントUP高い
- セール時にまとめ買い◎

### 絵本

→ **楽天 or 紀伊國屋等**

- 楽天ブックスでポイント付与
- Amazonは送料無料の絵本セット強い

### おもちゃ・知育玩具

→ **Amazon メイン**

- 品揃え豊富
- レビューが信頼できる
- 海外輸入品もある

### 大型家具・ベビーカー

→ **楽天メイン**

- 取扱店舗豊富
- セール価格大幅割引
- ポイント還元大きい

## 6項目で徹底比較

### 1. 価格

#### 楽天市場

- **セール時最強**（スーパーSALE・お買い物マラソン）
- 通常時はやや高め
- 送料が店舗ごと

#### Amazon

- **通常時の安定価格**
- プライム会員送料無料
- セールは年数回

### 2. ポイント

#### 楽天

- 楽天ポイント1%＋SPU倍率
- **SPU最大15倍**（楽天サービス利用で）
- ふるさと納税・楽天証券との連携

#### Amazon

- Amazonポイント0.5〜2%
- ポイント期待は薄い
- 「価格」で安さを訴求

### 3. 配送

#### 楽天

- 店舗ごとに送料・配送日異なる
- 「あす楽」対応店舗もあり
- 送料無料は店舗による

#### Amazon

- **プライム会員：即日・翌日無料**
- 非会員でも2,000円以上送料無料
- 全国配送が安定

### 4. 品揃え

#### 楽天

- 国内ブランド豊富
- 専門店の品揃え◎
- 中小企業の独自商品

#### Amazon

- **品揃え量No.1**
- 海外商品も豊富
- 並行輸入品も

### 5. 定期便

#### 楽天

- 各店舗の定期購入
- 割引率は店舗による
- 解約は店舗連絡

#### Amazon

- **定期便で5〜15%OFF**
- 自動配送
- いつでも解約可

### 6. セール

#### 楽天

- 楽天スーパーSALE（年4回）
- お買い物マラソン（毎月）
- ブラックフライデー

#### Amazon

- プライムデー（年1回）
- ブラックフライデー（11月）
- タイムセール祭り（毎月）

## 楽天SPU活用法

楽天SPU（スーパーポイントアップ）でポイント最大化：

| SPU項目 | 倍率 |
| --- | --- |
| 楽天モバイル | +4倍 |
| 楽天カード | +2倍 |
| 楽天市場アプリ | +0.5倍 |
| 楽天ブックス | +0.5倍 |
| 楽天Pasha | +0.5倍 |

**最大15.5倍（2026年5月時点）**。10万円の買い物で15,500ポイント。

## Amazonプライム活用法

年会費5,900円（または月額600円）：

- 配送無料・即日
- Prime Video（動画見放題）
- Prime Music（音楽聴き放題）
- Prime Reading（電子書籍）
- Amazon Photos（無制限保存）

**月1〜2回利用で元取れる** 計算。

## 使い分けの理想形

### 楽天で買うもの

- ベビー服・子ども服
- 絵本・書籍
- ベビーカー・家具（セール時）
- ふるさと納税
- イオン・西友なら → 別途

### Amazonで買うもの

- おむつ（定期便）
- 飲み物・お米・水
- 知育玩具
- 急ぎ便利用品

### 直接店舗で買うもの

- 試着が必要な物
- 生鮮食品
- 大型家具（配送料考慮）

これに合わせて **大きな買い物を計画的に** 行うとお得。

## 我が家のリアル

- 楽天モバイル＋楽天カード＋楽天証券＋楽天市場で **SPU 10倍程度**
- Amazon プライム会員（おむつ定期便メイン）
- 月の合計購買額：楽天3万円・Amazon1.5万円
- 年間ポイント還元：約8万円分

両方併用が **最強コスパ** という結論。

## まとめ

「楽天 vs Amazon」は **使い分け** が正解。

- 高頻度購入＋即日配送 → Amazon
- ポイント貯める＋セール買い → 楽天
- 両方併用がコスパ最強
- 子育てカードと組み合わせて最大化
