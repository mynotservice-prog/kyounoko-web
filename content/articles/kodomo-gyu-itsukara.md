## 結論

| 形態 | 開始時期 |
| --- | --- |
| 赤身ミンチ（完全加熱） | **9〜11ヶ月** |
| 薄切り（柔らかい部位） | 1歳〜 |
| ステーキ（柔らかい部位） | 1歳半〜 |
| 焼肉カルビ | 2歳〜 |
| レア・生肉 | **絶対NG** |

## なぜ離乳食後期から？

- 鶏肉・豚肉に慣れた後に導入が推奨
- 牛肉は脂質・鉄分が豊富
- 鉄分は離乳食後期から不足しがち
- 完全加熱必須（O157等のリスク）

## 月齢別の進め方

### 〜8ヶ月

- 与えない
- 鶏ささみ・白身魚から

### 9〜11ヶ月

- 赤身ひき肉を細かくほぐして
- 完全加熱（中心まで）
- 少量から（小さじ1）

### 1歳〜1歳半

- 薄切り（しゃぶしゃぶ用）
- 細かく切って煮込み
- ハンバーグ・ミートボール

### 1歳半〜2歳

- ステーキを薄く切って
- 焼肉ロース・ハラミ
- 柔らかい部位を選ぶ

### 2〜3歳

- カルビなど脂多い部位も少量
- ローストビーフは完全加熱なら可

### 3歳以降

- 通常量に近づく
- ステーキはしっかり焼く（ウェルダン）

### 5歳〜

- ミディアム可（ただし安全な店で）
- レアは控えめ

## 部位別判断

| 部位 | 目安 | 特徴 |
| --- | --- | --- |
| ひき肉（赤身） | 9〜11ヶ月 | 離乳食定番 |
| もも・ヒレ | 1歳〜 | 赤身・低脂質 |
| 肩ロース | 1歳〜 | バランス良い |
| サーロイン | 1歳半〜 | 脂多め |
| カルビ | 2歳〜 | 脂多い |
| ハラミ | 2歳〜 | 柔らかい |
| バラ | 2歳〜 | 脂多い |
| タン | 3歳〜 | 噛みきれるサイズで |
| レバー | 1歳〜 | 鉄分豊富・少量 |

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 9〜11ヶ月 | 10〜15g |
| 1歳 | 15〜20g |
| 2〜3歳 | 30〜50g |
| 4〜5歳 | 50〜70g |

## 鉄分補給のポイント

- 牛肉のヘム鉄は吸収率が高い（15〜25%）
- 1歳前後は鉄欠乏性貧血が出やすい時期
- 週2〜3回は赤身肉を取り入れたい
- ビタミンC（ブロッコリー等）と一緒に
- レバーは特に鉄分豊富（週1〜2回）

## 調理のコツ

### 柔らかく仕上げる

- すりおろし玉ねぎ・りんごを加える
- 片栗粉でコーティング
- 短時間で焼く（焼きすぎ硬化）
- 圧力鍋で煮込み
- ヨーグルトに漬ける

### 完全加熱の目安

- 中心温度75℃1分以上
- 中心がピンクでない
- ミンチ・ハンバーグは特に念入りに

## アレルギー対策

### 牛肉アレルギー

- 比較的稀だが存在する
- 牛乳アレルギーと交差反応することも
- 初めては少量・午前中・単独で

### 症状

- 蕁麻疹
- 嘔吐・下痢
- 呼吸困難

→ 出たら受診。

## 食中毒対策（重要）

### 危険な食べ方

- レア・ユッケ・生肉
- 中心まで火が通っていない
- 古い肉・冷凍解凍ミス

### 安全に

- 信頼できる店・新鮮なもの
- 必ず完全加熱
- まな板・包丁の使い分け
- 手洗い徹底

## 注意点・避けたい場面

- ステーキはしっかり焼く（5歳までウェルダン推奨）
- 噛みきれないサイズはNG
- カルビは脂多くお腹こわすことあり
- 大人と同じ調味料は控える
- ハンバーグの中心がピンクなのは生焼け（要再加熱）

## お店デビュー

### しゃぶしゃぶ

- 1歳〜（しっかり加熱）
- しゃぶしゃぶ温野菜・木曽路など子連れ歓迎店

### ステーキ

- ステーキ宮・ビッグボーイ等は2〜3歳〜
- お子様ハンバーグ・お子様ステーキを活用

### 焼肉

- 3歳〜
- 詳しくは焼肉記事へ

## 我が家のリアル

息子9ヶ月で牛ひき肉デビュー。ハンバーグの中に細かくして混ぜて。1歳でしゃぶしゃぶ薄切りデビュー、柔らかくて食べやすそう。

1歳半でステーキ少量。ペッパーランチで薄切り肉プレートを取り分け。「美味しい！」と気に入って、その後ステーキ屋が定番に。

「鉄分のために牛肉週2回」を意識して、ハンバーグ・しぐれ煮・牛丼の素を活用。レバーは苦手なので、ハンバーグに少量混ぜ込んでいます。

## まとめ

- 9〜11ヶ月から赤身ミンチで
- 1歳から薄切りでステーキも
- 鉄分補給に週2〜3回が理想
- 完全加熱必須・レア禁止
- 部位は赤身から、脂多い部位は2歳〜
- ヘム鉄で貧血予防
