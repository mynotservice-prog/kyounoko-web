## 結論

| 部位 | 開始時期 |
| --- | --- |
| 麺（湯通しして短くカット） | **1歳〜** |
| スープ（薄めて少量） | 2歳〜 |
| 通常のラーメン1杯 | 3歳〜（半量） |
| 通常量 | 5〜6歳〜 |

## なぜスープは慎重に？

- **塩分過多**：1杯で5〜6g（子どもの1日目安を超える）
- **油・脂質**：豚骨・とんこつ系は特に多い
- **化学調味料**：刺激が強い
- **麺の誤嚥**：すすると気管に入りやすい
- **熱さ**：火傷リスク

## 月齢別の進め方

### 〜1歳

- 与えない
- 麺はうどん（柔らかく短く）から

### 1〜1歳半

- 中華麺を湯通し、塩分を流す
- 短く切る
- スープはなし、お湯で
- 少量から

### 1歳半〜2歳

- 麺を慣らす
- スープは数滴のみ

### 2〜3歳

- スープを薄めて少量
- 子ども用ラーメン（醤油・塩のあっさり系）

### 3〜4歳

- お店デビュー可（あっさり系・半量）
- 子ども用メニューを選ぶ

### 5〜6歳

- 通常量に近づける
- ただしスープは飲み干さない

## 量の目安

| 年齢 | 1食の目安 |
| --- | --- |
| 1歳 | 麺20〜30g・スープなし |
| 2歳 | 麺40〜50g・スープ少量 |
| 3〜4歳 | 大人の1/2杯 |
| 5〜6歳 | 大人の2/3杯 |

## 塩分対策

### 家でラーメンを作る時

- 麺を別茹でして塩抜き
- スープは規定量の半分
- 薄めるお湯を足す
- 具材で野菜を多めに
- 子ども用は別丼で

### お店で食べる時

- スープを飲み干さない（特に注意）
- 半玉・お子様サイズを選ぶ
- 醤油・塩から始める（味噌・豚骨は塩分高）
- お冷でスープを薄めるのも手

## 種類別の判断

| 種類 | 目安 | 注意 |
| --- | --- | --- |
| 醤油 | 3歳〜 | あっさり系で |
| 塩 | 3歳〜 | あっさり系 |
| 味噌 | 4歳〜 | 塩分・脂質高 |
| 豚骨 | 5歳〜 | こってり・脂質高 |
| 担々麺 | 6歳〜 | 辛い |
| 冷やし中華 | 3歳〜 | タレ薄めで |
| つけ麺 | 4歳〜 | タレ濃厚 |

## アレルギー対策

### ラーメンに含まれる可能性のあるアレルゲン

- 小麦（麺）
- 卵（麺・トッピング）
- 大豆（醤油）
- 乳（一部スープ）
- 甲殻類（一部）

### 初めての与え方

- 平日午前〜昼
- 少量から
- 既知の食材で試した後

## トッピング別の判断

| トッピング | 目安 |
| --- | --- |
| チャーシュー | 2歳〜（薄切り） |
| メンマ | 3歳〜（噛みきれる量） |
| 海苔 | 1歳半〜（小さく） |
| 味付け卵 | 2歳〜（半熟は3歳〜） |
| ネギ | 3歳〜（白ねぎ少量） |
| もやし | 2歳〜（噛み切れれば） |
| わかめ | 1歳半〜 |
| コーン | 1歳半〜 |
| バター | 2歳〜（少量） |

## 注意点・避けたい場面

- スープを飲み干させない
- 熱々のまま食べさせない（火傷）
- すすり方を教える（小さい子は噛み切る）
- 麺は短くカットして誤嚥防止
- カップラーメンは塩分高すぎ・4歳までは推奨しない
- 食後は水を多めに

## ラーメン屋デビューのコツ

- 平日のすいた時間
- お子様メニュー・ハーフサイズがある店
- カウンターより座敷・テーブル席
- あっさり系の店から
- お冷・お茶を多めにもらう
- 取り分け皿を頼む

## 我が家のリアル

息子1歳半で家ラーメンデビュー。湯通しした麺を3〜4cmにカット、スープなしで野菜とチャーシューを一緒に。2歳半でスープ少量解禁。

3歳でラーメン屋デビュー。あっさり醤油の子ども用ラーメンを半量。「美味しい！」と完食しましたが、スープは半分残させました。スープを飲み干すクセは大人になっても続くと聞いて、最初から「スープは飲まない」をルールに。

## まとめ

- 麺は1歳から（短くカット）
- スープは2歳以降・薄めて少量
- 3歳でお店デビュー可
- スープは飲み干さないルール
- カップラーメンは4歳まで控える
- 種類はあっさり系から
