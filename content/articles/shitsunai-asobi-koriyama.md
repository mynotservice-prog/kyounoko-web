## 期限つきの注意（2026年11月9日時点）

- **ペップキッズこおりやまの砂場は 2026年11月1日〜12月18日は使えません**（15周年リニューアルに向けた工事で完全封鎖）。
- **ペップキッズこおりやまは 2027年4月1日から有料**になります。子ども1人200円（0歳児を除く）、保護者1人200円（2026年9月時点で決定している内容。納入方法は未発表）。
- **スペースパークは 2027年1月18日〜22日が全館休館**（展望ロビーを含む）です。2027年4月1日から利用料金が変わります（宇宙劇場の幼児は100円→180円など）。

## 1. ペップキッズこおりやま（郡山市元気な遊びのひろば）｜無料・完全WEB予約制

郡山市が設置し、認定NPO法人郡山ペップ子育てネットワークが運営する屋内遊び場です。公式のよくある質問に**「駐車場・場内遊び場は無料でご利用頂けます」**と書かれています。

| 項目 | 内容 |
|---|---|
| 所在地 | 郡山市横塚1丁目1-3 |
| 対象 | 0歳から小学生以下と保護者（扶養者または20歳以上の親族）。保護者1名につき子ども3名まで |
| 料金 | **無料**（ペップキッチンは材料費500円）。**2027年4月1日から子ども200円（0歳児を除く）・保護者200円** |
| 利用時間 | 1日4クール・各75分（10:00〜11:15／12:00〜13:15／14:00〜15:15／16:00〜17:15。受付は各15分前から） |
| 予約 | 完全WEB予約制。利用希望日の1週間前の0時から、公式LINEか予約サイトで予約（1日1クールまで） |
| 休み | 毎月第2水曜とその翌日、第3水曜とその翌日、年末年始（12月31日〜1月3日） |

70平方メートルの砂場、三輪車のサーキット、赤ちゃん専用のベビーコーナーがあります。各クールの上限は250名です。**2026年11月1日〜12月18日は砂場が工事で封鎖**され、遊べません。

遊び場の中では、子どもは靴下を脱いで裸足で遊びます。場内での食事（アメ・ガム・離乳食を含む）はできず、飲み物はカフェスペース・受付周辺・ロッカースペースだけで飲めます。ミルクは授乳室やカフェスペースで、お湯は持参です。お友だちの子だけを連れて行くことはできません。郡山駅前（西口）からの路線バス（まちなか循環など）で「ペップキッズ前」下車です。詳細は[ペップアクティブの公式ページ](https://pep-kids-koriyama.com/active.html)と[よくある質問](https://pep-kids-koriyama.com/faq.html)で確認できます。

## 2. カルチャーパーク屋内子どもの遊び場｜無料・人工芝約2,470㎡

郡山カルチャーパークの中にある、全面人工芝の屋内遊び場です。運営する公益財団法人郡山市観光交流振興公社の公式ページに**「利用料金 無料」**と書かれています。

| 項目 | 内容 |
|---|---|
| 所在地 | 郡山市安積町成田字東丸山61（郡山カルチャーパーク内） |
| 対象 | 0歳から15歳（中学生）まで（未就学児は保護者同伴） |
| 料金 | **無料** |
| 利用時間 | 9:00〜17:00 |
| 休み | 毎週月曜（祝日の場合は翌日以降の平日）、年末年始（12月28日〜1月4日）。7月21日〜8月24日は無休 |
| 設備 | 屋内遊び場（人工芝 約2,470㎡）、キッズスペース（161㎡）、授乳室、多目的トイレ、子ども用便座 |

未就学児と小中学生で利用エリアが分かれています。キッズスペースには動物のぬいぐるみやソフト積み木、人工芝のエリアには竹馬、ターゲットボール、バランスボールなどの備え付けの遊具があります。遊具の持ち込みはできません。

人工芝のため飲食はできず、通路の一部での水分補給だけ可能です。土日祝と学校の長期休みには、小中学生向けにボールの貸し出しがあります。詳細は[郡山カルチャーパーク「屋内子どもの遊び場」](https://www.koriyamaculturepark.com/playground/)と[郡山市の公式ページ](https://www.city.koriyama.lg.jp/site/kosodate/1354.html)で確認できます。

福島県の一覧（2023年8月29日更新）では、広さ250平方メートル、乳幼児用のスペースを区分していると説明されています。屋外にはスカイデッキ（吊り橋・滑り台）や木製アスレチックがあります。指定管理者は学校法人国際総合学園、問い合わせ先は郡山青少年会館（024-961-8282）です。詳細は[郡山市の公式ページ](https://www.city.koriyama.lg.jp/site/kosodate/1356.html)と[福島県の施設ページ](https://www.pref.fukushima.lg.jp/sec/21055a/ko-riyama2.html)で確認できます。

## 5. スペースパーク（郡山市ふれあい科学館）｜有料・展示ゾーンは幼児無料

郡山駅西口のビッグアイ20〜24階にある、郡山市の科学館です（正式名称は高柳電設工業スペースパーク）。プラネタリウムの「宇宙劇場」と、体験型の「展示ゾーン」があります。

| 項目 | 内容 |
|---|---|
| 所在地 | 郡山市駅前2-11-1（ビッグアイ20〜24階） |
| 料金（個人・2027年3月31日まで） | 展示ゾーン：幼児 無料／小学生・中学生 200円／高校生・大学生等 300円／一般（65歳未満）400円。宇宙劇場：幼児 100円／小学生・中学生 200円／高校生・大学生等 300円／一般（65歳未満）400円 |
| 幼児の宇宙劇場 | 席を使わない場合は無料 |
| 開館時間 | 展示ゾーン 10:00〜17:45（入館17:00まで）。宇宙劇場 平日10:00〜16:15・金曜10:00〜19:45・土日祝10:00〜17:45 |
| 休み | 毎週月曜（祝日の場合は翌日）、年末年始。休館カレンダーでは2026年12月30日〜2027年1月3日が休館（1月1日は全館休館）、2027年1月18日〜22日は全館休館 |

**2027年4月1日から料金が変わります**。宇宙劇場は幼児180円・小中学生240円・高校生大学生等360円・一般600円、展示ゾーンは小中学生240円・高校生大学生等360円・一般600円（幼児は引き続き無料）です。宇宙劇場の料金は1回ごとで、各回入れ替え制です。

トイレにベビーベッドがあり、22階でベビーカーを貸し出しています。**専用駐車場はありません**（近隣の有料駐車場を自己負担。提携割引もなし）。JR郡山駅西口から徒歩約1分です。詳細は[スペースパークの利用案内](https://space-park.jp/guide/)と[2027年4月からの利用料金](https://space-park.jp/info/archives/202607/111100.html)で確認できます。

## 6. リトルプラネット MOLTI郡山｜有料・デジタル遊具の屋内パーク

郡山駅前のMOLTI郡山1階にある、砂遊びやぬりえなどの遊びにデジタル技術を組み合わせた屋内型のテーマパークです。

| 項目 | 内容 |
|---|---|
| 所在地 | 郡山市駅前2丁目11-1 MOLTI郡山1F |
| 平日料金 | 30分：こども（4〜12歳）700円・幼児（2・3歳）500円・おとな700円／60分：こども1,200円・幼児1,000円・おとな800円／1日フリーパス：こども1,800円・幼児1,600円・おとな900円 |
| 休日料金 | 30分：こども920円・幼児700円・おとな900円／60分：こども1,550円・幼児1,300円・おとな1,000円／1日フリーパス：こども2,600円・幼児2,300円・おとな1,300円 |
| 1歳以下 | 無料 |
| 営業時間 | 10:00〜18:00（最終受付17:30） |
| 休み | MOLTIの定休日に準じる（MOLTIの店舗ページに「11月の休館日はございません」と記載）。年末年始の営業は公式に記載を確認できませんでした |

入場には1家族（1グループ）につき代表者1名の**会員登録（年会費600円、翌年以降300円）**が必要です。**長期休暇中の営業は土日祝と同じ扱い**なので、冬休み中は平日でも休日料金になります。おとな1名につき同伴できる子どもは3名までです。当日券は受付で買えます。

JR郡山駅から徒歩1分です。提携駐車場はビッグアイ駐車場と郡山駅西口駐車場で、3,000円以上の支払いで1時間分が無料になります（営業時間10:00〜18:00）。詳細は[リトルプラネット MOLTI郡山の公式ページ](https://litpla.com/space/molti_koriyama/)と[MOLTIの店舗ページ](https://molti.jp/shop/shop7931/)で確認できます。

## 冬の雨・雪の日のコツ

- **年末年始は休みの幅が施設ごとに違う**：カルチャーパークは12月28日〜1月4日、大槻公園は12月29日〜1月3日、ペップキッズは12月31日〜1月3日、スペースパークは12月30日〜1月3日が休み。ペップキッズの公式の休館日（第2・第3水曜とその翌日、12月31日〜1月3日）には12月29日・30日は入っていません（予約制）
- **曜日で休みが違う**：月曜はカルチャーパーク・大槻公園・八山田こども公園・スペースパークが休み。ペップキッズは第2・第3水曜とその翌日が休み
- **ペップキッズは1週間前の0時から予約**：完全WEB予約制で、1日1クールまで。冬休みは早めに枠を確認する
- **ペップキッズの砂場は12月18日まで封鎖**：砂場目当てなら12月19日以降に
- **リトルプラネットは冬休み中は休日料金**：長期休暇中は土日祝と同じ扱いです
- **駅前の2つは駐車場に注意**：スペースパークに専用駐車場はなく、リトルプラネットは提携駐車場の割引（3,000円以上で1時間分）があります

## よくある質問

### Q. 郡山市で無料の室内遊び場は？

A. **ペップキッズこおりやま、カルチャーパーク屋内子どもの遊び場、大槻公園と八山田こども公園の体験学習施設**が無料と公式に記載されています。ペップキッズは2027年4月1日から有料（子ども200円・0歳児を除く、保護者200円）になります。スペースパークの展示ゾーンも幼児は無料です。

### Q. 0歳を連れて行けるところは？

A. **ペップキッズこおりやま**は0歳から使え、赤ちゃん専用のベビーコーナーと授乳室があります。**カルチャーパーク屋内子どもの遊び場**も0歳から対象で、キッズスペースと授乳室があります。リトルプラネットは1歳以下が無料です。

### Q. 年末年始（12月29日〜1月3日）に開いているところは？

A. **ペップキッズこおりやま**の公式の休館日は年末年始が12月31日〜1月3日で、12月29日・30日は休館日に入っていません（完全WEB予約制）。**スペースパーク**は休館カレンダーで12月29日が開館、12月30日〜1月3日が休館です。カルチャーパーク（12月28日〜1月4日）と大槻公園（12月29日〜1月3日）は休みです。リトルプラネット MOLTI郡山の年末年始の営業は公式に記載を確認できませんでした。

### Q. 郡山市にボーネルンド（キドキド）やザキッズはある？

A. ボーネルンドの公式店舗一覧（2026年11月9日確認）の「北海道・東北」には北海道の施設だけが載っており、**福島県の店舗はありません**。ザキッズの公式サイトの都道府県別一覧（同日確認）にも、福島県は含まれていません。

### Q. 郡山駅から歩いて行けるところは？

A. **スペースパーク**（JR郡山駅西口から徒歩約1分）と**リトルプラネット MOLTI郡山**（JR郡山駅から徒歩1分）です。どちらも有料です。ペップキッズこおりやまは郡山駅前（西口）から路線バスで「ペップキッズ前」下車です。
