## 結論｜ネグレクトの基本

- **意味**：必要な養育を行わないこと（育児放棄）
- **根拠法**：児童虐待の防止等に関する法律（児童虐待防止法）第2条
- **位置づけ**：児童虐待 **4類型のひとつ**（身体的・性的・心理的・ネグレクト）
- **相談先**：児童相談所虐待対応ダイヤル **189（いちはやく）**
- **悩んだとき**：自分自身が辛いときも相談できる
- **特徴**：見えにくく、当事者も気づきにくい

## ネグレクトとは何か

ネグレクトは、 **「保護者が子どもに必要な養育を行わないこと」** を指し、 **児童虐待防止法第2条第3号** に定められた児童虐待の4類型のひとつです。「育児放棄」と訳されますが、 **意図的な放棄だけでなく結果として養育が不十分になる場合も含む** 広い概念です。

### 児童虐待の4類型

| 類型 | 内容 |
| --- | --- |
| 身体的虐待 | 殴る・蹴る・激しく揺さぶる など |
| 性的虐待 | わいせつな行為をする・させる |
| **ネグレクト** | **養育を行わない・放置する** |
| 心理的虐待 | 言葉の暴力・無視・面前DV など |

## ネグレクトの主な種類

| 種類 | 内容 |
| --- | --- |
| 身体的ネグレクト | 食事・衣服・入浴など身体の世話を行わない |
| 医療ネグレクト | 必要な医療を受けさせない（予防接種・治療等） |
| 教育ネグレクト | 学校に行かせない・教育を受けさせない |
| 情緒的ネグレクト | 関心を示さず情緒的な関わりを持たない |
| 監督ネグレクト | 安全な環境を提供せず、長時間放置する |

## 気づきのサイン（早期発見の手がかり）

### 子どもに見られるサイン

- 季節に合わない衣服・不潔な様子
- 身体・髪・歯の手入れがされていない
- 痩せている・極端な体重減少
- 給食をがつがつ食べる
- 学校・園を頻繁に欠席
- 予防接種・健診を受けていない
- 家に帰りたがらない

### 家庭に見られるサイン

- 家の中が著しく不衛生
- 食料が常になく食事の準備がされていない
- 保護者が長時間不在
- 同年齢の子と比べ生活リズムが大きく乱れている

## 起こりやすい背景

ネグレクトは **特定の家庭だけでなく、誰にでも起こり得ます**。

- 産後うつ・育児うつ
- ワンオペ・孤立育児
- 経済的困窮
- 保護者の精神疾患・依存症
- 望まない妊娠
- DVを伴う家庭環境
- 保護者自身が虐待を受けて育った

## いつから注意？

**0歳から学齢期まで** あらゆる年齢で起こり得ます。乳児期はとくに **生命の危険** に直結するため、社会全体での見守りが重要です。

### 自分の家庭が心配なとき

### 周囲の子が心配なとき

- **児童相談所虐待対応ダイヤル：189（いちはやく）**
  - 24時間・通話料無料
  - 匿名通告OK
  - 守秘義務あり
- 警察（命の危険があるとき：110）

### 通告は「義務」

児童虐待防止法第6条で、 **児童虐待を発見した者は速やかに通告する義務** があるとされています。「確証がなくても」通告できます。

## メリット・デメリット（相談の効果）

| 早期相談のメリット |
| --- |
| 親子が孤立せず支援につながる |
| 子の発達・健康への影響を最小化できる |
| 保護者の状況も支援対象に |
| 一時保護・カウンセリングなど選択肢が広がる |

## 親側のSOSとしても

「育児が辛い」「子どもをかわいいと思えない」「無視してしまう」——これらの気持ちは **誰にでも起こり得るSOS**。 **189・子育て支援センター・保健師** へ早めに話すことで、 **ショートステイ・カウンセリング・経済支援** など複数の支援につながります。

## よくある質問

**Q1. 1日くらい放置したらネグレクト？**
1回の出来事ではなく **継続的な養育の欠如** が問題視されます。ただし乳児を1人にするのは短時間でも危険。

**Q2. ワンオペでつい怒鳴ってしまう。これは虐待？**
**怒鳴り続ける・無視を続ける** のは心理的虐待に該当することも。辛いと感じたら早めに相談を。

**Q3. 通告したら逮捕される？**
通告は **支援につなげる仕組み**。逮捕ありきではありません。

**Q4. 匿名で通告できる？**
**できます**。守秘義務もあります。

**Q5. ネグレクトされた子の発達への影響は？**
脳の発達・愛着形成・自己肯定感に影響することがあると報告されていますが、 **早期の介入と安定した環境で回復可能** とされています。

## 我が家のリアル

我が家もワンオペが続いた時期、 **「子どもの泣き声が聞こえなくなる瞬間」** が怖かった時期がありました。「ネグレクトなんて遠い話」と思っていたけれど、 **寝不足と孤立** が重なると誰にでも起こり得ると実感。私たちが救われたのは **子育て支援センター** の保健師さんでした。「辛いときは話していい」と何度も聞き、 **189番** の存在も保健師さんから教わりました。「親が壊れる前に助けを求める」のは正しい選択。 **「子が辛い」も「親が辛い」も、同じ窓口で受け止めてもらえる** ことを知っているのと知らないのでは、心の余裕が全く違います。

## まとめ

- ネグレクトは **児童虐待4類型のひとつ**（児童虐待防止法）
- **身体・医療・教育・情緒・監督** など複数の種類がある
- 誰にでも起こり得る・ワンオペや孤立がリスク
- 困ったら・気づいたら **189（いちはやく）**
- 親自身のSOSとしても活用できる
