## 結論（時期・必要なもの）

習い事を続けるコツは**「本人のやる気の波を受け入れる」「親が応援者に徹する」「無理に続けさせない」**の3点。**3か月・半年・1年**の節目で振り返り、家族で話し合うのが鉄則。**「続けること自体」が目的化しない**よう、本人の成長と楽しみを最優先にしましょう。

- 向いている人：習い事を始めて数か月、続けるか迷っている
- 向いていない人：始めたばかりで判断早すぎ

## いつやる？目安

### 続けるかの判断タイミング

| 時期 | 判断ポイント |
| --- | --- |
| 1か月 | まだ判断せず慣れる期間 |
| 3か月 | 楽しめているか、教室の雰囲気が合うか |
| 半年 | 上達を感じるか、本人が行きたがるか |
| 1年 | 続ける価値があるか、家族でレビュー |

## 続けるコツ

### 1. やる気の波を受け入れる

- **「行きたくない」週があって当然**
- **波を理解し、追い詰めない**
- **休みたい時は1回休んでOK**
- **続けたい時は応援**

### 2. 親は応援者・観客に徹する

- **「上手にやれ」より「楽しんでね」**
- **送迎・準備のサポートに徹する**
- **発表会・試合は応援に行く**
- **比較・批判はしない**

### 3. 小さな成長を一緒に喜ぶ

- **「先週できなかったことができた」**を見つける
- **写真・動画で成長を記録**
- **祖父母と共有して褒められる場を作る**

## 準備するもの

### 続ける仕組み

| 仕組み | 内容 |
| --- | --- |
| 振り返りノート | 月1で本人＋親で記入 |
| 送迎カレンダー | 夫婦で分担 |
| 練習動画アルバム | 成長を可視化 |
| 月謝管理表 | 家計と相談 |

### モチベ維持グッズ

- **習い事カレンダー**（出席シール）
- **小さなご褒美**（送迎帰りのジュースなど）
- **発表会の写真フレーム**
- **同じ習い事の友達**との交流機会

## 当日の流れ（習い事の日）

| 時間 | 内容 |
| --- | --- |
| 帰宅後 | おやつ＋休憩 |
| 出発前 | 準備物確認、トイレ |
| 移動中 | 励ましの一言 |
| レッスン中 | 親は待機 or 用事 |
| 帰宅 | 「どうだった？」軽く聞く |

## スランプ期の乗り越え方

### サインの見つけ方

- **「行きたくない」が続く**
- **練習を嫌がる**
- **泣く・口数が減る**
- **体調不良が増える**

### 対処法

1. **本人の話をじっくり聞く**
2. **教室の先生に相談**
3. **一時休会の検討**
4. **目標を小さく再設定**
5. **「やめる選択肢もある」と伝える**

## 服装のポイント

### 動きやすさ優先

- **ジャージ・スポーツウェア**
- **体育館用シューズ**は別途用意
- **着替え2セット**（汗対策）

### 季節別

- **夏**：吸汗速乾、帽子
- **冬**：上着、防寒小物
- **梅雨**：レインコート、タオル

## 写真撮影のコツ

### 撮影可能か確認

- **多くの教室は通常稽古は禁止**
- **発表会・試合は許可制**
- **個人撮影 vs 公式写真サービス**

### 撮れる範囲で

1. **教室の入り口で「行ってきます」**
2. **発表会の衣装**
3. **賞状・トロフィー**
4. **成長過程の動画**（自宅練習）

## 親の送迎負担を減らす工夫

### 工夫リスト

- **近所の教室を選ぶ**（移動15分以内）
- **夫婦で分担**
- **送迎付き教室を選ぶ**
- **複数の習い事を同じ建物で**
- **オンラインレッスン併用**

### 送迎時間の活用

- **本を読む・勉強する**
- **隣の保護者と情報交換**
- **散歩・運動**

## やめどきの判断軸

### 続けるべき場合

- 本人が「楽しい」と言う
- 上達を感じている
- 友達ができている
- 親も負担を感じていない

### やめてもいい場合

- 本人が長期間嫌がる
- 体調・精神面で悪化
- 家計を圧迫している
- 親が負担で家族が疲弊

> 「**続けたから偉い、やめたら負け**」ではない。本人の成長に必要かで判断を。

## 我が家のリアル

長女は**スイミング3年継続中**。途中「やめたい」期が2回ありましたが、**話を聞いて休会1か月**を挟んだら復活。今は週1のペースで楽しく通っています。

正直、**送迎が一番の負担**でした。共働きで土曜午前を確保する苦労が今でも続いています。それでも**「水に強い体」を獲得し、自分から泳げるようになった**達成感は本人の自信に。

ピアノは**半年で本人が辞めたい**と言い、あっさり辞めました。**「やめる選択肢」を残しておく**ことで親子の信頼関係が保てます。

## まとめ

- 続けるコツは**やる気の波を受け入れる**
- 親は**応援者・観客に徹する**
- **3か月・半年・1年**で振り返り
- **スランプ期は休会も選択肢**
- 送迎負担は**夫婦分担・近所選び**で軽減
- **やめる選択肢を残す**ことが続ける力に
