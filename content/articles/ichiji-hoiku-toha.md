## 結論｜一時保育の基本

- **一時保育とは**：保育園・認定こども園などで **一時的に子どもを預かるサービス**
- **対象**：在籍児以外も利用可（自治体・施設による）
- **料金**：1日 **2,000〜4,000円程度**（自治体補助で変動）
- **申し込み**：施設や自治体の窓口で事前登録→予約
- **利用理由**：就労・通院・冠婚葬祭・リフレッシュなど

## 一時保育とは何か

一時保育は **保育園・認定こども園・地域子育て支援拠点などで、一時的に保育を必要とする子どもを預かる事業** です。「一時預かり事業」とも呼ばれます。保育園に在籍していない家庭でも利用でき、家庭の状況に応じて柔軟に使えます。

### 主な利用理由

- **就労**：パート・短時間就労、就労継続
- **冠婚葬祭・通院**：単発の用事
- **育休中の上の子預け**：下の子の通院・体調回復
- **リフレッシュ**：保護者の心身ケア（自治体による）

## 制度の概要

### 預けられる時間

- 1日数時間〜終日まで（施設で異なる）
- 多くは **平日昼間** が中心
- 月単位で **利用可能日数の上限** を設定（例：月10日まで）

### 料金相場

| 区分 | 1日料金の目安 |
| --- | --- |
| 認可保育園の一時保育 | 1,500〜3,000円 |
| 認定こども園・私立 | 2,000〜4,000円 |
| 地域子育て支援拠点の一時預かり | 500〜1,500円 |
| 病後児・病児枠 | 2,000円〜（補助で軽減） |

給食費・おやつ代を別途徴収する施設もあります。

## 申し込み方法

### ステップ

1. **自治体や施設の情報収集**：自治体HPで実施施設リストを確認
2. **事前登録**：登録用紙・健康状況・かかりつけ医情報などを提出
3. **見学・面談**：施設によっては事前面談・慣らし利用が必要
4. **利用予約**：電話・WEBで予約（人気施設は競争率高）
5. **当日持参**：おむつ・着替え・哺乳瓶・水筒・連絡帳

### 必要書類

- 利用申込書／登録票
- 母子手帳の写し
- 健康保険証の写し
- 緊急連絡先

## 対象者・条件

- 0歳〜就学前の子ども（施設により0歳の月齢制限あり）
- 居住自治体内に住んでいること（区外利用可の自治体も）
- 健康状態が比較的安定していること
- 予防接種を一定程度受けていること

> **発熱・感染症の場合は利用不可**。病気のときは病児保育を利用しましょう。

## メリット・デメリット

| 項目 | 内容 |
| --- | --- |
| メリット | 単発で預けられる／料金が比較的安い／保育士による安心の保育 |
| デメリット | 予約が取りにくい／登録が必須／病気の子は預けられない／場所が遠い場合も |

## 似たサービスとの違い

| サービス | 違い |
| --- | --- |
| 認可保育園入所 | 継続的・毎日利用 |
| ベビーシッター | 自宅での個別保育、料金は高め |
| 病児保育 | 病気・回復期の子向け |
| ファミサポ | 地域住民の助け合い、自宅・送迎可 |
| 学童保育 | 小学生対象 |

## よくある質問

**Q1. 何日前から予約できる？**
施設により1か月前〜前日まで様々。人気施設は **予約開始日に電話殺到** することも。

**Q2. 0歳でも預けられる？**
生後57日〜6か月以降から対応する施設が多い。施設に確認を。

**Q3. 急な用事でも当日OK？**
原則は事前予約。空きがあれば当日対応の施設もあり。

**Q4. リフレッシュ理由でも使える？**
自治体・施設により「就労以外でも可」とされる場合あり。要確認。

**Q5. 慣らし保育は必要？**
初回は短時間からの慣らし利用が推奨されます。

## 我が家のリアル

我が家は娘の育休中、息子の通院に付き添うため一時保育を月3〜4回利用しました。事前登録が早めにできていたので、急な発熱以外は希望日に取れて助かりました。**「単発でも事前登録は早めに」** が我が家の鉄則。リフレッシュ目的でも気兼ねなく使えるのが、地域子育て支援拠点の一時預かりでした。30分単位で利用でき、保護者の休息にも子の社会経験にもなる「ちょうどいい預け先」として重宝しています。

## まとめ

- 一時保育は **単発で利用できる公的預かり事業**
- 料金は1日2,000〜4,000円程度
- 事前登録＋予約が基本
- 病気のときは利用不可
- リフレッシュ・通院・育休中の上の子対応に便利
