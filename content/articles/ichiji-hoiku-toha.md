## 結論｜一時保育の基本

- **一時保育とは**：保育園・認定こども園などで **一時的に子どもを預かるサービス**
- **対象**：在籍児以外も利用可（自治体・施設による）
- **料金**：1日 **2,000〜4,000円程度**（自治体補助で変動）
- **申し込み**：施設や自治体の窓口で事前登録→予約
- **利用理由**：就労・通院・冠婚葬祭・リフレッシュなど

## 一時保育とは何か

一時保育は **保育園・認定こども園・地域子育て支援拠点などで、一時的に保育を必要とする子どもを預かる事業** です。「一時預かり事業」とも呼ばれます。保育園に在籍していない家庭でも利用でき、家庭の状況に応じて柔軟に使えます。

### 主な利用理由

- **就労**：パート・短時間就労、就労継続
- **冠婚葬祭・通院**：単発の用事
- **育休中の上の子預け**：下の子の通院・体調回復
- **リフレッシュ**：保護者の心身ケア（自治体による）

## 制度の概要

### 預けられる時間

- 1日数時間〜終日まで（施設で異なる）
- 多くは **平日昼間** が中心
- 月単位で **利用可能日数の上限** を設定（例：月10日まで）

### 料金相場

| 区分 | 1日料金の目安 |
| --- | --- |
| 認可保育園の一時保育 | 1,500〜3,000円 |
| 認定こども園・私立 | 2,000〜4,000円 |
| 地域子育て支援拠点の一時預かり | 500〜1,500円 |
| 病後児・病児枠 | 2,000円〜（補助で軽減） |

給食費・おやつ代を別途徴収する施設もあります。

## 申し込み方法

### ステップ

1. **自治体や施設の情報収集**：自治体HPで実施施設リストを確認
2. **事前登録**：登録用紙・健康状況・かかりつけ医情報などを提出
3. **見学・面談**：施設によっては事前面談・慣らし利用が必要
4. **利用予約**：電話・WEBで予約（人気施設は競争率高）
5. **当日持参**：おむつ・着替え・哺乳瓶・水筒・連絡帳

### 必要書類

- 利用申込書／登録票
- 母子手帳の写し
- 健康保険証の写し
- 緊急連絡先

## 対象者・条件

- 0歳〜就学前の子ども（施設により0歳の月齢制限あり）
- 居住自治体内に住んでいること（区外利用可の自治体も）
- 健康状態が比較的安定していること
- 予防接種を一定程度受けていること

> **発熱・感染症の場合は利用不可**。病気のときは病児保育を利用しましょう。

## メリット・デメリット

| 項目 | 内容 |
| --- | --- |
| メリット | 単発で預けられる／料金が比較的安い／保育士による安心の保育 |
| デメリット | 予約が取りにくい／登録が必須／病気の子は預けられない／場所が遠い場合も |

## 似たサービスとの違い

| サービス | 違い |
| --- | --- |
| 認可保育園入所 | 継続的・毎日利用 |
| ベビーシッター | 自宅での個別保育、料金は高め |
| 病児保育 | 病気・回復期の子向け |
| ファミサポ | 地域住民の助け合い、自宅・送迎可 |
| 学童保育 | 小学生対象 |

- **理由を問う制度かどうか:** 千代田区・品川区・大田区・杉並区では、区立保育園の一時保育は入院・出産などの理由がある場合に限る制度です。表には、理由を問わずに使える方を載せています（千代田区は児童館などの「いっとき預かり保育」、品川区はオアシスルーム、大田区は一時預かり事業、杉並区は一部の私立保育園の一時保育）。理由に限りのある方の料金は、千代田区の保育園・こども園の一時（いちじ）保育が児童1人につき1日1,600円、品川区の区立保育園の一時保育が児童1人につき1日2,000円、大田区の区立保育園の緊急一時保育が1日1,400円（昼食代含む）です。中央区は保育園ではなく子ども家庭支援センターで実施しています。
- **料金の数え方:** 1時間ごと、時間の区分ごと、1日ごとの区があります。同じ区でも施設や理由で料金が分かれる例として、新宿区は区立認定こども園の専用室型が3,400円/日（食材料費300円含む）、空き利用型（区立）が1,000円/日（食材料費300円を含む）、台東区はサポート1・サポート2が150円/時間です。私立園の料金は区立と異なる区があります（例: 中野区の私立保育園は利用料1人1時間あたり600円～）。千代田区と新宿区の料金は、区のページから開ける案内のPDFに書かれています。
- **無償化:** 港区は、未就学児1人あたり年間144時間まで一時保育などの利用料を無償化しています（令和8年度は9月開始のため84時間まで）。表の料金は、区立保育園の一時保育のページに書かれている利用料金です。
- **対象年齢:** 生後57日から、生後4か月から、生後6か月から、満1歳からなど、区や施設によって始まりが違います。認可保育園などに在籍している子は使えないと書いている区があります。
- **こども誰でも通園制度:** 国の「こども誰でも通園制度」は一時保育とは別の制度で、23区すべての区のページに令和8年度の実施が書かれています。使える時間や呼び方は区で違います（例: 港区版、江東区「あずかーる」、目黒区「はじめのいっぽ」、大田区「おててひろば」、豊島区「こどもつながる定期預かり事業」）。江戸川区は、子育てひろばで行っていた一時保育をこの制度に移しています。

## よくある質問

**Q1. 何日前から予約できる？**
施設により1か月前〜前日まで様々。人気施設は **予約開始日に電話殺到** することも。

**Q2. 0歳でも預けられる？**
生後57日〜6か月以降から対応する施設が多い。施設に確認を。

**Q3. 急な用事でも当日OK？**
原則は事前予約。空きがあれば当日対応の施設もあり。

**Q4. リフレッシュ理由でも使える？**
自治体・施設により「就労以外でも可」とされる場合あり。要確認。

**Q5. 慣らし保育は必要？**
初回は短時間からの慣らし利用が推奨されます。

## 我が家のリアル

我が家は娘の育休中、息子の通院に付き添うため一時保育を月3〜4回利用しました。事前登録が早めにできていたので、急な発熱以外は希望日に取れて助かりました。**「単発でも事前登録は早めに」** が我が家の鉄則。リフレッシュ目的でも気兼ねなく使えるのが、地域子育て支援拠点の一時預かりでした。30分単位で利用でき、保護者の休息にも子の社会経験にもなる「ちょうどいい預け先」として重宝しています。

## まとめ

- 一時保育は **単発で利用できる公的預かり事業**
- 料金は1日2,000〜4,000円程度
- 事前登録＋予約が基本
- 病気のときは利用不可
- リフレッシュ・通院・育休中の上の子対応に便利
