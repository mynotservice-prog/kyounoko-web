## 結論

| 形態 | 開始時期 |
| --- | --- |
| 果汁（加熱・薄める） | **5〜6ヶ月** |
| 果肉（薄皮取り・刻む） | 7〜8ヶ月 |
| 薄皮ごと | 1歳〜 |
| 房そのまま | 2〜3歳〜 |
| 通常量 | 4歳〜 |

## なぜ早めから可？

- 柑橘類の中では酸味マイルド
- ビタミンC豊富
- 加熱しなくても食べやすい
- 種なしで誤嚥リスク低い（薄皮さえ注意）
- 日本の冬の定番果物

## 月齢別の進め方

### 〜4ヶ月

- 与えない

### 5〜6ヶ月

- 果汁を絞って湯で薄める（1:1〜1:2）
- 小さじ1から
- スプーンで少量

### 7〜8ヶ月

- 薄皮を取って細かく刻む
- 少量から
- すりつぶしてヨーグルトに

### 9〜11ヶ月

- 薄皮を取って房を1〜2片
- 手づかみ食べに

### 1歳〜

- 薄皮ごと食べられる（噛みきれる子）
- 房1〜2片

### 2〜3歳

- 1〜2個食べられる
- 自分で皮むき練習も

### 4歳以降

- 通常量
- ただし食べ過ぎ注意

## 薄皮の扱い

### 取った方が良い時期（7〜11ヶ月）

- 消化機能未熟
- 噛みきれない
- 口の中に残りやすい

### 薄皮ごとOK（1歳〜）

- 食物繊維豊富
- ペクチン（整腸作用）
- 噛みきれる子なら可

### 取り方のコツ

- 房を半分に裂いてピンセットで
- 茹でて柔らかくする
- 冷蔵で少し固めると剥きやすい

## 量の目安

| 年齢 | 1日の目安 |
| --- | --- |
| 5〜6ヶ月（果汁） | 大さじ1まで |
| 7〜8ヶ月 | 1/4個分 |
| 9〜11ヶ月 | 1/3〜1/2個 |
| 1〜2歳 | 1/2〜1個 |
| 3〜4歳 | 1〜2個 |
| 5歳〜 | 2〜3個 |

## 食べ過ぎ注意（柑皮症）

### 柑皮症とは

- カロテンが体内に蓄積し**手のひら・足の裏が黄色く**なる
- 健康被害はないが見た目変化
- 食べる量を減らせば数週間で戻る
- 黄疸とは別物

### 予防

- 1日2〜3個までに
- 連日大量摂取を避ける
- バランスの良い果物摂取

## 注意点・避けたい場面

- 種付き品種（甘夏等）は1歳まで避ける
- 食物繊維過多で下痢になることも
- 寝る前は虫歯リスク
- ハチミツみかんは1歳以降
- 缶詰みかんは2歳〜（シロップ控えめ）
- 風邪の時の柑橘は喉に刺激

## 品種別目安

| 品種 | 特徴 | 開始 |
| --- | --- | --- |
| 温州みかん（一般的） | 種なし・薄皮柔らか | 5〜6ヶ月果汁・7〜8ヶ月果肉 |
| デコポン | 種少・甘い | 7〜8ヶ月 |
| 伊予柑 | 種あり・酸味 | 1歳〜 |
| ポンカン | 香り強い・甘い | 9〜11ヶ月 |
| 甘夏 | 酸味強・種あり | 1歳半〜 |
| はっさく | 苦味あり | 2歳〜 |
| グレープフルーツ | 苦味・薬との相互作用 | 1歳半〜 |

## アレルギー対策

### 柑橘アレルギー

- 比較的稀
- 口の周りの赤み（接触性）
- 仮性アレルゲン反応

### 症状

- 口の周り・唇の赤み
- 蕁麻疹
- 嘔吐

→ 出たら受診。

### グレープフルーツの注意

- 薬との相互作用（フロクマリン）
- 子どもが薬を服用中は与えない

## ビタミンC補給

- みかん1個でビタミンC約30mg
- 子どもの1日推奨量（35〜40mg）の大半
- 風邪予防に役立つ
- 鉄分吸収促進（食事と一緒に）

## 選び方

- ヘタが小さく茶色いもの（甘い目安）
- 皮にハリがあるもの
- 重みがあるもの
- 国産・無農薬が安心
- 春みかんは酸味あり、冬みかんは甘め

## 缶詰みかんの目安

- 2歳〜
- シロップを切る
- 量を控えめに
- 子ども用おやつのトッピングに便利

## 我が家のリアル

息子5ヶ月半でみかん果汁デビュー。すごく嫌な顔をしたので2〜3日空けて再挑戦したら少しずつ慣れました。

冬は毎日みかんが食卓に。1歳で「自分で皮むく！」と挑戦するも失敗。2歳で上手にむけるように。3歳で「いくつでも食べたい」と要求するも、1日2個までのルール。

5歳の時、手のひらが黄色くなって「黄疸かも」と慌てて受診。柑皮症と判明。1週間みかんを控えたら元に戻りました。今は食べ過ぎ注意がママのお守り。

## まとめ

- 果汁は5〜6ヶ月から
- 果肉は7〜8ヶ月から薄皮取って
- 1歳〜は薄皮ごと可
- 1日2〜3個まで（柑皮症予防）
- 種付き品種は1歳半〜
- ビタミンC補給に最適
