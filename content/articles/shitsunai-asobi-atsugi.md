子育て支援センター「もみじの手」と屋内広場solaは**同じアミューあつぎ8階**にあるので、はしごができます。

## 1. 子育て支援センター「もみじの手」｜アミューあつぎ8階

0〜6歳の未就学児とその保護者を対象にした交流施設です。サロン室は出入り自由で、育児相談にも対応しています。

| 項目 | 内容 |
|---|---|
| 所在地 | 厚木市中町2-12-15 アミューあつぎ8階 |
| 対象 | 0歳〜6歳の未就学児と保護者（**厚木市外の方も利用可**） |
| 料金 | 公式サイトで要確認 |
| 利用日 | 月曜〜日曜（祝日、年末年始12/29〜1/3、アミューあつぎ休館日はお休み） |
| サロン室利用時間 | 午前9時〜正午、午後1時〜4時 |
| 設備 | **8階共通でおむつ替えコーナー・授乳室あり** |

**土日祝でも開いている**のが強みです。小中学生のきょうだいは1人まで同伴入室できます。

詳しくは[厚木市の公式ページ](https://www.city.atsugi.kanagawa.jp/soshiki/kenkozukurika/2_1/3/1520.html)で確認できます。

## 2. 屋内広場 sola｜アミューあつぎ8階

建築家・石上純也氏設計の広場で、巨大な「雲の壁」がある開放的な空間です。子育て支援センターと同じ8階にあります。

| 項目 | 内容 |
|---|---|
| 所在地 | 厚木市中町2-12-15 アミューあつぎ8階 |
| 料金 | 公式サイトで要確認 |
| 利用可能時間 | 8時30分〜18時00分（アミューあつぎ休館日を除く） |
| 設備 | **8階のおむつ替えコーナー・授乳室・トイレを利用可** |

飲食可能ですが、ゴミは各自持ち帰りです。専用利用（イベント等での占有）には事前申請が必要と案内されています。

詳しくは[厚木市の公式ページ](https://www.city.atsugi.kanagawa.jp/soshiki/kenkozukurika/2_1/2/2889.html)で確認できます。

## 3. 地域子育て支援拠点「ほっと れもんてぃ」｜あゆのこ保育園内

厚木市があゆのこ保育園（社会福祉法人湘北福祉会）に委託して運営する子育て支援拠点です。遊具やおままごとコーナーがあります。

| 項目 | 内容 |

| 所在地 | 厚木市恩名1丁目10-38（あゆのこ保育園内 子育て支援室） |
| 対象 | 小学校就学前の子と保護者 |
| 料金 | 公式サイトで要確認 |
| 利用日 | 月曜〜金曜（祝日、年末年始12/29〜1/3はお休み） |
| 利用時間 | 午前9時30分〜11時30分、午後1時〜4時 |
| 設備 | 公式記載なし |

**土日は利用できません。**園庭開放は午後1時〜3時です。駐車場はあゆのこ保育園のものが使えますが台数に限りがあります。

詳しくは[厚木市の公式ページ](https://www.city.atsugi.kanagawa.jp/kosodate/asobu_manabu/oyako_shisetsu/20556.html)で確認できます。

## 4. 厚木市の児童館（市内38館）｜幼児は保護者同伴・「おひさまタイム」あり

厚木市には児童福祉法に基づく児童館が38館あります。三田・厚木南・厚木北・上依知・森の里など、市内各地区にあります。

| 項目 | 内容 |
|---|---|
| 対象 | 小学生が主だが、幼児（保護者同伴）〜18歳まで利用可 |
| 料金 | 公式サイトで要確認 |
| 開館 | 月〜金 午後1時〜5時／土日祝・学校長期休業期間 午前10時〜午後5時 |
| 休館 | 年末年始（12月29日〜1月3日） |
| おひさまタイム | 平日午前10時〜正午、乳幼児と保護者向けに閉館中の児童館を開放（**実施曜日は館により異なる**） |

未就学児は**保護者同伴が必須**です。最寄りの児童館と「おひさまタイム」の実施曜日は施設ごとに違うので、公式の一覧ページで確認してから向かってください。

詳しくは[厚木市の公式ページ（児童館）](https://www.city.atsugi.kanagawa.jp/kosodate/asobu_manabu/oyako_shisetsu/40767.html)で確認できます。

## 5. 厚木市立中央図書館 こどもの本のフロア｜図書館法で入館無料

小田急小田原線本厚木駅そば、厚木シティプラザ内にある中央図書館です。3階がこどもの本のフロアで、絵本・紙芝居・図鑑などが揃います。

| 項目 | 内容 |
|---|---|
| 所在地 | 厚木市中町1-1-3（厚木シティプラザ） |
| 対象 | どなたでも |
| 料金 | **無料**（図書館法第17条により公立図書館の入館・利用は無料と定められています） |
| 開館 | こどもの本のフロア（3階）・視聴覚コーナー（3階） 午前9時〜午後5時 |
| 休館 | 公式カレンダー参照（施設保守日・年末年始・特別整理期間ほか） |

地階・2階（調べもの・おとなの本）は午後7時までですが、**こどもの本のフロアは午後5時まで**と閉まるのが早いので注意してください。月2回程度「おはなし会」も開かれています。

詳しくは[厚木市立中央図書館の公式ページ](https://www.city.atsugi.kanagawa.jp/soshiki/chuotoshokan/7/6316.html)と[開館時間・休館日のページ](https://www.city.atsugi.kanagawa.jp/soshiki/chuotoshokan/13/20953.html)で確認できます。

## 予算で選ぶ

- **0円で済ませたい** → 厚木市立中央図書館 こどもの本のフロア（図書館法第17条で無料）
- **しっかり遊ばせる** → キッズランドUS神奈川厚木店（平日60分800円〜、0歳無料）
- **駅近くではしごしたい** → もみじの手・屋内広場sola（どちらもアミューあつぎ8階）

## 雨の日のコツ

- **もみじの手とsolaは同じ建物**：アミューあつぎ8階にまとまっているので、雨の日でも移動が最小限で済む
- **児童館は平日13時開館と遅め**：乳幼児連れは平日午前の「おひさまタイム」を狙う（館ごとに曜日が違うので事前確認）
- **ほっとれもんてぃは土日休み**：週末に使いたいときは選択肢から外れる
- **図書館のこどもの本のフロアは17時閉室**：本館自体は19時まででも児童フロアは先に閉まるので午後早めに

## よくある質問

### Q. 厚木市で無料の室内遊び場は？

A. **厚木市立中央図書館のこどもの本のフロアが図書館法第17条により無料**です。子育て支援センター「もみじの手」や屋内広場solaは、利用料の記載が公式ページになく施設への確認をおすすめします。

### Q. 0歳を連れて行けるところは？

A. **もみじの手・ほっと れもんてぃ**はどちらも0〜6歳の未就学児が対象です。**キッズランドUS神奈川厚木店も0歳は無料**と公式に明記されています。

### Q. 厚木市にボーネルンド（キドキド）やモーリーファンタジーはある？

A. **ありません。**ボーネルンド公式のショップリストで神奈川県内に載っているのはマークイズみなとみらい・グランツリー武蔵小杉・川崎ルフロンの3店で、厚木市にはありません。モーリーファンタジーの公式店舗検索（神奈川県36店舗）にも厚木市の店舗はありません。

### Q. 日曜に開いているところは？

A. **もみじの手**は日曜も開所（祝日・年末年始・アミューあつぎ休館日以外）。**児童館**も日祝は10時〜17時開館です。**中央図書館**も開館日カレンダーに沿って開いています。**ほっとれもんてぃ**は土日休みです。

### Q. 児童館は誰でも入れる？

A. 小学生の利用が主ですが、**未就学児は保護者同伴で利用可能**です。年末年始（12/29〜1/3）以外は開館しています。
