## 結論｜0〜2歳の入園準備早見表

長くなるので先に答えます。

| 軸 | やること |
| --- | --- |
| **必需品購入** | 着替え多め・哺乳瓶・お昼寝布団・帽子等 |
| **お名前付け** | 100〜200個。1〜2月で計画的に |
| **慣らし保育** | 4月最初2週間、徐々に時間延長 |
| **生活リズム** | 起床・食事・お昼寝を保育園スケジュールに |
| **書類** | 健康保険証コピー・予防接種記録・口座振替 |
| **職場復帰** | 慣らし終了後にフル復帰 |

入園説明会は2〜3月に開催。具体的な持ち物リストはそこで確定。

## お名前付けの効率テクニック

最大の関門。**1〜2月の2ヶ月で計画的に**。

### 必要なもの

- お名前シール（防水・印刷済み）
- お名前スタンプ（オーダーメイド）
- 油性マジック（細字 0.7mm）
- アイロン接着お名前シール（服用）

3. **テレビ見ながら家族で分担**
4. **3〜5日に分ける**

## 慣らし保育の進め方

入園直後、子も親も大変な期間。**焦らず徐々に** が鉄則。

### 慣らし保育の標準スケジュール

| 日数 | 滞在時間 |
| --- | --- |
| 1〜2日目 | 1〜2時間（親同伴の園もあり） |
| 3〜5日目 | 半日（午前 or 午後） |
| 6〜10日目 | 給食まで（11時半まで） |
| 11〜15日目 | お昼寝まで（14時半まで） |
| 16日目以降 | フル登園（18時頃まで） |

園によって異なるので **入園前に園に確認** を。

### 慣らし保育のコツ

- **子も親も泣いて当たり前**：1〜2週間で慣れる
- **絶対に隠れて帰らない**：「行ってきます、必ず迎えに来るね」を伝える
- **迎えの時間を守る**：信頼関係の土台
- **疲れている前提で過ごす**：帰宅後は穏やかに

### よくあるトラブル

- 初日大泣き → 標準。1週間で慣れる
- 病気もらってくる → 標準。免疫獲得期
- 食べない・寝ない → 1〜2週間で改善
- 1ヶ月で「行きたくない」 → 親同伴で時間延長

## 0歳・1歳・2歳のクラス別の違い

### 0歳児クラス

- 一人ひとり個別対応
- お昼寝が複数回
- 哺乳瓶・離乳食対応
- 抱っこの時間が長い

### 1歳児クラス

- 集団生活の始まり
- お昼寝が1回に減る
- 自分で食べる練習
- 「自分でやりたい」期

### 2歳児クラス

- イヤイヤ期と重なる
- お友達との関わり増
- 集団活動が増える
- 言葉が増える時期

## 病気・けがの心構え

入園後1〜2ヶ月は **月に2〜3回病気** が標準。

### よくある病気

- 風邪・発熱
- 手足口病
- 水ぼうそう
- インフルエンザ
- 胃腸炎

### 対策

- 病児保育の登録（市・民間）
- 祖父母・親族のヘルプ体制
- 在宅勤務の活用
- 子供のかかりつけ医決め
- 健康保険証コピー常時携帯

## 我が家のリアル

息子が0歳7ヶ月で保育園入園した時の記録：

慣らし保育は2週間。最初の3日は1時間で泣き止まず、4日目から少しずつ笑顔が見られるように。1週間で慣れて、2週間目はフル登園できました。

**準備で良かったこと**：
- お名前シール大量発注（後から追加発注の手間ゼロ）
- 着替えを大量に（7枚×3セット）
- お気に入りのタオルを園に持参（安心材料）
- 病児保育を事前登録

**反省点**：
- 初月の病気欠席が多すぎて職場に申し訳なかった → 病児保育を最初から想定すべきだった
- お昼寝布団の購入が遅れた → 2月中に決断すべき

## FAQ｜よくある質問

**Q1. 何ヶ月から保育園に？**

A. **0歳児クラスは生後57日以降** の園が多い（園による）。1歳児・2歳児クラスは前年度4月生まれが対象。「何月生まれが有利か」は出産時期によって判断。

**Q2. お名前付けは何個くらい？**

A. **100〜200個**。着替え多め＋小物類で意外に増える。**シール＋スタンプの併用** で効率化。

**Q3. 病気はどのくらい多い？**

A. 入園後1〜2ヶ月は **月2〜3回** 発熱・体調不良で欠席が標準。半年経つと頻度減ります。

**Q4. 慣らし保育は何週間？**

A. **1〜2週間** が標準。子の様子で延長することも。職場復帰のスケジュールは慣らし終了の余裕を見て。

**Q5. 持ち物の名前付け、ひらがな or 漢字？**

A. **ひらがな推奨**。0〜2歳は字が読めないので、子に見せる用ではなく、先生・他の保護者に見せる用。

**Q6. 着替えは何セット？**

A. **5〜7セット** が標準。給食・水遊び・お昼寝後など、1日2〜3回着替える前提。

**Q7. 給食はある？**

A. ほぼ全園で提供。**離乳食対応** も園で可能。アレルギーがある場合は事前に園に相談。

## まとめ

0〜2歳の保育園入園準備は「必需品＋お名前付け＋生活リズム」で失敗しません。

- 1〜2月：必需品まとめ買い、お名前シール準備
- 3月：お名前付け、生活リズム調整
- 4月：慣らし保育、徐々にフル登園
- 病気・欠席対策（病児保育登録）
- 着替え多めに準備

子も親も大変な時期ですが、半年で軌道に乗ります。
