## 結論｜駅の外へ出る。設備なら京王百貨店7階、次点で高島屋9階

新宿駅で赤ちゃん連れが授乳・おむつ替えをするなら、答えはシンプルです。

- **設備を最優先** → **京王百貨店 新宿店 7階**（授乳室3部屋・施錠可・**オンラインで空き状況を確認できる**）
- **次点** → **新宿高島屋 9階**（個室・調乳に適した温度のお湯・電子レンジ・オゾン生成器）
- **東口側にいる場合は注意** → **ルミネエスト新宿には授乳室の記載がありません**

そしてもうひとつ、事前に知っておくべき前提があります。**「改札内／改札外」の区分は、調べたどの施設の公式ページにも書かれていません。** 「改札を出ずに授乳できる場所」を公式情報から特定することは、新宿駅ではできません。

この記事は、JR東日本・京王百貨店・新宿高島屋・ルミネ新宿・ルミネエスト新宿・NEWoMan新宿・小田急百貨店新宿店の各公式サイトを**2026年7月27日**に確認して作成しています。

## 前提｜JRの公式ページからは駅構内の授乳室を確認できない

まず正直に書きます。**JR東日本の新宿駅の公式駅ページには、授乳室・ベビー休憩室の文字記載が一切ありません。**

バリアフリー情報として掲載されている項目は次の5つのみです。

| バリアフリー情報の項目 | 掲載 |
|---|---|
| エレベーター | あり |
| エスカレーター | あり |
| バリアフリートイレ | あり |
| 点字運賃表 | あり |
| シニアカー | あり |
| **授乳室・ベビー休憩室** | **項目そのものがない** |

階も、設備も、利用時間も、改札内外の区別も、すべて記載がありません。さらに新宿駅の構内図には**授乳室の凡例そのものがない**ため、**公式表記からは駅構内に授乳室があるかどうかを断定できません**。

だから結論が「駅の外に出る」になります。新宿駅は東口・西口・南口それぞれに大型商業施設が直結しており、そちらの公式サイトのほうが情報が具体的です。以下、施設ごとに公式記載を整理します。

## 京王百貨店 新宿店7階｜公式にいちばん詳しい

京王百貨店 新宿店（keionet.com）の**7階**にある「◆ベビー休憩室・授乳室」は、今回調べた中で公式サイトの記載が突出して詳しい施設です。

| 設備 | 公式記載の内容 |
|---|---|
| 授乳室 | **3部屋**・肘掛付きソファ・**施錠可** |
| 空き状況 | **オンラインで確認できる** |
| 調乳用給湯 | **70℃以上対応の調乳用浄水・温水器** |
| シンク | **あり** |
| 電子レンジ | **あり**（離乳食を温められる） |
| おむつ交換台 | 両サイドガード＋フットガード付き／横にベビーカー置きスペース |
| 着替え台 | **別途あり** |
| プレイスペース | 幼児用（靴を脱いで遊べる） |
| ソファスペース | キッズチェアあり |
| 自動販売機 | 飲料あり |
| 利用時間 | **記載なし**（7階を含む3階以上は10:00〜20:00） |

注目すべきは3点です。

**1. 調乳用給湯・電子レンジ・シンクの3点すべてが公式に明記されているのは、調べた新宿の施設の中でここだけ。** ミルクを作る、離乳食を温める、使ったものを洗う——この3つが1か所で完結します。

**2. 授乳室が3部屋あり、施錠できる。** 個室が複数あることと、鍵がかかることが公式に書かれているのは大きな差です。

**3. オンラインで空き状況を確認できる。** 混雑する新宿で「行ってみたら満室」を避けられる仕組みが公式にあるのは、今回調べた中でここだけでした。

ベビーカーの貸出も、**1階正面案内所と7階ベビー休憩室**の2か所。**生後1ヶ月から利用できるA型**と公式に記載されています。7階のベビー休憩室で借りられるので、授乳のついでにベビーカーを調達する動きが可能です。

なお、**ベビー休憩室そのものの利用時間は公式に記載がありません**。7階を含む3階以上の営業時間は10:00〜20:00なので、これが目安になります。

## 新宿高島屋9階・14階｜オゾン生成器つき

新宿高島屋（タカシマヤ タイムズスクエア／takashimaya.co.jp）は、赤ちゃん休憩室が**9階と14階**の2か所。**授乳室は9階の赤ちゃん休憩室**にあります。

公式の設備記載は次のとおりです。

> 落ちついて授乳ができる個室のほか、調乳に適した温度のお湯が出る給湯設備、電子レンジ、オゾンの力で脱臭除菌するオゾン生成器を備えました。

| 設備 | 公式記載 |
|---|---|
| 個室の授乳スペース | **あり** |
| 調乳用給湯 | **あり**（調乳に適した温度） |
| 電子レンジ | **あり** |
| オゾン生成器 | **あり**（脱臭除菌） |
| シンク | **記載なし** |
| 利用時間 | **記載なし**（店舗 10:30〜19:30） |

**電子レンジと調乳用のお湯が揃っている点で京王百貨店に並びます**が、**シンクの記載がない**点だけが差です。哺乳瓶を洗いたい場合は京王百貨店のほうが確実です。

ベビーカーの貸出場所は**1階明治通り口／2階JR口／9階赤ちゃん休憩室／駐車場A・Bロビー**と4系統あり、今回調べた中でもっとも貸出拠点が多い施設です。9階の赤ちゃん休憩室でも借りられます。

店舗の営業時間は10:30〜19:30で、京王百貨店（10:00〜）より30分遅く、終わりも30分早い点は覚えておくと計画が立てやすくなります。

## ルミネ新宿・ルミネエスト・NEWoMan｜階と記載の有無

駅直結の3施設は、公式の記載量に差があります。

### ルミネ新宿

**授乳室はルミネ1が7F、ルミネ2が4F**です。設備の記載は「※調乳用温水器がご利用いただけます。」の1行のみで、**電子レンジ・シンクの記載はありません**。

利用時間は**「館営業時間に準ずる」**と公式に明記されています。今回調べた中で、授乳室の利用時間の考え方が公式に書かれているのはルミネだけでした。

- **ベビーベッド付トイレ**：ルミネ1は4F・5F・6F・7F／ルミネ2は2F・3F・4F・5F
- **ベビーカー貸出**：ルミネ1・2の2F、館営業時間に準ずる、**1ヶ月〜48ヶ月、100円返却式**

ベビーカーが**100円返却式**である点も公式に明記されています。100円玉を用意しておくと詰みません。

### ルミネエスト新宿

**授乳室の記載がありません。** 公式サイトの「お子さまをお連れのお客さまへ」の欄に、授乳室という項目自体が存在しません。

記載があるのは以下です。

- **ベビーベッド付トイレ**：B2・B1・3F・4F（男性用トイレ内）・6F・7F・8F（女性用トイレ内）
- **ベビーカー**：1Fインフォメーション
- **多目的トイレ**：B1（オストメイト対応）、平日11:00〜22:00／土日祝10:30〜22:00

**おむつ替えはできるが、授乳室は公式に確認できない**——これがルミネエストの状態です。**東口側で授乳したいなら、ルミネエストではなく別の施設を目指す必要があります。** 4F（男性用トイレ内）と8F（女性用トイレ内）にもベビーベッドがあると明記されているのは、パパひとりのおむつ替えでは有用な情報です。

### NEWoMan新宿

**授乳室は4F**。ただし**設備の記載がありません**。利用時間の記載もなく、ファッションフロアの営業時間は月〜土11:00〜20:30／日祝11:00〜20:00です。

- **ベビーカー貸出**：4F（サービスカウンターに問い合わせ）
- **多目的トイレ**：M2、4F、7F（オストメイト対応あり）

授乳室があることは確実ですが、**お湯が出るのか、レンジがあるのかは公式サイトからは判断できません**。ミルクや離乳食が必要なら、京王百貨店か高島屋を選ぶほうが確実です。

## 小田急百貨店 新宿店7階｜アイコンのみの記載

小田急百貨店 新宿店（odakyu-dept.co.jp）は、公式に「新宿店　新宿西口ハルクで営業しております。」と明記されています。建替工事に伴う現在の営業形態です。

フロアガイドでは「授乳室」「おむつ交換台」のアイコンが**7階にのみ**付与されています。ただし、**設備の内容も利用時間も、すべて記載がありません**。7階の営業時間は10:00〜20:00です。

**「7階に授乳室がある」ことは公式のアイコンから分かるものの、中身は不明**——という状態です。ここを目的地にするなら、お湯やレンジは期待せず、持参前提で向かうのが安全です。

## 状況別の選び方

**ミルクを作りたい・離乳食を温めたい** → **京王百貨店7階**。70℃以上対応の調乳用温水器、電子レンジ、シンクの3点が揃っているのは公式記載上ここだけです。空き状況をオンラインで確認できるのも、混雑する新宿では大きな利点です。

**満室が心配・混雑を避けたい** → やはり**京王百貨店7階**。オンラインで空き状況が見られる唯一の施設です。

**南口・タイムズスクエア側にいる** → **新宿高島屋9階**。個室・調乳用のお湯・電子レンジ・オゾン生成器と設備は充実しています。シンクの記載がないので、哺乳瓶を洗う想定なら注意してください。店舗は10:30〜19:30と、開店がやや遅く閉店が早めです。

**東口側にいる** → **ルミネエストには授乳室の記載がありません。** おむつ替えだけならベビーベッド付トイレがB2・B1・3F・4F・6F・7F・8Fにあります。授乳が目的なら、西口の京王百貨店か南口の高島屋まで移動する判断になります。

**とりあえずおむつ替えだけしたい** → ルミネエスト（B2〜8Fに分散）やルミネ新宿（ルミネ1は4〜7F、ルミネ2は2〜5F）のベビーベッド付トイレが使えます。

**ベビーカーを調達したい** → 京王百貨店（1F・7F、**生後1ヶ月からのA型**）、高島屋（4か所）、ルミネ（2F・**100円返却式**）。ルミネは100円玉が必要です。

## よくある質問

### Q. 新宿駅の構内（改札内）に授乳室はありますか？

**公式表記からは断定できません。** JR東日本の新宿駅ページには授乳室・ベビー休憩室の文字記載がなく、構内図にも授乳室の凡例がありません。さらに、今回調べた6つの商業施設の公式ページにも**改札内／改札外の区分表記がありません**。確実に授乳したいなら、駅の外の商業施設を目指すのが現実的です。

### Q. 新宿でいちばん設備が整っている授乳室はどこですか？

**京王百貨店 新宿店の7階**です。授乳室3部屋（肘掛付きソファ・施錠可）、70℃以上対応の調乳用浄水・温水器、シンク、離乳食を温められる電子レンジ、両サイドガード付きおむつ交換台、着替え台、幼児用プレイスペース、飲料自販機。**調乳用給湯・電子レンジ・シンクの3点すべてが公式に明記されているのは、調べた新宿の施設の中でここだけ**です。

### Q. 授乳室の空き状況を事前に確認できる場所はありますか？

**京王百貨店 新宿店7階のみ**です。公式に「オンラインで空き状況が確認できる」と記載されています。他の5施設には空き状況確認の記載がありません。

### Q. ルミネエスト新宿に授乳室はありますか？

**公式サイトに授乳室の記載がありません。** 「お子さまをお連れのお客さまへ」の欄に授乳室の項目自体が存在しません。ベビーベッド付トイレはB2・B1・3F・4F（男性用トイレ内）・6F・7F・8F（女性用トイレ内）にあり、おむつ替えは可能です。授乳が目的なら別の施設へ向かってください。

### Q. 授乳室は何時まで使えますか？

**利用時間が公式に書かれているのはルミネ新宿の「館営業時間に準ずる」だけ**です。他の施設は授乳室そのものの利用時間の記載がなく、館の営業時間が目安になります。京王百貨店は3階以上が10:00〜20:00、新宿高島屋は10:30〜19:30、NEWoManのファッションフロアは月〜土11:00〜20:30／日祝11:00〜20:00、小田急百貨店（新宿西口ハルク）の7階は10:00〜20:00です。

### Q. 離乳食を温められるのはどこですか？

**京王百貨店7階と新宿高島屋9階**です。どちらも公式に電子レンジの記載があります。ルミネ新宿・NEWoMan新宿・小田急百貨店には電子レンジの記載がありません。

### Q. ベビーカーはどこで借りられますか？

京王百貨店（1階正面案内所・**7階ベビー休憩室**／生後1ヶ月から使えるA型）、新宿高島屋（1階明治通り口・2階JR口・9階赤ちゃん休憩室・駐車場A/Bロビー）、ルミネ新宿（ルミネ1・2の2F／**1ヶ月〜48ヶ月・100円返却式**・館営業時間に準ずる）、NEWoMan新宿（4F、サービスカウンターに問い合わせ）、ルミネエスト新宿（1Fインフォメーション）です。小田急百貨店には記載がありません。

## まとめ

新宿駅の授乳室は、**駅の中で探さず、隣接する商業施設に出るのが正解**です。JRの公式ページには授乳室の文字記載がなく、構内図にも凡例がないため、駅構内については公式情報から判断できません。

- **設備最強は京王百貨店 新宿店7階**。調乳用温水器（70℃以上）・電子レンジ・シンクの3点が揃う唯一の施設で、授乳室3部屋・施錠可・**オンラインで空き状況も確認できる**
- **次点は新宿高島屋9階**。個室・調乳用のお湯・電子レンジ・オゾン生成器。ただしシンクの記載はなし
- **ルミネエスト新宿には授乳室の記載がない**。東口側にいるなら移動が必要
- **改札内／改札外の区分は、どの施設の公式ページにも書かれていない**

赤ちゃん連れで新宿を通る予定があるなら、**京王百貨店7階をデフォルトの目的地に決めておく**のがもっとも失敗しにくい選択です。公式に記載がない項目については、当日各施設の案内カウンターで確認してください。
