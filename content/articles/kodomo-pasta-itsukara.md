## 結論

| 形態 | 開始時期 |
| --- | --- |
| 細かく刻んで柔らかく | **7〜8ヶ月** |
| 1〜2cm | 9〜11ヶ月 |
| 3〜4cm | 1歳〜 |
| 通常長 | 2歳〜 |

## なぜ離乳食中期から？

- 小麦に慣れていれば導入可
- 米・パン・うどんの次のステップ
- ベビー用パスタ（早茹で・短い）が便利
- ただし塩茹でする場合は塩抜きが必要

## 月齢別の進め方

### 〜6ヶ月

- 与えない

### 7〜8ヶ月（離乳食中期）

- ベビーパスタを柔らかく茹でて細かく刻む
- 5mm程度に
- 塩なしで茹でる、または茹で汁を捨てる
- 少量から

### 9〜11ヶ月（離乳食後期）

- 1〜2cmにカット
- 軟らかめに茹でる（表示時間+1〜2分）
- ソースも薄味

### 1〜1歳半（完了期）

- 3〜4cmにカット
- ナポリタン・ミートソース（薄味）
- フォーク練習にも

### 1歳半〜2歳

- 5cm程度
- 大人より柔らかめ
- ソースは薄め

### 2歳以降

- 通常長
- すする練習中はカット

## ソース別判断

| ソース | 目安 |
| --- | --- |
| トマトソース（手作り） | 7〜8ヶ月〜 |

| ミートソース | 9ヶ月〜（薄味） |

| ボロネーゼ | 1歳〜（薄味） |

## 量の目安

| 年齢 | 1食の目安（茹で後） |
| --- | --- |
| 7〜8ヶ月 | 20〜30g |
| 9〜11ヶ月 | 40〜60g |
| 1歳 | 80g |
| 2〜3歳 | 100〜120g |
| 4〜5歳 | 150g |

## 塩分・調味料対策

### 茹でる時

- 離乳食期：塩なし
- 1歳以降：塩控えめ、または塩抜き
- ベビー用パスタは塩なしで茹でやすい

### ソース

- 大人の半分以下の濃さ
- ケチャップ・トマト缶は無添加を選ぶ
- 粉チーズは少量
- バターは2歳から少量

## 小麦アレルギー対策

### 注意点

- うどん・パンが食べられていれば基本OK
- 米粉パスタという選択肢もある

### 症状

- 蕁麻疹
- 嘔吐・腹痛
- 呼吸困難

→ 症状あれば即受診。

## トマトの注意

- トマトの皮・種は1歳まで取り除く
- アレルギー報告少ないが、唇が赤くなる子もいる
- 酸味が苦手な子もいる

## 注意点・避けたい場面

- 長い麺はそのまま食べさせない（誤嚥）
- フォークでくるくる巻く練習は3歳〜
- ペペロンチーノなど辛味は4歳以降
- カルボナーラの半熟卵は3歳以降
- スパゲッティはすすると気管に入りやすい

## お店デビューのコツ

- ファミレス（ガスト・ジョリーパスタ等）が便利
- ナポリタン・ミートソースから
- お子様メニューを活用
- キッズフォーク・スプーンを借りる
- お皿に取り分けて短く切る

## 我が家のリアル

息子8ヶ月でベビー用パスタデビュー。トマトソースを薄めて、細かく刻んで。フォークの練習にもなって良かったです。

1歳半でジョリーパスタデビュー。お子様ナポリタンを取り分けて、フォークで巻く練習。最初はうまくいかず手づかみでしたが、3歳でフォーク巻きをマスター。

「パスタは何センチに切れば？」と聞かれることがあります。子どもの口の大きさに合わせて、噛みきれる長さに。我が家は3歳まで3〜4cmが基本でした。

## まとめ

- 7〜8ヶ月から離乳食でOK
- 月齢に応じて長さ調整
- ソースは薄味で
- ベビー用パスタが便利
- 辛味・半熟卵は3〜4歳以降
- お店はファミレスから
