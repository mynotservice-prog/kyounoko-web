# 01. ブランドキット 発注書

## 依頼ゴール

きょうのこ.jp のビジュアル基盤になる **ブランドキット** を作る。下記7点を納品物とする。

## 納品物

### A. ロゴ刷新
- 現状: `/public/img/favicon.svg` の自前生成版(個性が弱い)
- 要望:
  - 横組ロゴ(サイトヘッダ用 / 透過SVG)
  - 縦組 or 正方形ロゴ(SNSアイコン / OGP用 / ファビコン用)
  - モノクロ版(白背景・黒背景の両方で映える)
- コンセプト: 「子育て家庭の意思決定を軽くする」サイト。**温かい紙色** に **クレイ系オレンジ** が映える世界観。子どもキャラを前面に出さず、保護者目線の落ち着きと信頼感。
- 連想ワード: 暮らし・記録・選ぶ・3分で決める・実訪問の地図帳的な質感

### B. ファビコン / PWAアイコン一式
- ファビコン(16/32/48/64/256 PNG + SVG)
- Apple Touch Icon (180×180, 167×167, 152×152)
- Android adaptive icon (foreground/background)
- Maskable icon (192×192, 512×512)
- 全部 `/public/icons/` 配下に置ける形式で

### C. カラーパレット定義書
- 既存トークンを尊重しつつ、必要に応じて統廃合提案
- 各色の用途・コントラスト比・darkmode対応案を文書化
- 最終形は `/Users/nagaminehideki/Developer/kyounoko-web/app/globals.css` の `:root` にそのまま反映できる CSS 変数として
- 既存トークン: `00_overview.md` 参照

### D. タイポグラフィ定義
- 現状: Noto Sans JP(本文)/ Shippori Mincho(見出し・mincho)/ Inter(英字eyebrow)
- 残しつつ、サイズ・行高・letter-spacing のスケール表(h1-h6 / body / caption / eyebrow)を作成
- モバイル <600px と デスクトップ ≥768px の2スケール

### E. トーン&ボイスガイド
- きょうのこの「らしい言葉遣い」を1ページにまとめる
- 使う言葉 / 使わない言葉(例: 「ぜひ◯◯してみてください」は禁止、「◯◯すると楽です」を推奨)
- 既存記事の中で良い見本を5本ピックアップ可

### F. グラフィック装飾要素
- 引用ブロック・FAQアコーディオン・TL;DR箱・「ながみー家のリアル」ボックス等で使える装飾線・小さなアイコン
- 「紙的な質感」を活かす(過度なシャドウ・グラデーションを避ける)

### G. デザイントークンFigmaファイル
- 上記A-Fを集約したFigma(または同等のSVG/PDF)1ファイル
- 開発側がコピペで実装できる形

## 避けてほしい方向

- LINE着せ替え的・キャラクター中心(子どもより親に届ける媒体のため)
- 男女ステレオタイプ(ピンク=女の子等)
- パステル全振り(信頼感が損なわれる)
- 黒背景+ネオン系(全く合わない)
- 「明るく元気な3人家族!」のような押し付けがましい家族像
