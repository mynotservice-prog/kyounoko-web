# 駅ページのチェーン店を「公式で実在を確認した店」だけにする

`lib/station-verified-stores.ts` を作るための道具。2026-10-08 作成。

## なぜあるか

駅ページのチェーン一覧は、駅の規模に応じた一律付与で、その駅に店があるかを確かめていなかった。
2026-10-08 に全駅を照合した結果、表示していたチェーンのうち公式で実在を確認できたのは
郊外92駅で38%（5,152中1,932）、東京23区484駅で33%（18,640中6,211）だった。

## 手順

```bash
cd scripts/station-verify
# 1) 56チェーンの全国の店舗一覧を公式から取り直す（stores/<slug>.json。1チェーン1スクリプト）
for f in fetch/[a-z]*.py; do SV_REFRESH=1 python3 "$f"; done
python3 fetch/_enrich_coords.py   # スシロー・サブウェイ・コメダの座標を補う
# 2) 駅から800m以内の店を拾う（matched.json）。住所の座標化に国土地理院の住所検索を使う
python3 match.py
# 3) 対象駅のリストを渡して lib/station-verified-stores.ts を作る
python3 gen_ts.py ../../lib/station-verified-stores.ts list-suburb.txt "$(date +%F)"
```

- `stations.json`: 駅の座標（`lib/station-coords.json` と、新設駅は HeartRails Express API）。
- `list-suburb.txt`: 一律付与を受けていた郊外の主要駅＋四ツ谷。`list-tokyo23.txt`: 東京23区。
- `cache/` `stores/` `matched.json` は生成物でコミットしない。

## 判定の決まり

- 判定に使うのは各チェーンの公式サイト・公式APIだけ。
- 店の位置は公式座標を使う（全体の約98%）。NAVITIME系（吉野家・松屋・松のや・かつや・はなまるうどん・
  ドトール・エクセルシオール）とサイゼリヤの公式座標は日本測地系なので、世界測地系に直してから使う
  （直した後は、住所から出した位置との差が中央値10〜20m）。
- 一覧に座標が無いスシロー・サブウェイ・コメダは、各店の公式ページ／公式APIから座標を補う（`fetch/_enrich_coords.py`）。
  星乃珈琲店・洋麺屋五右衛門は座標が無いので、公式の住所を国土地理院の住所検索で座標にする。
  住所が街区までしか当たらないときは、同じ番地にある別チェーンの店の公式座標を借りる。
- **公式座標と住所の突き合わせ**: 対象都府県の全店で、公式座標と住所の位置を比べる。住所が「号」まで当たっているのに
  1km以上離れていたら公式座標の誤りとみなし、住所の位置を使う（`review_coord_mismatch.json` に出る）。
  2026-10-08 時点で4店（かっぱ寿司 秋葉原万世橋店は、公式データの座標がアトレ亀戸店と同じ値だった）。
- 住所の変換結果が別の市区町村になった場合は採用しない（住所表記の崩れで県庁の位置に飛んだ例がある）。
- 駅中心から直線で300m以内を「駅前」、800m以内を「徒歩圏」。800mを超える店は載せない。
  直線距離なので、線路や幹線道路の向こう側の店は実際には10分を超えることがある。
- 載せない店（`match.py` の `EXCL`）: 閉店・開店前（「グランドオープン」表記を含む）・長期休業・改装休店中・
  テイクアウトや弁当の専門店・改札内や駅ナカ施設（エキュート等）・球場内・大学や病院の構内・
  派生業態（MOSH Burger&Bar、むさしの森Diner、ポケットキッチン）。改装などの一時休業は載せる。
- 1チェーンにつき駅に近い順で最大5店まで載せ、残りは件数だけ持つ。
- 「無い」と言えるのは、全国一覧を取れていて、件数が公式の表示と合っているから。
  取得スクリプトを直したら、件数と既知の実在店（陽性対照）を必ず確かめる。

## 検算

1. 2026-10-07 に公式店舗検索を1店ずつ引いて照合した10駅（相模大野・関内・日吉・大船・四ツ谷・松戸・
   流山おおたかの森・柏の葉キャンパス・浦和・所沢）と突き合わせた。7駅は完全に一致、残りの差は
   駅から700〜800mの店の扱いだけだった（`reports/next-faces-2026-10/station-verify-*.md`）。
2. 2026-10-08 に無作為の25駅（23区17・郊外8）を、台帳を見せずに公式サイトだけで検算した。
   載せる店216件のうち問題3件（休業中・開店前・大学構内）、載せないチェーン200件のうち見逃し1件
   （スシロー 新宿西口店。住所が街区止まりで駅から遠く出た）。抜き取りの外で、公式座標の誤りによる
   別駅の店の混入1件、改札内・球場内・休店中の店の掲載4件が見つかった。いずれも上の決まりに反映済み。

手順を変えたら、同じやり方で抜き取り検算をやり直す（機械の台帳を見せず、今日の公式サイトだけで判定させる）。

## 既知の限界

- 駅は1点の座標で測っている。出口が離れている大きな駅では100〜200mの差が出る。
- 改札内・構内の判定は店名・住所・注記の語に頼っている。公式ページの本文にしか書かれていない店
  （例: スターバックス 都営神保町駅店）は個別に `EXCL` へ足す必要がある。
- 「È PRONTO」「てっぱんのスパゲッティ」など、取得の段階で別業態として外しているブランドがある。
- ロッテリアは公式の店舗検索がゼッテリアに統合されており、一覧に載るのはゼッテリア名義の店。
- 大阪王将・魚べいは、公式ページのJSに書かれた公開の値を実行時に読んでAPIを呼ぶ。
